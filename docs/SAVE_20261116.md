## 본선 전투와 원정

로켓 발사 후 외계인 본선에 진입하고, 착륙선까지 실제로 돌아가 재탑승하면 지구로 귀환한다. 재정비 후 다시 출전할 수 있으며 최종 보스를 처치해야 승리한다. 보스에게 체력에 따른 2단계 공격과 원·직선·근접 충격파 예고를 적용했다. 예고와 재사용 대기 시간도 저장한다. 착륙 구역과 전투 구역을 구분하고 본선 전용 카메라 여백·초점 높이, 갑판과 착륙선·보스 미니맵 표시를 조정했다.

후반 체크포인트에서 왕복·재출전·일반 공격·예고 공격 저장복원·승리 저장을 확인했다. 패키징한 개발 실행 파일에서도 본선 재로드와 엔딩 판정을 검사했다. 준비된 로켓과 장비를 사용하는 기능 검사이며 정상 경제 완주 기록은 아니다. 기본 나무칼 장수 1명의 별도 전투는 보스 체력 36/149를 남기고 실패했다.

도보 원정대는 본거지 외곽 길목으로 걸어가 출발한다. 출정 호위와 원군 배정·직접 전투·복귀를 연결했다. 원군이 출발 위치와 가깝다는 이유로 즉시 해산하던 조건을 고쳐, 저장을 다시 불러온 뒤 약 115.9m 이동하고 귀환해 민간 작업으로 돌아오는 것을 확인했다. 원정대가 돌아올 때 맞이 호위전을 강제하지 않는다. 마지막 승무원이 사라져도 기존 화물은 보존하되, 귀환에는 살아 있는 운반자가 필요하고 새 적재에는 용량 제한을 적용한다.

## 손수레와 탐사

손수레는 자원 관리 기술로 해금한다. 목재 20·판재 10·섬유 5를 실제로 배송하고 30 작업량을 들여 조립한다. 기본 화물 80, 장수 4명, 내구 180이며 전력이나 연료 없이 지상 장수가 견인한다. 도보보다 이동 시간은 15% 길다. 실제 시공·탑승·견인·출발, 견인 중 저장복원과 일시 중단·재개를 확인했다. 수리와 잔해 회수도 목재를 사용하며 실제 차감까지 검사했다.

새 게임에서는 먼 지역을 처음부터 모두 보여 주지 않는다. 본거지 작업으로 첫 흔적을 찾고, 원정 현장의 지도 조각과 무선 통신 연구로 탐사 범위를 넓힌다. 연구원이 무선 신호를 조사해 먼 지역 두 곳을 발견하고 저장하는 것을 확인했다. 기존 저장의 공개 지역은 유지한다.

## 자원이 고갈된 뒤의 생산

채석장·벌목장·모래 채취장·점토 채취장·자원 재배원·갱도 광산·심부 광산 7종을 기술과 생산 주문에 연결했다. 기본 시설은 장수가 직접 일하고 산출물을 현장에 내려놓은 뒤 운반한다. 재배원은 물 배송이 필요하고 심부 광산만 200W를 사용한다. 광물은 표본 연구와 채굴 기술을 요구하며 별광석에는 추가 기술이 필요하다.

시설 7종과 주문의 전체 저장복원, 장수의 채석장 접근과 석재 생산을 확인했다. 심부 광산은 실제 발전기의 석탄 소비·전력 공급, 정전 중 작업 보존, 복전 후 티타늄 3개 생산을 검사했다. 충분한 재료와 연료를 준비한 격리 검사다.

자연 진행에서는 본거지에 흙 채집 노드가 없는데 채석장 건설과 첫 생산 연구가 먼저 흙을 요구하는 순환이 드러났다. 기본 채석장과 벌목장 건설비를 목재 20으로 바꾸고, 첫 자원 생산 연구에서만 흙 비용을 제거했다. 식량 25·연구 작업량 200과 실제 건설·생산은 유지했다. 기존 청사진에 이미 납품한 자재도 보존한다. 재건한 채석장이 흙 5개를 실제로 생산하고 입고하는 과정까지 확인했다.

미반입 중립 원정지의 자연 매장량은 정착지 재산에서 제외했다. 현장의 플레이어 화물과 편입 거점 재고는 계속 계산한다. 조사한 저장에서는 중립 흙 1,480개가 빠졌지만 기대 등급은 전후 모두 1이었다. 기분이 개선됐다고 기록하지 않는다. 생산 화면에는 주문 없음과 재고 목표 충족 대기를 구분해 표시했다. 이 묶음의 경제·소유권·표시 검사는 10개를 통과했다.

## 음식·음주·생활

보리죽은 보리와 물, 수프는 통합 식량과 물, 꿀빵은 밀가루와 꿀을 사용한다. 별도 완성품과 Meshy 외형을 적용하고 재료 배송·조리·운반·보관·식단·섭취 효과를 연결했다. 조리 도중 저장과 완성품 재로드, 이전 v24 수송 화물 배열 이관을 확인했다.

바닥 음식도 식단과 이동 경로를 확인한 뒤 직접 걸어가 먹는다. 원식량 창고가 비어 있어도 접근 가능한 식사가 있으면 굶주림 이탈로 처리하지 않는다. 실제 음식 한 끼 소비와 식사 중 저장복원을 확인했다. 운반 중 위생이 낮아지면 입고를 마친 뒤 위생을 처리하도록 바꿨다. 조리 재료 병목과 식량 비축·부패·공급 표시, 작물 성장 외형도 보완했다.

음주는 장수별 허용 여부와 간격을 설정하며, 실제 창고 접근과 1회분 소비를 거친다. 취기·숙취·금단·의존 특성과 작업·전투 효과, 취소 시 바닥 반환을 연결했다. 불러오기 중 명령 초기화가 마시던 술을 취소하던 문제를 수정하고 남은 음주 시간과 효과 복원을 검사했다.

먹을 수 있는 식사가 없는 장수는 포만 25 이하에서 기아 경고를 받는다. 위협 자동정지 설정을 따르고 같은 경고를 중복 생성하지 않는다. 장수 상세에는 장기 불만의 300초 이탈과 별도로, 포만 0·먹을 식사 없음·기분 50 미만일 때 식량 점검에서 발생하는 이탈 조건을 표시했다. 이탈 규칙 자체를 완화하지 않았다. 식사·바닥 음식 접근, 자동정지 켜짐/꺼짐, 중복 억제와 UI 등 9개 검사를 통과했다.

## 시설 외형과 사용 동작

Meshy 채석장·벌목장·심부 광산을 Unity 재질과 실제 시설에 연결했다. 나머지 생산 시설 4종은 아직 Blender 모델이다. 음식 3종과 짚자리, 산성탑, 도보 원정 보급품, 비본선 보스도 Meshy 모델을 적용했다. Blender는 Meshy 원본의 변환·축·크기·텍스처 추출에 사용했다. 모든 임시 에셋 교체가 끝난 것은 아니다.

기록으로 확인한 생성 비용은 생산 시설 3종 72크레딧, 음식 3종 72, 짚자리 24, 산성탑 39, 도보 보급품 36, 비본선 보스 24다. 서로 다른 작업 시점의 기록이며 현재 잔액이나 전체 결제액을 뜻하지 않는다.

산성탑은 조준과 발사 위치를 외형에 맞추고 이전 원통이 겹치지 않게 했다. 비본선 보스는 복제와 저장복원 때 모델이 숨겨지던 조건을 수정했다. 기존 체력·공격 패턴·피격과 클릭 판정은 유지했다. 도보 원정 보급품의 노란 차량 상자 표시도 교체하고 화물·접지·재로드를 확인했다.

방 지붕은 고정 월드 높이 대신 실제 지면과 벽 외형 상단을 따른다. 직사각형 방에는 Meshy 초가지붕을 적용하고 확대하면 내부가 보이도록 했다. 불규칙한 방의 빈칸은 기존 칸별 메시로 보존한다. 16칸 방과 14칸 불규칙 방, 저장복원, 벽 개방 후 지붕 제거를 검사했다. Meshy 돌 화덕·식량 저장고·양쪽으로 열리는 목책문도 시설에 연결했다.

책장과 목공대는 실제 접근 후 독서·톱질을 확인했다. 기본 목재 모델 선택과 작업 지점 계산을 보완하고, 중앙 작업 지점이 NavMesh 때문에 밀리면 앞쪽 가장자리의 좌우 지점을 사용하도록 했다. 실제 판재 생산·운반과 재로드를 확인했다. 짚자리는 축 변환을 수정한 뒤 자연 야간에 장수 3명의 베개 방향과 수면 접점을 확인했다. 전 장비·전 자세의 관통 검증은 남아 있다.

## 사망 동작과 날씨

"몹이 그냥 뒤집힌다"는 요청에 따라 생물형 17종이 현재 자세에서 다리 지지를 잃고 몸통·머리·하부 관절이 차례로 무너지는 2.6초 동작을 적용했다. 작은 잔떨림 후 가라앉고, 사체의 방향과 자세도 저장한다. GPU 무리 개체의 사망 표본을 다시 생성하면서 생존 동작과 무리 간격을 보존했다. 실제 치명 피해에 따른 대표 개체와 무리 사체 생성, 전체 재로드를 확인했다.

바위·나무·채집 자원에 눈 쌓임과 융설, 비에 젖은 색, 계절 잎색과 낙엽을 연결했다. Meshy 원본 텍스처는 유지하고 소나무는 상록수로 남긴다. 적설과 젖음 상태도 저장한다. "바닥이 완전 하얘져서 분간이 안 된다"는 추가 요청을 반영해 지면 전체를 덮지 않고 흙 질감·노출 부분·경사면을 남겼다. 바위 윗면과 지면의 눈은 다르게 표현한다.

강설 45/90초 누적과 비의 융설, 저장된 적설 0.65·젖음 0.2, 사체 방향 73도와 최종 관절 자세 복원을 검사했다. 날씨 촬영은 격리 상태에서 진행했으며 자연 캠페인 실적으로 합산하지 않는다. 발자국·물리 적설 두께·별도 날씨 음향은 이번 구현 범위에 없다.

## 전투 반응·화재·표시

13웨이브 실제 진행에서 안개 밖 활 공격을 받는 적 16호스트가 표적 없이 중앙에 서 있던 문제를 확인했다. 실제 피해를 받은 표적 없는 습격자는 최근 피격 출발점을 10초 동안 탐색한다. 보이지 않는 장수를 자동 표적으로 지정하거나 사거리·피해·체력을 바꾸지는 않았다. 탐색 상태 저장을 포함한 11개 검사를 통과했고, 같은 저장을 다시 진행하자 추격이 발생해 10,491.4초에 정착지가 패배했다.

Meshy 시설에도 실제 불꽃과 본거지 화재 경고를 표시했다. 소방 작업과 장수의 직접 소화 명령, 일시정지 표시와 저장복원을 확인했다. 알림은 중요도 순 5개를 기본으로 보여 주고 전체 목록을 펼치거나 접을 수 있다. 같은 장수의 반복 기분 경고는 최신 상태로 갱신한다. 건축 메뉴의 최초 재료는 목재이며 사용자가 고른 재료는 유지한다.

씬의 TerrainGenerator 두 오브젝트에 붙은 누락 스크립트 참조를 각각 하나씩 제거했다. 원본 씬을 백업하고 정상 Transform 55개·컴포넌트 268개를 보존했으며 실제 이동과 기존 저장 재로드를 확인했다.

## 자연 진행에서 확인한 것

최초 장기 회차는 12웨이브를 막고 원정에서 흙 11개를 본거지에 반입했지만, 시설 손실과 장수 사망·탈주 끝에 13웨이브 10,145.8초에 패배했다. 별도 중반 회차도 11웨이브 8,497.5초에 패배했다. 후속 회차는 12웨이브 방어 뒤 채석장·우물·화덕 등을 재건하고 흙 생산을 확인했으나, 13웨이브 안개 피격 문제를 수정한 뒤 10,491.4초에 패배했다. 이 회차들을 합쳐 한 번의 완주로 계산하지 않는다.

최신 공급 검증은 기존 4웨이브 종료 저장 3,225.98초부터 이어 갔다. 식량 부족으로 장수 두 명이 떠났고 남은 한 명이 5웨이브를 막았다. 우물과 밭이 파괴된 뒤 수확·운반·조리·식사·재수확을 진행하고, 4,201.1초에 이주민이 합류했다. 두 장수로 6웨이브를 막은 4,598.3초 상태를 정상 저장했다. 남은 식량 8·흙 15, 목재와 물 0이며 산성탑 한 기는 체력 12/250이다. 생산 시설이 다시 파괴되고 밭 급수가 끊겨 경제 안정화에는 미달한다.

마지막 전체 재로드는 CLI의 65초 제한을 넘겼지만 실제 복원이 끝난 뒤 정상 재저장까지 확인했다. 주요 장수·재고·시설·작물 상태는 유지했다. 난수, 일부 엔트리·식별자, 착지 높이와 카메라 차이가 남아 있어 저장 JSON 전체 일치나 결정적 재현까지 보장한 결과는 아니다.

## 성능과 배포의 현재 범위

발 접촉 보정에서 전체 정점의 높이만 Burst로 계산하도록 바꿨다. 17종의 340자세에서 기존 높이와 최대 2.384e-7m 차이로 일치했다. 같은 중반 저장의 에디터 관찰 평균 프레임 시간은 140.56ms에서 44.71ms로 줄었다. 전후 표본 수가 42와 121로 다르고 짧은 에디터 측정이므로 최종 배포 FPS나 최대 규모 성능으로 해석하지 않는다.

Windows 후보 `Builds/Windows1115/AntColony.exe`는 오류 0·경고 528로 생성했고 실행을 확인했다. 이후 생산·생활·사망·날씨 등의 변경은 포함하지 않은 이전 빌드다. 최신 변경을 담은 최종 배포 빌드, 정상 경제의 엔딩 완주, 장기 식량·급수·방어 밸런스와 대규모 성능 검증이 남아 있다.

SAVE 요청에 따라 추가 구현을 멈추고 현재 결과를 보존한다. Unity 검사 설정과 저장 경로는 원복했고 Play는 종료했다. 컴퓨터는 종료하지 않는다. 원격 저장과 Notion 첨부의 최종 영수증은 완료 후 별도로 기록한다.

## SAVE 보관 범위

Notion 개발 일지와 문제 해결 기록을 2026-11-16 페이지로 작성하고 실제 기능 화면 7장을 첨부했다. humanizer 기준으로 문장을 다듬되 검사 수치·실패·미완료 범위는 유지했다. 날짜 목록은 11월 14일 다음에 일반 날짜 링크로 추가하고 기존 페이지·첨부를 보존했다.

이전 미완료 에셋 업로드를 이번 저장에 포함한다. 제작 원본·코드·검증 저장은 보존하며 반복 검사 중간 PNG/JPG 1,723장은 로컬 원본과 목록으로 남긴다. 원격에는 문서에 사용한 화면을 포함한다. 큰 파일의 복원 방법과 해시 검사는 `work/save-20261116`에 보관한다. 프리팹은 커밋하지 않는다.

추가 요청에 따라 사망 0·0.32·0.70·1.20·2.60초의 실제 Unity 캡처 5장을 묶은 GIF를 개발 일지에 첨부했다. 마지막 자세를 0.8초 유지하는 총 3.4초 반복이며 연속 녹화 영상은 아니다. 사진 7장도 유지했다.

저장소 비공개 전환 요청을 받았다. GitHub 연결의 조회 결과는 public이며 관리자 권한이 있다. 연결 도구에는 공개 범위 변경 기능이 없고, 브라우저 제어는 현재 URL을 확인하지 못한 자동 안전 검사에 의해 중단됐다. 사용자에게 직접 Private 전환을 안내했으며, 비공개 확인 전에는 새 변경을 공개 develop에 게시하지 않는다.

백업 원본 699개는 크기·SHA-256 검증을 통과했다. 전송된 아카이브 그룹 258개의 Git 트리 해시도 로컬과 일치한다. 나머지 16개 그룹과 develop 커밋·push는 비공개 확인 대기 상태다. 로컬 원본과 복원용 아카이브는 보존했으며 원격 SAVE 완료로 기록하지 않는다.


SAVE 후속 정정: 사용자가 비공개 전환이 막히면 생략하고 SAVE를 계속하도록 지시했다. 현재 공개 상태를 유지하며 전송을 재개했고 274개 아카이브 그룹 전체의 Git 트리 해시가 일치한다. 기존 비공개 대기 상태는 해제했다. 또한 최신 지시에 따라 SAVE 완료 확인 뒤 컴퓨터를 정상 종료한다.

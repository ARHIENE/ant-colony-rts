# 기존 시설 연결 · 재봉대 · 적 디자인 (2026-11-14)

사용자 요청: 새 에셋을 중복 생성하지 않고 기존 미연결 시설부터 연결. 재봉대는 의복 제작·수리까지 구현. 가죽 자원이 없는 점 확인 후 사용자가 가죽옷은 후속으로 지정했다.

## 반영

- 기존 production-kit-20261019 원본 7개 재사용: SewingTable, Prospector, DeepDrill, AdvancedDrill, GasExtractor, GasGenerator, GasTank. 신규 Meshy 생성·다운로드 없음.
- 재봉대를 생산 건설 메뉴에 추가. 지하 탐사기·심층 채굴기·합금 심층 채굴기·가스 추출기·가스 발전기·기체 탱크는 기존 대체 외형 대신 해당 원본 모델 사용. 기능·배관·연구 조건은 유지.
- 재봉대에서 직물 4를 배송받아 천옷 제작. 기존 품질·제작 경험치·생산 목록·바닥 완성품 운반 흐름 재사용. 일반 공방과 제작 품목 분리.
- 천옷은 방어구 슬롯. 초기 내구 100, 피해의 15%를 내구만큼 흡수. 소진 시 보호 없음. 수치는 잠정 밸런스.
- 손상된 천옷을 보관함에 넣고 재봉대에서 수리 예약. 직물 1 배송 후 작업. 원본 ID·품질 유지, 완료 시 내구 회복. 중복 예약/예약 중 장착 방지. 취소 시 옷은 보관함에 남으며 기존 재료 환급 규칙 적용.
- 수리 예약·진행도·결제 여부 저장. 재봉대의 건물 종류를 별도로 직렬화하여 불러오기 때 공방으로 바뀌지 않도록 처리.
- 의복에 금속 갑옷 모델을 덧씌우지 않음. 기존 캐릭터 기본 복장 표시 유지. 기존 SewRepair 동작 선택; 원본 모듈형 모션으로 폴백하며 전용 신규 Meshy 클립은 만들지 않음.

## 검증과 한계

- 공식 Hub 관리 CLI 1.0.0 / Unity 6000.5.8f1. 임포트 7개 및 URP 머티리얼 검사 통과. 기존 재봉대 미리보기 직접 확인.
- 격리된 임시 저장 경로에서 Play 검사 24개 통과: 재료 배송, 천옷 완성품, 수리 예약/중복 거절, 장착 제한, 수리 중 실제 저장·불러오기, ID/품질 유지, 취소, 피해 흡수와 마모. 검사 후 사용자 설정/저장 경로 복원.
- 1차 CLI 응답은 30초 제한으로 끊겼지만 에디터 내부 검사는 완료되어 work/existing-assets-1114/checks.txt에 PASS 결과를 기록했다. 최종 수정 후 재검사는 CLI 응답으로도 PASS 24를 확인했다.
- 자연 플레이 장기 생산·자동 운반의 전 구간, 재봉 손과 책상 접점, 옷 전용 외형은 이번 검사 범위가 아니다. 가죽옷은 사용자 결정에 따라 미구현.

## 적 디자인 제안

사용자는 무인기뿐 아니라 진짜 외계인과 외계인이 타는 것을 요청했고, 첫 기계식 외계인 시안을 너무 기계적이라고 정정했다. 생물형 군체 느낌으로 다시 디자인했다.

![생물형 외계인 콘셉트](../art/enemy-concepts-1114/organic-invaders-concept.png)

1. 소형 사냥개체: 빠른 접근과 측면 압박.
2. 지성 외계인: 기수/지휘 개체의 공통 몸체 후보.
3. 중장 돌파 생물: 벽·방어선 압박.
4. 산성 분사 생물: 후방 원거리 공격.
5. 외계인 기수 + 대형 사냥 생물: 별도 생물 두 개체가 신경 연결된 기동형.
6. 외계인 조종자 + 거대 공성 생물: 느리고 큰 원거리 공성형.

모두 디자인 제안이며 수치·웨이브 편성·게임 구현은 미확정. 최초 네 발 기계형 무인기 시안은 이후 사용자 요청으로 폐기하고 후보에서 제외했다(2026-11-14). 현재 생물형 후보는 후속 시안을 포함해 17종이다. 실제 모델 제작 전 기존 적 에셋과 중복 점검 필요. 그림의 미세한 돌기·힘줄은 RTS 시점에 맞게 단순화해야 한다.

사용자는 생물형 시안의 느낌을 긍정했고 벽을 노리는 적·원거리 적 추가 디자인을 요청했다. 후속 역할 제안:

![벽 공격·원거리 특화 개체](../art/enemy-concepts-1114/organic-specialists-concept.png)

| 후보 | 실루엣·공격 예고 | 역할·대처 |
| --- | --- | --- |
| 충각수 | 낮고 넓은 몸, 두꺼운 이마, 여섯 지지 다리. 몸을 낮춘 뒤 직선 돌진 | 통로를 막는 벽을 공격. 준비 중 집중 공격하거나 돌진선을 비움 |
| 부식붙이 | 납작한 몸과 벽을 붙잡는 짧은 갈고리, 부푸는 산성 주머니 | 벽에 붙어 지속 부식. 붙은 뒤 움직임이 제한되어 방어측의 우선 제거 대상 |
| 침사냥꾼 | 가늘고 긴 다리, 수평으로 긴 주둥이, 발사 전 펼쳐지는 볼막 | 긴 사거리 직사 공격. 벽으로 시야를 가리고 발사 간격에 접근 |
| 포낭수 | 낮은 복부, 넓은 고정 다리, 위로 솟은 유연한 발사 기관 | 고정·팽창 후 벽 너머 곡사 포격. 착탄 예고를 보고 이동, 고정 중 접근해 제거 |

돌진·지속 부식·시야 판정·착탄 예고는 아직 게임에 연결하지 않은 설계 제안이다. 벽 파괴 역할은 기존 적 목표 우선순위와 연결할 후보이며, 벽을 항상 무시하도록 정한 것이 아니다.

추가 아이디어(사용자 확정 전): 포낭 운반체(작은 개체 방출), 안개 분비체(무리 은폐), 갈고리 포식자(혀로 고립된 장수 끌기), 갑각 수호체(뒤의 적 보호), 회수 생물(전장 사체 활용), 굴착 잠복체(균열 예고 후 출현). 우선 디자인 후보는 역할과 실루엣이 덜 겹치는 운반체·포식자·수호체. 굴착형은 초기 벽 방어를 무력화하지 않도록 후반 특수 역할로 제안하며, 구현·수치 결정은 별도다.

# 방 지붕 연결 — 2026-11-15

기존 자동 지붕은 월드 높이2.6에 고정돼 지면이 약10인 본거지에서 땅속에 생겼다. 방의 벽 외형 상단과 지면을 읽어 높이를 잡도록 바꿨다. 벽 모델이 늦게 준비되면 방을 다시 계산한다.

기존 Meshy 초가지붕을 FBX·2K 텍스처로 변환해 직사각형 방에 연결했다. 원본 축 변환을 보존하고 벽 위까지 처마를 확장했다. 가까이 확대하면 지붕이 흐려져 내부가 보인다. 불규칙 방은 기존 칸별 메시를 사용하므로 빈칸이나 안뜰을 임의로 덮지 않는다. 추가 생성·크레딧 사용은 없다.

격리 검사에서 실제 기본 벽으로16칸 방을 구성하고, 높이·재질·투명도·저장/전체 재로드·14칸 불규칙 방·경계 개방 후 지붕 제거를 확인했다. 첫 촬영의 청록색은 URP `FallbackLoading` 셰이더였다. 컴파일이 끝난 뒤 재촬영해 초가 텍스처와 처마를 직접 확인했다.

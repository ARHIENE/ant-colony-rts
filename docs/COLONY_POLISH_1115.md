# 11월 15일 운영·자원·탐사 연결

사용자 지시는 빌드 산출이 아닌 실제 게임 완성도 개선이다. 기존 미커밋 변경을 보존하고 정착지 운영과 원정·본선 엔딩 연결을 함께 다듬고 있다. 전체 구현·검증 완료 후 SAVE한다. 최신 지시에 따라 컴퓨터는 종료하지 않는다. 현재 전체 완료 조건은 충족하지 않았다.

## 적용한 변경

- 보리죽·수프·꿀빵을 별도 자원 ID와 레시피로 추가. 기존 ID/레시피 순서는 유지하고 저장 버전25에서 v24 수송 화물 배열을 확장한다. 기존 그릇/빵 자산을 Blender로 변형한 외형3종과 URP 재질을 연결했다.

- 조리 주문의 재료 병목 처리, 식량 비축·부패·공급 병목 표시, 정신 붕괴 심각도, 작물 성장 외형 연결.
- 채석장·벌목장·모래/점토 채취장·자원 재배원·갱도 광산·심부 광산. 기본 시설은 인력 생산이며 재배원은 물 배송, 심부 광산은 200W를 요구한다. 임의로 자동 생산하지 않고 생산 주문·작업·현장 배출·운반으로 연결한다.
- 광물 표본 연구와 기술 해금, 자원 고갈 이후 지속 생산 경로. 신규 기술 ID는 끝에 붙이고 정의 배열을 ID 순으로 정렬해 기존 저장과 선행 연구 참조를 보존한다.
- 새 게임의 숨겨진 지역, 본거지 작업의 첫 단서, 원정 현장의 지도 조각, 연구원 작업으로 무선 신호 탐사. 기존 저장은 종전 공개 상태를 유지한다.
- 양조 산출물의 음주 정책·실제 창고 접근·1회분 소비·취기·숙취·금단·의존 특성·저장 복원을 연결했다. 성인 제한, 금지 정책, 의존의 소집 예외, 중단 시 바닥 반환을 검사했다.

## 에셋

Meshy 기존 보유499크레딧에서 콘셉트27·3D45, 총72크레딧 사용 후427크레딧을 확인했다. 채석장22,747·벌목장22,566·심부 광산22,875삼각형의 텍스처 GLB를 다운로드했고 Blender MCP로 지면·크기를 맞춰 FBX와 텍스처를 내보냈다. Unity URP 재질과 실제 시설 모델 연결을 확인했다. 다른4시설은 Blender 제작 모델을 사용한다.

원본 다운로드: `Woodland_Quarry_3D.glb`, `Woodland_Logging_Camp.glb`, `Woodland_Deep_Mine_3D.glb`. 프로젝트 변환 원본은 `work/colony-polish-1115/meshy`, 런타임은 `Assets/Resources/Industry1115`다.

## 확인한 범위와 실패 구분

- 음식3종 재료 예약·실물 소비·조리·바닥 산출·섭취 등급·포만 회복 통과. 보리죽 조리 도중 저장/전체 재로드와 완료 후 세 완성품 재로드, 원본 v24 본선 체크포인트 및 수송 배열 이관 통과. 검사는 재료를 준비한 격리 환경이며 자연 재배 경제 완주 증거는 아니다. 바닥 모델 Start 초기화 전 즉시 검사하던 조건을 다음 프레임 이후로 수정했고 조리 완료 반올림 경계도 보정했다.
- 기본 나무칼 장수1명 일반 본선 전투는 2단계에서 실패했다(보스 잔여36/149, 마지막 체력0). 보스 체력이나 장수 체력을 주입하지 않은 스트레스 검사이며 정상 승리로 기록하지 않는다. 후반 장비를 준비한 별도 전투 검사를 진행한다.

- 시설7종 생성·기술 관문·수동/전력 구분·재배원 물 배송 대기. 지정한 장수의 실제 채석장 접근·석재5개 생산·주문 소진 및 정상 저장·전체 재로드 통과.
- 초기 검사에는 다른 장수가 채집한 석재를 생산 완료로 잘못 감지할 수 있었다. 다른 장수 작업을 끄고 해당 채석장 주문 소진을 기다리도록 검사 조건을 수정한 뒤 통과했다.
- 실제 발전기의 석탄 소비와 전력 공급, 정전 시 작업 보존, 복전 후 티타늄3개 생산 통과. 처음 주입한 석탄20개로는 연료가 부족해 중단했고, 충분한 연료를 둔 별도 검사를 통과했다.
- 실제 연구원 배정·연구 작업으로 먼 지역2개 발견과 저장 통과. 처음의 벽시계120초 제한은 끝나기 전에 만료했다. 진행을 보존한 상태에서 기다리는 시간을 늘려 완료를 확인했다.
- 최신 자원·탐사 코드에서 기존 본선 체크포인트 로드, 일반 공격, 예고 공격 저장·복원, 최종 승리 회귀 통과. 처음부터 자연 경제로 엔딩까지 완주한 결과는 아니다.
- 음주 첫 검사에서 불러오기 중 명령 초기화가 보유 중인 술을 취소하는 결함을 발견했다. 저장 복원 중에는 취소하지 않도록 수정했고 음주 잔여 시간 복원을 확인했다. 시간 상수 오류를 수정한 뒤 효과·취소 반환·소집 예외·실제 음주 후 금단 해소·저장 검사를 통과했다.

상세 실행 기록은 `work/colony-polish-1115/*checks.txt`, 본선 회귀는 `work/campaign-complete-1115/run.txt`에 있다. 초기 실패와 최종 통과를 합산해 자연 플레이 성공으로 해석하지 않는다. 이전 Windows 빌드는 이 후속 변경을 포함하지 않는다.

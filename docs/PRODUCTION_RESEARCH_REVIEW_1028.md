# 생산·연구 비교 기준

100항목21~40 검토용. 사용자 승인한 정착지 자동 운영 방향을 기준으로 실제 규칙과 미완을 구분한다. 게임 속 표시는 기존 밭/과학 화면을 재사용한다.

## 작물 선택 (21·22)

## 겨울·가공 (23~28, 검토 잔여)

- 겨울6일과 요리3일은 별도다. 곡물24일 보존은 겨울 전 전량 조리하지 않고 필요한 만큼 조리하는 선택을 준다. 곡물→요리의 실제 배송/조리/식사/저장 경로는 요리88·산업96검사에서 확인했지만, 전체 장수3명의 겨울 수지와 낚시/세금/냉장 조합은 아직 장기 검증하지 않았다.
- 기존 납작빵은 밀4→밀가루2→1끼로 같은 간단식인 밥(쌀2)보다 원료가 두 배이고 추가 제분 노동도 들었다. 잠정 배합을 밀2→밀가루1→납작빵1로 낮췄다. 제분8+조리12의 노동은 남고, 쌀보다 짧은 밀의 성장 주기와 가용 원료를 보고 고르는 대안이다. 완성 요리 보존3일·품질은 유지하며 보존식에 새 보존 보너스를 붙이지 않았다.
- 냉장·냉동 효과는 내부 재고에만 적용하며 창고 이전은 자동화하지 않는 확정 규칙을 유지한다.

## 남은 연결 (35~40)

자원 표본은 본거지 반입·연구 후 채굴 해금이며 연구 작업300이 필요하다. 가스/원유/전력/가공 실물 경로는 기존 검사 범위가 있으나 시대별 최종 선행·상위 설비의 노동 절감·연료/면적/안정성 비교와 정전 시 우선순위는 아직 남아 있다. 전체 산업 기획을 연결 완료로 표시하지 않는다.

## 부족 전력의 공급 순서 (39)

가용20J·냉동고20W·전등10W에서 두 부하가 모두 꺼지고20J도 미사용 상태였던 경로를 재현했다. 건물별 전력 우선순위1~9로 높은 부하부터 공급하고 실제 공급분만 배터리에서 소비하도록 수정했다. 기본 냉장/냉동8·생산5·전등3은 잠정값이며, 플레이어가 선택→상세의 기존 하단 패널에서 바꿀 수 있다. 공급 못 한 큰 부하 뒤의 작은 부하도 검사한다. 작업/운반 순위와 별도이며 구 저장0은 종류별 기본값이다.

## 겨울3명 기준 수지 (24)

하루2끼·장수3명·겨울6일을 명목36끼로 계산한다. 기질/잔치/식중독·이동/생활·배속은 제외한 보수적 계획 기준이다. 날것은72원료, 쌀72는밥36으로 조리 순수360작업, 낚시 원료72는 기준240작업으로 계절한도300 안에 든다. 곡물24일은 겨울 전체를 넘지만 요리3일은 그렇지 않으므로 한꺼번에 전량 조리하는 계획은 피해야 한다. 시민100명·세율20%·균형·행정0의6일 식량 세액은127.5이며 이주/동원·정수 지급/소수 이월·식단/배송은 별도다.

기존 빵36끼는 밀144·밀가루72·제분/조리1008작업으로 겨울900초보다 길었다. 새 잠정 배합은 밀72·밀가루36·제분/조리720작업이다. 이것도 이동·생활과 실제 작업 속도를 제외한 값이므로1명으로 겨울 완전 자급한다는 뜻은 아니다. 겨울 전 제분/재고와 분업을 고려해야 한다. 실제 혼합요리 배송/취소/저장/섭취/구20/모델/UI와 구 밀가루2개 대기의1개 소비·초과1개 바닥 보존까지 CookedFood91검사 통과했다. 전체 맵/특성/기후의6일 실전 수지는 잔여다.

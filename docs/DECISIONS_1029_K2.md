AoE 저장 필드의 `captured=false` 빈 인라인 객체는 구저장/유휴 상태로 취급한다. JsonUtility가 null 클래스를 빈 객체로 만드는 경우에도 공격이 새로 발생하지 않는다. 저장 검증은 유한 좌표·단위 수평 방향·0~60초 타이머·명중 후 경고0을 요구한다(기존 예고1.2/1.5초, 명중 뒤.15초는 변경 없음).

원정 시간 계산·AoE 상태 기계·구저장 기본값·잘못된 입력은 실제 DLL로 오프라인 판정했다. 경고 중 실제 JSON/SaveSnapshot 복원·실피해/경고 표시·지형·포로 도착·화면 폭은 `Review1029K2Checks.RunScene` 및 인계서의 Claude 실행 항목이며, 장시간 플레이 필요로 분류하지 않는다.

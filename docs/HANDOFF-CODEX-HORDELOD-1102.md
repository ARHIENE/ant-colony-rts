## 변경

1. 원본 부품의 material/property-block `_BaseColor`를 정점 색으로 굽는다. 원본 `_BaseMap`도 준비 시에만 64×64 색 견본으로 읽어 UV별 색을 곱한다. 얼굴·옷의 텍스처 색 정보를 버리지 않으면서 단일 흰색 BaseMap을 사용한다. 선형 색 공간에서는 tint도 선형으로 변환한다.
2. 설치된 URP `Universal Render Pipeline/Particles/Simple Lit`를 사용한다. 패키지 소스에서 COLOR 입력, 색 곱셈, `multi_compile_instancing`, 일반 instance ID 전달을 확인했다. 파티클용 procedural 버퍼 경로는 일반 RenderMeshInstanced 경로에서 활성화하지 않는다. 새 패키지·셰이더·자산 파일 없음.
3. 해당 셰이더가 플레이어에서 제거되었거나 지원되지 않으면 기존 URP Lit로 대체한다. 면별 평균 정점 색을 런타임 팔레트 텍스처와 면별 고정 UV로 읽는다. 각 면의 세 정점은 분리하며 원래 위치·노멀을 유지한다. 이 경로도 재질/submesh는 각각 하나다. 팔레트는 최대 64×64, Point/Clamp/밉 없음이다. 정점별 부드러운 색 대신 면별 색으로 보일 수 있다.
4. 부품/submesh별 경계를 유지한 격자 정점 병합으로 모든 추가 몸체의 LOD를 한 번 만든다. 위치·색을 평균하고 퇴화면과 같은 방향 중복면을 제거한다. 원본에서 다시 시작해 셀을 15%씩 키우고 1,500삼각형 이하인 첫 결과를 사용한다. 미사용 정점도 제거한다. 호스트 자체는 기존 상세 외형 그대로다.
5. `Attach` API, 공유 캐시·참조 수 정리, 배치 511, 기존 움직임·위치 배열 재사용은 유지했다. `ShadowCastingMode.Off`도 유지했다. 임시 bake mesh/색 견본/RenderTexture와 마지막 사용자의 공유 메시·재질·대체 팔레트를 정리한다. 선택 사항인 카메라 frustum culling은 추가하지 않았다.

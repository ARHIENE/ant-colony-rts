# IMPL-D2 — G27 최소 API 진행 검사

- 담당: Codex / `codex/d2-g27-check`. 변경은 D2 안에서만 수행, 게임 코드 변경·커밋 없음.
- `ImplG27Checks.Main(): Task<string>`을 기존 `RunChecks.cs`가 그대로 컴파일·실행한다.
- `startingCount`와 같은 길이의 `startingTeam`으로 새 게임을 각각 1명·3명 시작한다. 후보의 작업 금지 특성은 검사에서 제거한다.
- 단계별 예외를 수집해 `C03[3] PASS ...` / `C03[3] FAIL ...` 형식으로 28줄과 전체 PASS/FAIL 합계를 반환한다. 시작 자체 실패 시 해당 인원의 모든 단계를 시작 실패로 표시한다.

| 단계 | 최소 검증 내용 |
|---|---|
| C01 | 생존 장수 N명·초기 병력/시민 0 |
| C02 | 전원 보존식 14끼, 창고 없이 소지 식량으로 식사·포만 회복 |
| C03 | 본거지의 시작 돌 20개에서 맨손으로 1개 추출·수량 차감, 잔해 해체 API로 목재 생성 |
| C04 | 잠자리·변소·세면대·모닥불 배치 시작 허용(완공·생활 자동화 검사는 아님) |
| C05 | fixture 자원/주거 준비 → 이주 반복으로 시민 확보 → 징집소에서 병력 5명 편성·반환·민간 복귀 |
| C06 | fixture 식량으로 1인 도보 원정 편성·보급 적재·출발·도착·귀환 |
| C07 | 첫 보스 공개·실제 보스 생성·개인 공격력·보스 피해 API 수용(전투 승리 검사는 아님) |
| C08 | A 처치 상태를 API로 모의 입력 → 핵심물 획득·1회 반입·핵심물 2개·B/C 제조법 |
| C09 | B 탐지기 실제 비용 소비 제작·시간 진행·도구 사용·공개 |
| C10 | C 탐지, B만 반입 시 D 잠금, B/C 반입 후 D 탐지, 모의 D 보상 반입으로 설계도 해금 |
| C11 | 1인 연구대 배정·낚시 연구 완료, 철 표본 반입·표본 연구 완료 |
| C12 | D 설계도 확인 후 후반 연구 완료 상태를 fixture로 준비, 로켓 선체/기관 비용 소비·건조 시작·완료 |
| C13 | 연료 적재·가동·준비 시간 진행·탑승·발사 요청 수용(발사 확정/승리는 검사하지 않음) |
| C14 | 로켓 fixture 제거 후 실제 파일 저장/불러오기, 생존 장수 수·ID 집합·시민 수·시작 인원 유지 |

실행 명령(통합된 Unity 프로젝트에서):

```bash
CHECK_POLLS=120 bash AgentScripts/tools/run_checks.sh ImplG27Checks
```

현재 `run_checks.sh`는 `/e/Git/ant`로 이동한다. D2의 새 파일을 읽는 명령이 아니므로 이번 작업에서는 실행하지 않았다. 통합 담당자가 스크립트를 통합한 후 실행할 것. 이 도구는 결과 앞 600바이트만 출력하므로 전체 28줄은 해당 프로젝트의 `Temp/check-result.txt` 또는 `AntColony.CheckResult`에서 확인한다.

- 임시 `SaveStorage.RootOverride` 사용·자동 저장 비활성화, 종료 시 경로/설정/난수 복원 및 일시정지. 검사 시작은 현재 Play 세션을 새 게임으로 교체한다.
- fixture 시설 생성·기본 재고 칸에 자원 지급·모의 보스 처치·시간 가속·후반 연구 상태 주입을 사용한다. PASS는 각 API 최소 전제의 통과이며 자연 진행/자원 수지/수동 완주의 통과 근거가 아니다. 선행 단계 실패가 후속 단계 실패를 일으킬 수 있다.
- 오프라인 검증: Unity 6000.5.8f1 내장 Roslyn, 본체 Bee rsp 옵션/참조 + D2 소스, Editor rsp 참조 + 생성한 본체 DLL로 새 스크립트 단독 컴파일. 두 컴파일 모두 exit 0 / 오류 0(기존 obsolete 경고). 결과·rsp: `Temp/off/runtime.log`, `check.log`, `runtime.rsp`, `check.rsp`.
- D2에 없는 원본 rsp의 외부 에셋 소스는 제외. 유일하게 필요한 `SpinFree.cs`는 원본에서 읽어 D2 `Temp/off`에 복사하여 컴파일했다. 원본 파일 수정 없음.
- Unity 런타임 검사는 미실행. G27 표의 1명·3명 통과 판정은 실행 후 기록해야 한다.

# 웨이브 설계 초안 — 2026-11-03 (사용자 검토 3·5·6번)

> **초안이다. 3·5번은 규칙 변경이라 사용자 승인 전 코드에 넣지 않는다.** 6번은 사용자 승인으로 바로 구현(Codex WAVE-RETREAT-1103).
> 기준: GAME_DIRECTION.md 6.1 '웨이브 준비 기대치'·'무리와 장수의 역할 분담'(2026-11-03 확정).

## 3. 웨이브 적 유형 (준비를 다르게 요구하는 4종)

새 시스템 없이 기존 WildMonster(침입자·무리)·EnemyCommander·원거리 공격(attackRange>2) 경로에 수치·목표 선택만 바꿔 만든다.

| 유형 | 행동 | 요구하는 준비(대응) | 막는 경험 | 첫 등장(안) |
|---|---|---|---|---|
| 기본 무리 | 가까운 장수·건물을 친다 | 벽+탑 (역할 분담: 무리는 시설이 처리) | 방어선 기본기 | 1웨이브 |
| 공성형 | 장수를 무시하고 벽·건물만 친다. 느리고 벽 압력 큼 | 벽 앞에서 녹일 탑 화력·수리 인력. 벽만 두꺼우면 결국 뚫림 | "벽만 쌓으면 끝"을 깸 | 3웨이브 |
| 빠른 돌파형 | 빠르고 약함. 가장 약한 벽·문·외곽 건물로 우회 | 함정·문 병목·방어선 빈틈 메우기 | 외곽 방치 처벌, 함정 연구 동기 | 4웨이브 |
| 정예가 이끄는 무리 | 적 장수 1이 무리를 이끈다. 정예가 죽으면 무리가 흩어지거나 약해짐 | 장수 집중 공격(정예 저격) | 후반에도 지휘가 남음 | 5웨이브 |
| 원거리형 | 벽 밖 사거리에서 탑·장수를 쏜다 | 사거리 연구·장수 출격 후 복귀(교대·후퇴) | 성 안에서 기다리기만 하면 안 됨 | 6웨이브 |

- 이후 웨이브는 2~3종 혼합. 예고 정보(유형·방향)는 6.3 미정 — 평화 중 감시탑이 있으면 유형 공개를 안으로 둔다.
- 결정 필요: 유형 수(4종 고정?)·등장 순서·정예 사망 시 무리 반응(흩어짐 vs 약화).

## 5. 첫 평화 구간(첫 웨이브 전) 노출 범위

삭제가 아니라 **노출 순서**. 무조작 6일 측정(2026-11-03): 이탈 없음, 기분 22~52(노숙 −15·굶주림 −15), 비축 식량 0. 첫 6일의 일은 "잠자리·식량·첫 방어선"이면 충분하다.

| 첫 웨이브 전 노출 | 해금 시점(안) |
|---|---|
| 채집·기본 작물 농사·낚시, 창고 | 처음부터 |
| 침상·초가집·변소·세면대·모닥불(생활 최소) | 처음부터 |
| 기본 조리 1~2종(구이·죽 등) | 처음부터. 나머지 식품은 조리대·연구 후 |
| 나뭇잎 벽·흙벽·문·산성탑 | 처음부터(2웨이브 기준을 맞추려면 필수) |
| 연구: 1시대만 표시 | 2시대 이후 목록은 1웨이브 방어 후 |
| 오락·장식 탭 | 1웨이브 방어 후(기분 관리가 필요해지는 시점) |
| 군사 훈련장·징집소 | 1웨이브 방어 후 |
| 고급 식품·다이아 등급 효과 설명·6시대 트리 | 해당 연구/조건 도달 시 |
| 원정 | 일시 제거(2026-11-03 사용자 지시, 추가 기획 대기) |

- 결정 필요: 숨김(목록에서 안 보임) vs 잠금 표시(보이되 회색+해금 조건). 추천은 **잠금 표시** — "다음에 무엇이 열리는지 미리 알아야 한다"(GAME_DIRECTION 5장 발전).

## 6. 웨이브 종료 보완 — 소수 잔여 퇴각 (구현 중)

- 생성이 끝난 뒤 남은 적 ≤ max(3, 총량×2%)이고 총량 ≥ 100이면 남은 적이 맵 밖으로 퇴각하고 웨이브는 성공 종료(잠정 수치).
- 초반 소규모 웨이브(총량 100 미만)는 기존대로 전멸 시 종료.

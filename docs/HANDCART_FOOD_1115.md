# 손수레·Meshy 음식 후속

사용자 최신 지시: 전체 기획 구현과 새 게임부터 엔딩까지 진행 검증을 계속한다. 모두 끝나면 SAVE하며 컴퓨터는 종료하지 않는다. 이 문서는 중간 구현 기록이며 전체 완료나 SAVE 기록이 아니다.

## 음식 에셋

- Meshy 프로젝트: https://www.meshy.ai/ko/agent/0wLt4vpli4Mr0BRdd14AZ
- 보리죽 4,987삼각형, 수프 4,527삼각형, 꿀빵 5,273삼각형. 2K 텍스처 포함 GLB 3종 다운로드.
- 콘셉트 27 + 3D 45 = 기존 크레딧 72 사용. 잔액 331 확인. 별도 결제 없음.
- 형상·텍스처는 Meshy 원본이다. Blender는 GLB→FBX 변환과 텍스처 추출에만 사용했다.
- Assets/Resources/MeshyFood1115에 Unity 임포트하고 URP 텍스처 연결 검사 통과. 게임 표시 경로를 이 모델로 변경했다. 교체 후 조리·섭취·저장 이관 회귀와 Unity 화면 확인 통과.

## 손수레

- 자원 관리 기술로 해금. 목재20·판재10·섬유5를 배송하고 30 작업량으로 조립. 전력·연료 없음.
- 기본 화물80, 장수4명, 내구180. 지상 장수가 실제로 출입 길목까지 견인한 뒤 월드맵 이동한다. 도보보다 이동 시간이 15% 길다. 확정 수치가 없는 부분의 이번 구현값이다.
- 기존 운반·탑승·원정·화물·수리·잔해 구조를 사용한다. 손수레 수리/회수 재료는 목재다.
- 공급된 창고 자재를 실제로 운반·시공하고 탑승·4m 이상 견인, 견인 중 저장/전체 재로드, 길목 도착 뒤 원정 이동 및 저장 통과. 기록: work/colony-polish-1115/handcart-checks.txt.
- 이 검사는 격리 자재 준비 fixture다. 자연 경제 완주 증거가 아니다.
- 후속으로 일시 중단·재개, 건설 툴팁, v26 저장 식별을 추가했다. 일시 중단 저장 복원·명시적 재개와 v26 저장 실행 재검증을 통과했다.

## 남은 범위

새 게임의 정상 경제부터 최종 엔딩까지 연속 완주, 기획 잔여 대조, 최종 성능·화면·빌드와 SAVE는 아직 완료하지 않았다. 동물 수레·마차는 이번 손수레 구현에 포함되지 않는다.

- 추가 발견: 손수레 수리/잔해 자원 소비가 기존 흙으로 고정되어 있던 부분을 RepairMaterial(손수레 목재)로 연결. 실차감 검사 예정.
- Meshy 짚자리 추가 생성·다운로드(2,953삼각형, 2K, 24크레딧, 잔액307). 시설 모델과 수면 지지점 연결 중.

- 손수레 수리 실검증 통과: 흙만 있으면 회복하지 않음, 실제 수리 명령·시간 경과로 목재만 소비하고 완전 회복. 빈 수레는 수리 오류 대신 견인 장수 부재 표시.
- 자연 진행 검사는 542.8초까지 식량73/흙40/목재53, 체력100x3을 관찰했지만 근접 촬영 zoom5(저장 허용8~35)로 저장 거부 후 잘못 종료해 마지막 유효 체크포인트120.5초부터 재개 필요. 이 구간을 저장 완료로 취급하지 않는다. 검사 구간마다 검증 저장+실패 시 원본 snapshot 보존을 추가하고 카메라 RestoreView도 기존 줌 범위로 제한한다.


- Meshy 잠자리 재검수: Blender GLB가 quaternion 모드라 첫 축변환이 적용되지 않은 문제를 XYZ로 변환해 해결. Unity 바닥 길이2m/너비0.72m, 자연 야간에 3장수의 베개 방향·잠자리 접점 확인(04r-soil-and-water-422.png).
- 카메라 추가 조사: 실제 실행 인스턴스의 줌 범위는5~30으로 직렬화되어 있었고 저장 검증은8~35여서 정상 최소 줌도 거부될 수 있다. 현재 검사 뷰는8로 바꿔 저장 통과, 게임 저장 허용 범위 정합 수정은 다음 Edit에서 수행 예정.

## 후속 확인

카메라 허용 범위를5~35로 통일하고 실제 최소 줌5에서 저장·전체 불러오기까지 통과했다. 자연 진행은 바닥 식사 누락과 위생 중 화물 투하를 수정한 뒤 웨이브3 방어 성공(2,413.5초)까지 이어졌다. 당시 전원 생존, 체력49/14/49이며 회복·상위 생산·원정·엔딩은 잔여다. 자세한 조건과 실패 이력은 [자연 진행 기록](NATURAL_FLOW_1115.md)을 따른다.

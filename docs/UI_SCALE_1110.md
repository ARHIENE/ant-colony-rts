# UI 배율 · 선택 표시 · 글자 정렬 재수정 (2026-11-10)

사용자 정정: 실제 화면은 시안과 여전히 차이가 크며, 현재 화면 비율에 맞게 UI 크기를 비례시키고 장수 선택 시 위에 뜨는 표시와 글자 정렬을 수정해 달라고 요청함.

## 확인한 원인과 수정

1. HUD는 매 프레임 배율을 바꾸지만 MenuTheme.Canvas로 만든 GameMenus/Notifications는 최초 생성 시 배율을 유지했다. 동일 화면에서 서로 다른 캔버스의 글자/패널 크기가 어긋났다. 모든 캔버스를 ScaleWithScreenSize, reference1440×900, Expand로 통일했다. 창 변경 시 메뉴·알림·HUD 모두 min(width/1440,height/900) 배율을 사용한다. 1배 미만도 축소한다. 픽셀 정렬을 켰다.
2. 여러 장수의 초상 줄은 y66, 명령칸은 높이96으로 겹쳐 있었다. 초상을 선택 카드 내부에 넣고, 선택 타이틀·초상·명령 줄을 분리했다. 단일/다중 선택 모두 하단 중앙에 머문다.
3. CommanderOverhead는 실제 모델 크기와 무관한 높이2.2m +34px 오프셋을 쓰고 겹치면38px씩 위로 쌓았다. 실제 렌더러 경계 바로 위에 이름을 표시한다. 비선택·건강한 평시 장수는 숨기고 부상/전투/기분 경고는 유지한다. 체력은 부상 시, 병력은 출전 시 표시한다. 작업 상세는 하단 선택창에서 확인한다.
4. 툴팁이 화면 상단 너비60% 영역에 표시되던 것을 해당 컨트롤 옆의320 기준px 이하 소형 패널로 변경했다. 화면 경계를 넘으면 아래쪽에 표시하고 좌우를 제한한다.

## 바꾼 것

- **카메라** (`Camera/IsometricCameraController.cs`)
  - 방향키 이동, 가운데 버튼 드래그 이동(잡은 지면이 커서에 붙어 따라옴).
  - 휠 한 칸 = 12% 고정 비율, 목표값으로 부드럽게 수렴, 커서가 가리키는 지점 기준 줌.
  - 줌·회전을 실제 시간 기준으로 바꿔 일시정지 중에도 동작. 메뉴·목록 위에서는 줌하지 않음.
- **효과음** (신규 `UI/GameFeel.cs`): 에셋 없이 실행 중 합성한 짧은 소리. 버튼 클릭/비활성 버튼, 선택, 이동 지시, 공격 지시, 피격, 완공, 적 경보. 음량은 기존 설정의 전체 음량을 따른다. 같은 소리는 최소 간격을 둬 겹쳐 울리지 않는다.
- **피해 숫자** (`GameFeel.Hit` ← `AntUnitBase.TakeDamage`, `CommanderAnt.TakeFormationDamage`, `WildMonster.TakeDamage`): 같은 대상이 0.3초 안에 받은 피해를 합쳐 한 번만 띄운다. 아군 피해는 붉은색, 적 피해는 밝은 노랑. 화면 밖 대상은 생략, 프레임당 최대 6개.
- **명령 확인**: 공격 지시·공격 이동 지점에 붉은 마커 + 지시음. 채집 불가 등 거부에는 거부음.
- **공격 이동 커서**: A를 누른 뒤 지점을 고르는 동안 붉은 조준 커서.
- **대형 방향**: 이동·공격 이동 도착 대형이 무리 중심→목적지 방향을 앞으로 본다.
- **선택 편의**: 장수 더블클릭 = 화면 안 같은 상태(출전/평시) 장수 전원 선택. Ctrl+A = 출전 장수 전원(없으면 본거지 장수 전원). 여러 명 선택 중 S = 출전 장수 전원 정지. Shift+숫자 = 현재 선택을 부대에 추가.

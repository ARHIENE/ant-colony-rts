## D02. 평가 별점·오차·내부 갱신

- 공통: 종합 현재 능력은 CA, 분야별은 **16개 기술 각각**, 잠재력은 공통 PA 하나만 평가한다. 숫자 CA/PA는 UI에 공개하지 않는다. 비교 모집단은 우리 성인 장수(포로·사망 제외, 원정 중 포함)이며 최초 1명일 때도 계산 가능하다.
- 종합·분야·잠재의 비교 기준 M은 각각 모집단의 실제 CA·해당 기본 기술·PA 중앙값이다. 분모 하한은 CA 32·기술 2·PA 40. 같은 기준을 내부·외부 인재에 적용한다. 잠재 별점은 총 성장 한도의 상대 평가이며 특정 분야 성장·도달 보장이 아니다.
- 별점 원값 `S=clamp(3+2×(평가값/M−1),1,5)`. 자기 세력 중앙값은 3점이며 1/5점에서 포화한다. 아래 간격으로 가장 가까운 값에 반올림한다(정확히 중간이면 위).
- `s=조사 기본 기술 0~20`. 현재 오차는 평가값에 곱하는 상대 오차, PA 오차는 내부 PA 단위다. 고정 편향 u∈[-1,1]를 평가자·대상·평가 지표별로 균등 분포에서 1회 뽑아 저장하고 `평가값=실제값+u×오차폭`으로 계산한다. 현재값은 0 이상, PA 추정은 대상 CA~200으로 제한한다. 주기 갱신·담당 교체 후 복귀·로드로 같은 평가 쌍을 재추첨하지 않는다.

## D03. 외부 조사 파견

- 공통: 평가자 1명 필수·호위 장수 0~1명 선택, 병력 없이도 도보 파견 가능. 기존 도보/차량/항공 이동·좌석·실물 식량 규칙을 재사용한다. 기술은 **조사 시간·인원수·이동 속도를 바꾸지 않는다**. 별도 스카우트 비용·시설 조건 없음. 보급 권장은 왕복 이동+현지 조사+예비 1일, 부족하면 경고 후 강행 가능하다.
- 집중은 지정 인재, 탐색은 그 세력의 미조사 인재를 중복 없이 무작위 선택한다. 남은 인재가 적어도 조사 시간은 동일하다. 후보가 0명이면 출발을 막는다. 1회 분량 전체 완료 후 귀환하며 본거지 도착 때만 보고한다.

## D04. 현대 진형 6종·연구·합산

- 공통: 평진·삼국지풍 7종 수치는 유지한다. 현대식은 각자 독립 연구, 해당 시대 연구소 외 추가 선행 없음. 아래 수치는 **장수 부대 능력 보정**이며 실제 병사 대형·측면 개체 배치를 만들지 않는다.
- 방향 판정: 부대의 마지막 유효 이동/공격 방향을 전방으로 저장한다. ‘전방 90° 안’은 방향차 ≤45°, 측후방은 방향차 >90°다. 범위 공격은 폭심을 출발점으로 사용하고 출발점 없는 지속 피해는 방향 판정에서 제외한다. 종대의 월드 이동 보정은 해당 장수가 도보 원정일 때만 적용하며 차량·항공 속도를 올리지 않는다.
- 철수 판정: 공격 목표를 해제한 직접 이동 중에만 적용한다(어택무브·공격 중 제외). 계속 공격은 같은 대상에게 일반 공격이 실제 적중한 시간/횟수이며 대상 변경·3초 무적중 시 누적을 지운다.

## D08. 지하 탐사기·탐사·매장량

- 공통: 탐사기는 장수 1명·전력 필요, 연구 기술 속도 배율 `0.6+0.04×연구`(0/10/20=0.6/1/1.4). 탐사기 중심의 범위 안 미조사 후보를 가까운 순→동거리 고정 지점 ID 순으로 조사한다. 작업 누적량은 정전·담당 교대 시 보존하며 시설 이동 시 이전 위치 조사 기록도 남는다.
- 매장층 위치·종류·수량은 새 게임 시드로 고정한다. 탐사·철거·재설치·로드로 재생하지 않는다. 후보 1곳 조사 완료 시 그곳만 공개하며 빈 후보면 ‘매장 없음’을 기록한다. 미조사 후보가 없으면 대기하고 상태를 표시한다. 여러 탐사기는 같은 후보를 중복 예약하지 않는다.

## D09. 자동 수송 최대 3거점 경유

- 공통: 편입 거점 **중복 없이 1~3곳** 지정, 본거지→각 경유지 최대 1회씩→본거지로 한 사이클. 본거지 하역 완료 후 60초 대기(기존 수송 효율 연구 시 30초)한다. 목적지 사이 이동은 기존 월드 이동 시간을 계산하고 순간 이동하지 않는다.
- 화물 여유 `F=용량−실물 화물 점유−미완료 적재 예약−아직 싣지 않은 필수 보급 예약`. 이미 실린 보급은 실물에 포함해 한 번만 센다. 자원·장비·시신은 같은 화물 환산을 사용하고 좌석은 별도다. 식량 소비·부패는 실제 화물 점유량에 반영한다.

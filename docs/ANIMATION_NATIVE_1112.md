# 원본 모션·장비·외형 검수 — 2026-11-12

Meshy의 원본 뼈대와 원본 클립을 직접 재생한다. 기존 공통 리그에 관절 회전을 재변환하던 방식은 이 경로에서 사용하지 않는다. 모든 colony commander에 적용한다. 내비게이션이 수평 이동을 소유하며, 원본 관절 동작과 수직 움직임은 유지한다.

## 적용 및 검증

- 수집119클립: 원본과 게임용 SourceParts 외형의 5시점씩 렌더 검토, 실제 Play 선택·표시·재생 검사 통과. 연속 전체프레임 무관통 보장은 아니다.
- Runtime35클립/51행동: AntVisual API 연결 검사 통과. 실제 이동, 무 수확, 야간수면, 돌채굴, 벌목, 점토채굴은 별도 실제 명령/시뮬레이션으로 확인했다.119개의 자연 발생 행동을 구현했다는 의미는 아니다.
- 원본 mesh rest bounds로 키1.6m 정규화.3장수×5모션 검증. 수면 바닥 오차-.007m, 사망 종단 바닥 오차0m.
- 원본 바디의 정점·가중치를 유지한 SourceParts. 머리6종/의상4색변형×2리그48조합 활성 선택 검사, 표정8채널 이름/가중치 동기화와 근접화면 확인. 머리는 휘어지는 긴 띠를 방지하기 위해 Head 단일가중치로 고정했다. 의상은 기존 앞치마·주머니 기하형상 재현이 아닌 원본 의상의 색변형이다. 흉터·눈색 기능을 추가하지 않았다.
- 이전 모듈 메시를 원본 뼈에 맞추던 후보는 경계 벌어짐으로 불합격. 게임 Resources에서 제외하고 work/animation-1112/rejected-appearance에 보존했다.
- 일회 동작 루프 정책을 수정해 사망/넘어짐/일어나기/앉기 전환 등의 되감김을 방지한다. 맥락이 없는 사다리/밧줄/의자 모션은 라이브러리에 보관한다.

## 장비

사용자가 승인한 곡괭이·도끼·망치의 머리/자루 끝 방향을 유지한다. 양손 자루 접점과 손가락을 보정하고 삽/괭이에도 적용했다. 사용자의 ‘없으면 지금처럼, 따로 만들지 말라’ 지시에 따라 벌목은 기존 Heavy_Hammer_Swing 내려치기를 유지한다.

활122자세: 화살선 머리 여유 최소.229m, 팔길이 보존, 발사 구간 표시 검사 통과. 총기에는 팔길이를 보존하는 양손 IK를 추가했다.10무기 미리보기에서 최대 보조손 오차.000036m, 팔길이 변화.000026m 미만. QuakeMaul 머리 두께를.65배로 줄여 얼굴 가림을 완화했다. 수치 검사는 표면 전체 무관통의 증거가 아니다.

도구 끝과 실제 자원 표면의 정밀 타격 접촉은 남아 있다. 요리·치료·톱질·창찌르기 등 적합한 수집 원본이 없는 기존 행동은 legacy를 유지한다. 이 한계를 숨기기 위해 무관한 프리셋을 연결하지 않았다.

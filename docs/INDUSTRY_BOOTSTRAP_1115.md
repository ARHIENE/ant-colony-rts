- 실제 기존 저장 로드 후 흙10 대기 청사진을 정상 취소하고 목재20 청사진을 배치했다. 자연 전투를 마친 뒤 목재 운반·시공으로 채석장을 완공했다(9370초 이전). 자원·체력 지급, 강제 완공, 적 약화 없음.

# 초반 식량·약품 생산 연결 — 2026-11-14

지난 3웨이브 검증에서 식량 고갈과 치료 재료 부족이 이어졌다. 후속 작업은 외형·적 제작 담당에게 Unity를 양도받아 진행했다. 적 수, 전투 수치, 생활 불만 수치, 생산 비용·수량은 바꾸지 않았다.

## 수정

- 조리식 전용 식단에서도 주문한 요리의 생식량 원료를 확보한다. 기존 계산은 날것을 먹을 사람만 세어, 조리 주문이 있어도 원료 확보 우선순위가 사라졌다. 다음 배치의 재료에서 조리대에 도착한 양을 뺀다. 중지·완료된 주문은 수요를 만들지 않는다.
- 약제대 비축 주문이 있으면 환자가 없는 동안에도 지정된 약초를 확보하고 재료 배송·제조를 이어간다. 비축 준비는 긴급 치료보다 낮은 우선순위다. 새 채집 지정이나 생산 주문을 자동으로 만들지 않으며, 사용자의 작업표·대상 우선순위가 먼저 적용된다.
- 허기가 있어도 실제로 먹을 음식이 없으면 운반물을 내려놓지 않는다. 기존에는 실패한 식사 재시도 주기마다 배송을 끊을 수 있었다. 허용된 음식이 준비되면 기존대로 식사를 우선하며 수면·위생 전환 조건도 유지한다.

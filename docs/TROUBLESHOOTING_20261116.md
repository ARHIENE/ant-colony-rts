# 2026-11-16 문제 해결 기록

사용자는 초반 3웨이브 반복이나 빌드 생성에서 멈추지 말고 새 게임부터 본선 엔딩까지 실제로 이어지는 게임을 구현하도록 요청했다. 이후 웨이브를 무조건 통과시키면 안 된다고 정정했고, 이번 SAVE에서는 성공한 검사와 실제 패배를 모두 보존한다. 아래는 11월 15~16일 작업 중 사용자 요청과 자연 진행에서 확인한 문제다.

## 몹이 죽을 때 단순히 뒤집히는 표현

요청은 "몹들 죽는 애니메이션이 너무 단순함. 지금 그냥 뒤집히는데 디테일좀 추가해줘"였다. 기존 뒤집기 대신 17종의 관절을 사용해 다리 지지 상실, 몸통과 머리의 지연 붕괴, 잔떨림과 정착을 2.6초에 걸쳐 표현했다. 무리 GPU 사망 표본도 다시 생성하고 사체 방향과 자세를 저장한다.

실제 치명 피해로 대표 몹과 무리 사체가 생성되는 경로, 최종 자세의 반복 적용, 전체 저장복원과 지면 접촉을 확인했다. 요청한 동작 변경은 적용했다. 전투 밸런스·사체 수량·수명은 유지했고 모든 카메라 구도에서의 품질 검증은 남아 있다.

## 날씨가 자연물에 반영되지 않음과 하얀 바닥

사용자는 돌 위 적설, 계절에 따른 잎색과 낙엽을 요청한 뒤 "바닥이 완전 하얘져서 바닥 분간이 안 됨"이라고 추가 지적했다. 자연물에 적설·융설·젖음·계절 잎색을 연결하고, 지면에는 눈 사이의 흙과 경사면을 남겼다. 바위 윗면과 바닥의 덮임을 다르게 표현하고 소나무는 상록수를 유지했다.

눈 누적과 비의 융설, 적설·젖음 저장복원, 강설·가을의 실제 Unity 화면을 확인했다. 처음 보정한 화면도 평평해 보여 덮임과 질감 크기를 다시 조정했다. 현재 수정은 적용됐지만 물리 적설 두께·발자국·별도 날씨 음향은 구현하지 않았다.

## 자원 고갈 뒤 공급과 채석장의 흙 선납 순환

"맵의 돌이 없어지면 못 캐는 것 아니냐"는 질문 뒤 사용자는 기술로 채석장·벌목장을 만들고 기본 시설에는 전력을 요구하지 말라고 지시했다. 다른 자원과 미정 고급 광물도 실제 게임으로 구현하도록 승인했다. 지속 생산 시설 7종과 기술·주문·작업·운반을 연결했다.

후속 자연 진행에서는 본거지에 흙 노드가 없는데 채석장 건설과 이를 여는 연구가 먼저 흙을 요구했다. 기본 채석장·벌목장은 목재 20으로 만들고 첫 생산 연구에서만 흙 비용을 제거했다. 식량·연구 작업과 실제 생산 과정, 기존 청사진 납품은 유지했다. 자연 저장에서 재건·흙 생산·입고와 작업 중 재로드를 확인했고 관련 경제·표시·소유권 검사 10개를 통과했다. 초기 공급 순환은 수정했으며 시설 파괴와 인력·식량·물 부족으로 인한 장기 경제 문제는 남아 있다.

## 본선·원정의 실제 진행과 보이지 않는 외형

사용자는 본선과 원정부터 엔딩까지 연결하고 미연결 에셋을 실제 기능에 쓰도록 요청했다. 본선 카메라의 본거지용 여백 때문에 전투 대상이 화면 밖으로 밀리고, 원군은 출발 위치와 가깝다는 이유로 즉시 복귀 완료 처리됐다. 별도 본선 카메라 범위를 적용하고 이동·전투 중 원군은 해산하지 않게 수정했다. 숨김 외형의 빈 렌더러 집합 예외와 복제 시 보스 모델이 계속 숨겨지는 문제도 고쳤다.

본선 저장복원·일반 공격·왕복·재출전·승리 판정, 원군 약 115.9m 실제 왕복과 민간 작업 복귀를 확인했다. 보스 체력과 기존 공격 규칙은 유지했다. 후반 기능 검사는 통과했지만 정상 경제 완주와 보스 난도 검증은 미완료다.

## 장수 상실 뒤 원정 화물 때문에 저장 실패

자연 원정 8,094.2초 부근에서 마지막 승무원이 탈주한 뒤 화물 12가 남았다. 감소한 운반 용량을 기존 화물에 즉시 적용하면서 저장 검사가 실패했다. 사용자 전체 진행·저장 연결 요청의 후속으로 기존 화물을 보존하도록 검증을 수정했다. 새 적재 용량 제한과 살아 있는 귀환 운반자 조건은 유지한다. 손수레 화물 80 경계도 확인했다. 장수가 사라진 결과 자체를 취소하거나 화물을 무료 귀환시키지 않았다.

## 바닥에 음식이 있어도 굶주림과 탈주가 발생

운영을 실제로 다듬으라는 요청에 따라 자연 진행을 확인하는 중, 바닥 식사 접근 누락과 위생 때문에 운반 화물을 반복 내려놓는 문제가 드러났다. 실제 식단·이동 가능 조건에 따라 바닥 음식을 먹도록 하고 운반 입고 후 위생을 처리하게 했다. 바닥 요리 한 끼 소비와 식사 중 저장복원을 확인했다.

별도 회차에서는 식량 부족으로 두 명이 떠났는데 UI는 장기 불만의 300초 조건만 보여 줬다. 포만 25 이하의 조기 기아 경고와 실제 굶주림 이탈 조건을 추가했고 자동정지 설정·식사 접근·중복 억제·표시 9검사를 통과했다. 이탈 규칙은 바꾸지 않았다. 자연 진행의 식량·급수 안정화는 아직 실패이며 경고 추가를 경제 문제 해결로 기록하지 않는다.

## 안개 밖에서 맞은 적이 표적 없이 정지

13웨이브 10,452.8초 저장에서 적 16호스트가 본거지 중앙에 멈추고 마지막 활 장수에게 피해만 받았다. "웨이브가 무조건 통과하면 안 된다"는 기준에 따라 이 상태를 성공으로 처리하지 않았다. 실제 피해를 받은 표적 없는 적이 피격 출발점을 10초 탐색하도록 연결하고 그 상태를 저장한다.

피해 없음·실제 피해·시야 밖 표적 비지정·지상 접근·잘못된 좌표 거부·전체 저장복원 등 11검사를 통과했다. 같은 저장을 이어가자 적이 실제로 추격했고 10,491.4초에 패배했다. 피격 반응 결함은 수정했으며 웨이브 체력·피해·승리 조건은 유지했다.

## 지붕 높이·가구 접근·Meshy 화재 표시

미연결 에셋과 게임 전체를 가다듬으라는 요청을 따라 확인했다. 자동 지붕은 월드 높이 2.6에 고정돼 높이 약 10의 본거지 땅속에 생겼다. 벽과 지면 상단으로 높이를 계산하고 Meshy 초가지붕을 연결했다. 직사각형·불규칙 방, 저장복원과 벽 개방 후 지붕 제거를 검사했다.

목재 가구 모델 선택과 읽을 수 없는 메시의 경계 계산을 보완하고, 중앙 작업 지점이 밀리면 앞쪽 가장자리 좌우 지점을 쓰게 했다. 독서·톱질·판재 생산과 운반을 확인했다. Meshy 시설에서는 이전 렌더러 착색만으로 화재가 보이지 않아 별도 불꽃과 경고를 추가하고 소화·저장복원을 확인했다. 요청 범위의 연결은 적용했지만 모든 장비·자세 관통 검증은 남아 있다.

## 저장 경계와 씬 누락 참조

카메라의 실제 최소 줌 5가 저장 허용 8~35 밖이라 정상 화면에서도 저장을 거부할 수 있었다. 범위를 5~35로 맞추고 최소 줌에서 전체 저장복원을 확인했다. 음주 중 재로드 취소, 수원 등록 누락, 건설 주문 ID 재사용도 후속 저장 검사에서 수정했다. 수원 복원은 기존 체력을 보존하며 새 자원을 지급하는 방식으로 처리하지 않았다.

씬의 TerrainGenerator 두 오브젝트에서 누락 참조를 각각 하나 제거했다. 씬을 백업한 뒤 Unity API로 제거하고 정상 Transform 55개·컴포넌트 268개, 실제 이동과 기존 저장 재로드를 확인했다. 기존 빌드의 경고 528개가 모두 해소됐다는 뜻은 아니다.

최신 6웨이브 저장의 전체 재로드는 CLI 65초 제한 후 실제 복원이 끝났고 정상 재저장도 성공했다. 핵심 장수·재고·시설·작물 상태는 유지했지만 난수·일부 엔트리와 식별자·착지 높이·카메라 차이는 남았다. 전체 JSON 일치와 결정적 재현은 미검증으로 남긴다.

## 검증 도구의 실패는 별도 취급

날씨 촬영에서 시간을 뒤로 돌려 발생한 RocketEconomy 예외, 허용하지 않는 속도 4와 줌 값을 사용한 검사 저장 거부, 오래된 어셈블리·초기 로딩 중 명령·잘못된 슬롯을 사용한 검사 실패는 초기 기록을 보존했다. 게임 승리 조건이나 검증기를 느슨하게 하지 않고 검사 입력과 대기 조건을 수정했다. 자연 진행의 성공 횟수에 합산하지 않는다.

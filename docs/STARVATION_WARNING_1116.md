# 굶주림 이탈 사전 경고

자연 생산 검수의 별도 회차에서 장수2명이 포만0·먹을 음식 없음으로 이탈했다. 기분 알림은 장기 불만300초만 표시했으나, 실제 UpkeepManager에는 별도의 굶주림 이탈 판정이 있었다. 표시 누락을 수정했으며 이탈·기아 피해·소비 규칙은 유지했다.

- 포만25 이하이며 개인 식량·현재 식사·식단에 맞고 접근 가능한 음식이 없으면 위기 알림을 표시한다. 실제 기아 판정과 식사 접근 조건을 공유한다.
- 기존 위협 자동 일시정지 설정을 따른다. 설정을 끄면 알림만 남는다. 같은 위기를 매번 중복 등록하지 않으며 음식 확보 후 해제된다.
- 장수 상세에 장기 불만 시간과 굶주림 이탈 조건을 분리해서 표시했다.
- 격리 검사9개 통과: 경고 경계, 실제 바닥 음식·받은 식사, 자동정지 설정, 중복, 텍스트 높이, 읽기 전용 표시. 캡처를 직접 확인했다. `work/starvation-warning-1116/checks.txt`, `departure-detail.png`.
- 검사 중 일시 변경한 음식·포만·설정은 복원하고 자연3689.5초 저장을 전체 재로드했다. 앞선2명 이탈과1명 잔류 결과는 보존했다. 자연 완주는 아직 미완이다.

별도 회차3225.98→3689.5초에서 채석장·우물·추가 재배지2개가 정상 완공되고 실제 물 생산·운반·급수·성장이 진행됐다. 추가 재배지2개는 미완공, 첫 수확 전 식량 부족과 이탈이 발생했다. 운영 안정화 성공으로 기록하지 않는다. 검증 스크립트가 지원하지 않는4배속을 지정해 저장이 한 번 거절됐으며, 정상3배속으로 되돌려 저장하고 스크립트 입력 검사를1/2/3/5로 제한했다. 이 실패는 제품의 저장 검증 우회로 처리하지 않았다.

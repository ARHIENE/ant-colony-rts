## 저장·구저장

- 새 저장 상태 없음. 관계+2는 기존 `CommanderPersonalState.relations`, 문턱 사건은 `CampaignHistory.State`를 사용한다. `SaveDtos.CommanderDto.personalState` → `SaveSnapshot.CapturePersonalState/RestorePersonalState` → `SavePreflight`의 기존 개인 상태 검사를 재사용한다.
- 회복 유예·다음 준비·회복 예상·작업표 설명은 현재 상태에서 계산한다. 구저장에 기본값을 삽입할 신규 필드가 없고 저장24 유지. 기존 저장의 완료·결제·관계값·수술 진행량을 다시 지급하거나 초기화하지 않는다.
- 의료 작업 자체의 저장 중단 정책과 자동 저장 경계는 기존 Save 경로를 유지한다. 새 유예 시계나 담당자 저장 키는 만들지 않았다. 실제 저장 왕복은 Claude 실행 잔여.
- 관계 보너스는 성공 처리에만 지급한다. 반복 급식/부상으로 관계를 인위적으로 올리는 장기 악용성은 플레이 관찰 잔여이며 별도 영구 보상·무료 재료는 없다.

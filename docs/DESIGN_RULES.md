## 2. 금지 (택소노미 → 이 게임에서의 의미)

- 색: 그라디언트·글로우·네온 테두리, 의미 없는 다색 칩, 초록/보라 단색 강조 회귀. 표면은 중성, 색은 상태·선택·경고에만.
- 표면: 반투명 유리 패널, 모든 요소의 소프트 섀도, 저대비 본문(본문 대비 4.5:1 이상).
- 글자: 대문자 영어 라벨, 극단 위계(거대 숫자+작은 설명), 장식 이탤릭. 등급은 문자(다이아·골드·실버·레드)로, 보석 아이콘 장식 금지.
- 구조: 카드 안의 카드 중첩, 카드 왼쪽 컬러 띠, 아이콘 위 3열 카드 반복, 의미 없는 지표 배너, 장식용 상태 점, 모두 같은 크기·라운드.
- 버튼: 동작하지 않는 버튼(미구현이면 비활성 + 이유 툴팁), 이모지 아이콘 메뉴.
- 문구: 막연한 포부형 문장, 상투어, 3개씩 나열 습관, em-dash 남발, 번역투("~를 통해", "~에 대한", "~하는 것이 가능"), 책임 회피형 문장. 상태는 사실로: "재료 부족 — 목재 4/10"처럼 숫자와 원인.
- 모션: 이유 없는 페이드인·흔들림. 허용: 선택·눌림 피드백(80~150ms), 진행 막대.

## 3. 해야 할 것

- 행 구분(얇은 선)으로 목록을 나누고, 탭은 밑줄로 선택 표시.
- 한 창에 주 행동은 하나(accent 버튼), 나머지는 평면 버튼.
- 대기·불가 사유를 행 옆에 짧게 표시하고 위치 이동 버튼 제공.
- 눌림·포커스·호버 상태를 모든 버튼에 둔다.
- 구현 후 1920×1080·1280×720 캡처를 V6 참조(Temp/v6ref)와 나란히 보고, 넘침·겹침·대비를 확인한다.

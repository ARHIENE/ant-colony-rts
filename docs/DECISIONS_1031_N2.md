# N2 결정 — 2026-10-31

사용자 지시에 따라 선택이 필요한 사항은 추천안을 자동 선택했다.

1. 세력은 우리 `[=]`, 동맹 `[+]`, 중립 `[-]`, 적 `[!]`, 반란 `[X]`로 구분한다. 적·반란은 미니맵 적장수와 같은 회전 사각형(45도 마름모), 나머지는 사각형이다. 기존 C/B/R/T 거점 종류와 세력 색은 유지한다.
2. 판정 우선순위는 편입=우리 → 소유 문명의 반란/전쟁/유효 동맹/중립이다. 무소속은 미정리 정착지·보스·교역소 및 상실 거점을 적, 자원지·빈 현장·정리된 거점을 중립으로 표시한다. 단순 호감이나 교역 협정은 동맹으로 간주하지 않는다. 동맹 만료는 기존 HasTreaty 시각을 따른다.
3. 위험도는 기호 수가 과도하게 늘지 않도록 `D1`, `D2`, `D3`, `D4+`의 실제 숫자로 표시한다(4 이상도 D5 등 원래 값 보존). 범례에 1 쉬움/2 보통/3 어려움/4 이상 매우 어려움을 제공한다. 공격·상실·포기는 ATK/LOST/OFF 문자도 표시한다.
4. 배치는 기존 큐브 윗면에 흰 두 선으로 가능 `+`, 불가 `X`를 표시한다. 단일·건물 이동·연속 배치의 기존 preview 경로를 재사용한다. 새 그래픽 에셋/셰이더/설정 토글은 추가하지 않는다. 연속 배치 복제 시 기존 선을 재사용한다.
5. AntVisual 유닛은 기존 선택 원형 링 두께 .055→.13을 재사용한다. 해당 표시가 없는 건물·기본 모델에만 .16m 흰 사각 외곽을 표시한다. 기존 선택 색/선택 로직/클릭 범위/충돌은 유지한다. 월드맵 선택은 기존 확장된 외곽 프레임을 유지한다.
6. 범례는 월드맵 범례·마커 툴팁, 배치/선택 설명은 설정→조작에 제공한다. 항상 색 외 단서를 표시하여 접근성 옵션을 찾아 켤 필요가 없게 한다.
7. 신규 필드는 일시적인 렌더링 참조/표시 상태뿐이다. Save DTO/저장 경로/저장 버전(24)은 변경하지 않는다. JsonUtility null 중첩 객체 비교도 추가하지 않는다.
8. 원본은 컴파일 참조/패키지 소스 읽기만 허용하고 사본/산출물은 N2 Temp에 둔다. Unity·캡처·커밋·Notion은 실행하지 않는다. N1 지하 광층·작업 배정 파일은 수정하지 않는다.

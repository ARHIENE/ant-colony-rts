## 1. 사건 감독 규칙(잠정, 사용자 미확인)
- 상태: 위태(본거지 장수 절반 이상 부상/쓰러짐, 또는 1일 이후 식량 < 장수×5) / 번성(부상 0·식량 ≥ 장수×30·4일 이후) / 보통.
- 습격 간격 배수: 위태 1.6(늦춤), 번성 0.8(당김). 사건 위기 확률: 위태 ×0.35, 번성 +0.15(상한 1).
- 큰 위기(습격·재해) 뒤 180초 동안 새 위기 보류(숨 쉴 틈). 보류 중 습격 차례가 오면 30초씩 미룸.
- 첫날 밤 유예: 게임 첫날(Day 0) 밤 포식자 없음(캡처에서 침대·식량 0인 첫 밤에 "적 2" 확인 → 억울한 위기). 첫 포식자는 다음 계절 첫 밤.
- 새 사건·새 저장 필드 없음. 불러오기 후 휴식 타이머는 초기화(ponytail: 저장 필요 시 SaveDtos에 lastCrisisAt 추가).

## 4. 손맛 수치(잠정)
- 완공: 크기 +12% 튀김 0.32초, 원형 먼지 28개 0.7초. 입고: "+N 자원" 1.1초 동안 36px 상승, 동시 최대 24개. 피격: 모델 +14% 0.16초.
- 효과음은 오디오 자산이 없어 미구현.

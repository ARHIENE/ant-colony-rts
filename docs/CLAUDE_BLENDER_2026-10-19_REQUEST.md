## 3. 조합형 장비와 작업 도구

### 장착 부품

- 기본 투구/모자는 얼굴과 표정이 보이는 개방형으로 제작합니다.

- 기존 머리카락은 가려지는 부분만 선택적으로 숨기거나 착용용 파생 부품으로 처리하세요. 귀·꼬리는 그대로 유지합니다.
- 투구의 구멍 위치가 안 맞으면 귀 유형에 따른 장착용 변형을 사용하고 호환표에 기록하세요. 하나의 구멍으로 모든 귀를 지원했다고 주장하지 마세요.
- 귀·꼬리·머리·표정·장비는 교체 가능한 분리 메시여야 합니다. 검수용 조립 캐릭터와 실제 납품 부품을 구분하세요.
- 얼굴 전체를 덮는 투구는 이번 필수 제작에서 제외합니다. 별도 장비로 추후 검토합니다.

### 무기·도구의 재질 단계

- 기존 무기 계열을 보존하고, 근접 무기·금속 갑옷·투구·도구에 적용 가능한 재질 변형을 준비하세요.
- 구리 → 청동 → 철 → 강철 → 티타늄 합금 → 성휘합금(가칭).
- 곡괭이·도끼·삽·망치·괭이·낫은 돌 단계와 위 금속 단계를 표현할 수 있게 합니다. 돌머리가 부적합한 구조는 목재/돌 결합으로 설계하고 미리보기에서 설명하세요.
- 형상을 공유할 수 있는 단계는 재질·날/머리 부품 변형을 재사용하세요. 각 단계가 작은 화면에서도 구분되도록 실루엣·색·보강부에 차이를 주되 단계마다 전체 캐릭터를 복제하지 않습니다.
- 금·은은 장식·교역 재료이며 장비 강화 단계에 끼워 넣지 않습니다.
- 도끼날·망치머리·곡괭이머리는 자루 끝의 올바른 위치에 배치합니다. 긴 창은 손잡이 기준 원점을 맞춰 공중에 뜨지 않게 하세요.
- 기존 산 분사기·방패·지휘 신호기·비행 장비는 별도 기능을 유지합니다. 모든 장비가 구리검의 구조를 따른다고 임의 변경하지 마세요.

### 강체·접촉 필수 조건

- **장비가 손에서 떨어져 떠 있으면 실패입니다.**
- 손가락이 손잡이를 감싸고, 손잡이와 손바닥 접촉은 움직이는 내내 유지되어야 합니다.
- 허리·등의 무기는 칼집·고리·끈 등 고정부가 실제로 보이도록 합니다.
- 걷기·달리기·회전·작업·공격 중 무기와 갑옷이 팔·다리·몸·옷·머리·귀·꼬리를 관통하지 않게 하세요.
- **무기·도구·단단한 갑옷 판은 휘거나 꺾이지 않습니다.** 강체 부품은 소켓/단일 뼈를 따르고, 관절 갑옷은 분리 판으로 움직입니다. 금속 전체를 부드럽게 스키닝해 굽히지 마세요.
- 천옷·끈 등의 연성 부품과 강체 부품을 구분합니다.
- 손목·팔꿈치를 비정상적으로 꺾어 접촉을 맞추지 않습니다. 필요하면 자세·장착 위치·작업 위치를 함께 조정하세요.

### 재료 단계·품질·초기 밸런스
- 장비 금속은 구리→청동→철→강철→티타늄 합금→성휘합금 순으로 상승한다. 금·은은 장식·교역 재료이며 이 강화 단계에서 제외한다.
- 같은 품질의 상위 재료 장비는 공격/방어·작업 효율·내구도가 상승한다. 티타늄 합금은 경량 고급 장비다. 잘 만든 하위 장비가 조잡한 바로 위 단계보다 좋을 수 있지만 채굴 등급은 재료 단계에 고정한다.
- 기존 장비를 상위 금속으로 즉시 변환하지 않고 새로 제작한다. 하위 재료도 전선·시설·부품·합금·보수에 계속 사용한다.
- 산업 시설은 열전도·단열·내열·미관 등 용도 차이를 유지한다. 초반부터 복잡한 열 관리를 강요하지 않고 고온 산업부터 중요하게 한다. 별도 스트레스 수치는 도입하지 않는다.

- 식품은 1인분의 영양량, 액체·기체는 용량 기준으로 산출·소비를 계산한다. 단순 가공은 짧게, 장비 제작은 길게, 발효는 무인 시간 경과로 진행한다. 정확한 시간·전력·재료량·희귀도·성휘합금 배합은 미정이다.

## 부록 B. 장비·수리 규칙 참고

### 장비 외형·장착·도구 — 2026-10-19 확정
- 개미 신체 대신 사람 형태의 두 팔·두 다리와 조합형 머리·얼굴·귀·꼬리를 사용한다. 시민/장수의 기존 역할은 유지하며 모든 시민을 개별 장수로 바꾸지 않는다.

- 무기는 평소 허리·등의 칼집·고리·끈에 실제로 부착하고 전투 때 손에 든다. 작업 도구는 해당 작업 중에만 손에 표시하고 평소 숨기되 실물 소유·내구도는 유지한다.
- 손가락이 손잡이를 감싸며 이동·회전·작업·공격 중 장비가 뜨거나 몸·옷·귀·꼬리를 관통하지 않아야 한다. 단단한 무기·도구·갑옷은 휘거나 꺾이지 않고, 팔·손목도 비정상적으로 꺾이지 않게 한다. 정지 화면뿐 아니라 각 외형 조합의 실제 동작을 검수한다.

- 쓰러지면 장착 무기는 현장에 떨어지고 옷·갑옷은 몸에 남는다. 회복 후 무기 자동 회수는 없고 유저 장착 지시가 필요하다. 내 영토 사망 장비는 현장 회수, 원정 사망·포획 장비 압수는 기존 규칙 유지.

- 일반 교체는 장비 위치까지 가서 착용하고 벗은 장비는 바닥에 내려놓는다. 소집 중 자동 재장착을 위해 전투를 이탈하지 않는다.
### 내구도·수리 — 2026-10-19 확정
- 옷은 착용 중 서서히 닳고 갑옷은 피격으로도 손상된다. 도구는 사용으로 닳는다. 무기를 포함한 장비 내구도 소모 계수는 추후 조정한다. 내구도 0이면 파괴·소실하며 착용자·장비명을 오른쪽에 알린다.
- 파괴 전 주요 제작 재료와 작업 시간으로 수리한다. 수리량에 비례해 최대 내구도가 감소하고 현재 내구도는 감소한 최대치까지 회복한다. 품질은 유지한다. 같은 손상량을 나눠 수리해도 총손실이 같아야 한다.
- 제작 능력이 높을수록 수리 속도가 빠르고 재료 소모·최대 내구도 손실이 적다. 수리마다 담당자를 지정하며 식사·휴식·부상·포로 등으로 이탈하면 일시정지한다. 자동 교대는 없다.
- 유저는 담당자를 언제든 변경 가능. 변경 전 남은 작업의 재료량·예상 최대 내구도 손실을 새 담당자 기준으로 표시하고 적용한다. 각자가 실제 수행한 수리량·소모 재료·발생한 손실은 유지하며 마지막 담당자로 전체 결과를 다시 계산하지 않는다.

- 무기·금속 갑옷은 대장간, 천옷·가죽옷은 재봉 작업대 등 해당 제작 시설의 제작 대기열을 함께 사용하고 순서를 조절한다. 재료 부족/착용자 소집 중이면 대기하고 뒤의 가능한 작업을 진행한다.
- 모든 필요 재료와 실제 작업 차례가 확보될 때까지 장비를 계속 사용한다. 시작 시점 손상량으로 소모량을 재계산·표시하고 확보 후 시작한다. 착용자가 작업대에 장비를 벗어 놓고 제작 담당자가 수리한다. 장비·재료는 예약해 중복 사용을 막는다.
- 수리 중 장비는 사용 불가. 임시 장비는 유저가 직접 지정한다. 완료 후 무기·옷·갑옷 모두 원래 착용자가 자동으로 다시 장착하며 소집 중이면 해제 후 수행한다. 임시 장비는 바닥에 내려놓는다. 이는 쓰러져 떨어뜨린 무기의 수동 회수와 구분한다.
- 완료품은 작업대 옆 바닥에 두고 다음 제작을 진행한다. 원래 착용자 예약은 유지하며 다른 장수가 가져가지 못한다. 착용자 없는 바닥·창고 장비는 운반 담당자가 맡기고 완료 후 일반 보관 대상으로 처리한다.
- 취소해도 완료된 수리·최대 내구도 감소·재료 소모는 유지하고 미사용 재료 예약을 해제한다. 맡긴 장비는 현재 상태로 원래 착용자가 회수·재장착하며 소집 중이면 해제 후 수행한다.
- 수리 완료 알림은 착용자·장비명을 표시하고 클릭 시 장비 위치로 이동한다. 화면에 담당자·진행도·필요 재료·현재/수리 가능한 최대/원래 최대 내구도·예상 결과·대기 사유를 표시한다.
- 다른 장수에게 장착 지시하면 기존 수리·착용자 예약을 취소하고 새 지시를 따른다. 이미 진행한 수리와 소모는 유지한다. 원래 착용자 사망·이탈 시 수리는 계속하되 예약 해제 후 일반 보관한다.
- 장비 소실 시 요청 취소·미사용 재료 예약 해제·알림. 작업대 철거·파괴 시 장비와 남은 재료는 바닥에 남고 진행도 보존·중단. 유저가 새 작업대를 지정하면 기존 담당자·진행도로 재개한다.
- 최대 내구도가 낮다는 이유만으로 수리를 금지하지 않는다. 예상 결과를 보여주되 수리 후 현재 내구도가 증가하지 않는 경우만 시작 불가다.

- 지표 광맥은 칸별 채굴 지정→장수 작업→해당 부분 소멸→바닥 자원→운반 순서다. 진행도는 중단해도 보존하며 다른 장수가 이어 캘 수 있다.
- 돌 이상 도구: 일반 석재·석탄·구리·주석. 청동 이상: 철·은·금. 강철 이상: 티타늄. 티타늄 합금 이상: 성휘석. 구리·철 도구는 주로 속도·내구도 향상 단계다.
- 모래·점토는 삽으로 채취하되 재질 등급 제한은 없다. 열매·버섯 등 맨손 채집은 도구 불필요. 광물 외 벌목·농사·건설에는 우선 재질별 작업 제한을 두지 않는다.
- 도구 등급은 채굴 가능 대상을, 성능·품질과 채굴 작업 능력은 속도를 결정한다. 숙련도·도구와 무관하게 광맥 산출량은 동일하다. 채굴 능력이 도구 등급을 우회하지 않는다. 기존 기술 체계에 새 기술을 임의 추가하지 않으며 채굴 작업의 능력 연결은 기존 채집 체계와 조정한다.
- 도구가 파괴되면 중단·오른쪽 알림 후 새 도구 지정을 기다린다. 미보유·등급 부족도 사유 표시.
- 지표 광맥·기름이 배어 나오는 땅·가스가 새는 틈으로 매장 흔적을 확인한다. 기존 로컬 맵 전체 공개·안개 없음은 유지한다. 지하 화면이나 이동 가능한 지하층은 추가하지 않는다.
- 깊은 매장층은 연구로 해금하는 지하 탐사기에서 전력과 장수 작업으로 발견한다. 연구 능력이 탐사 속도에 영향. 자원 종류·위치·매장량을 오른쪽에 알리고 발견 기록은 정전 후에도 남는다.
- 자원 보기/채굴기 선택/배치 화면에서 발견한 매장 범위를 강조하고 필요한 시설을 표시한다. 심층 채굴기는 작업자·전력이 필요하고 기계 등급에도 채굴 단계 제한을 적용한다.
- 원유·가스는 매장 지점 위에 시추기·추출기를 설치한다. 전력으로 자동 추출하며 장수는 건설·수리를 맡는다. 설치 전 매장량·기본 속도·전력 표시. 채취 시설은 매장 지점당 하나를 기본으로 하며 심층 광맥의 칸별 처리 범위 수치는 별도 조정한다.
- 매장량은 유한하고 철거·재설치로 초기화되지 않는다. 고갈 시 알림, 시설 자동 철거 없음. 지점은 고갈 표시하며 새 추출 시설 설치 불가. 채굴기는 다른 지점으로 옮겨 사용할 수 있다.
### 원유·가스·연료
- 원유는 액체 배관, 천연가스는 기체 배관으로 운송한다. 탱크 하나는 내용물 한 종류를 보관한다. 전력·배출 공간 부족/탱크 가득 참/배관 막힘이면 추출 정지하며 생산물을 삭제하지 않는다.
- 정제소·발전기는 배관으로 공급받는다. 배관 단절 시 신규 공급은 중지하지만 시설 내부에 이미 공급된 물량은 사용한다.
- 교역·원정 화물은 원유 드럼통·가스 압축 용기로 충전해 운반한다. 전용 충전·배출 설비와 작업자를 사용하고 빈 용기는 재사용한다.
- 정유소는 원유→정제 연료, 화학 작업대는 별도 제조법으로 원유→플라스틱을 생산한다. 전력·작업자가 필요하고 재료·출력 공간 부족이면 정지한다.
- 천연가스는 발전·산업 시설에 직접 사용한다. 고체 연료 사용 시설은 목재·숯·석탄 중 허용 연료를 설정한다. 연료별 가동 효율을 표시한다.
- 배관·탱크 파괴 시 유체 유출·회수의 세부 동작은 미정이며 고체처럼 바닥 아이템이 된다고 확정하지 않는다.
### 술·양조·증류
- 맥주(보리·밀), 쌀술(쌀), 과실주(포도·사과·열매 등), 벌꿀주(꿀), 감로주(감로), 증류주(곡물·감자 등 발효 후 증류)를 만든다.
- 양조통은 묶음당 한 종류를 발효한다. 제조법별 허용 원료를 설정하고 발효 시작 후 재료 추가는 불가하다.
- 재료 투입·회수만 장수가 수행하고 발효는 시간 경과로 진행한다. 발효 중 취소하면 투입 재료를 회수하지 못하며 시작 전에 알린다.
- 증류기는 완성 발효주를 연료·작업 시간을 들여 증류한다. 숙성의 추가 효과·정확한 도수와 발효 시간은 미정.
- 음주는 여가 행동이며 일시적 기분 상승과 취기에 따른 능력 저하가 있다. 장수별 금지/허용·음주 간격, 어린 캐릭터 금지를 적용한다. 알코올 의존·술에 약함/강함·금단·만취·숙취 규칙은 장수 문서를 따른다.

### 음주 특성·취기 — 2026-10-19 확정
- 일반 장수는 음주 허용/금지·간격을 따르며 소집 중 음주하러 가지 않는다. 어린 캐릭터는 음주 불가다.
- 알코올 의존: 처음부터 보유하거나 반복 과음으로 후천 발생 가능. 오래 못 마시면 충동이 생겨 소집·작업 명령과 음주 금지를 무시하고 술을 찾을 수 있다. 이탈 시 이름·사유를 오른쪽에 알린다.
- 술을 못 구하면 금단으로 기분·작업 능력이 떨어진다. 술을 발견하는 것만으로 해소되지 않고 실제로 마셔야 충동·금단이 가라앉는다. 음주 후 소집 유지 시 전투 명령, 아니면 일반 행동으로 복귀한다.
- 술에 약함: 같은 양에 더 빨리·심하게 취하고 적은 양으로도 이동·작업·전투 능력이 저하될 수 있다. 의존과 별개이며 명령 불복종을 직접 유발하지 않는다. 의존과 동시 보유 가능.
- 술에 강함: 같은 양에 덜 취한다. 술에 약함과 동시 보유 불가이며 의존 면역을 뜻하지 않는다.
- 취기는 도수·음주량에 따라 누적되고 시간 경과로 감소한다. 만취하면 비틀거리거나 쓰러져 행동 불가, 과음 후 숙취는 일정 시간 기분·작업 능력을 낮춘다. 취기·숙취·금단을 상태창에서 구분한다.
- 특성 등급·정확한 충동 간격·도수·금단 수치·의존 치료/회복은 미정이다. 기존 특성 슬롯 체계는 유지한다.

# 2026-11-14 직접 작업·1인 운영 검증

## 오늘 추가 기획과 담당 범위

Notion 기획 본문·자동 작업·장수·건물·원정 문서를 확인했다. 평시 직접 지휘, 1인 시작 가능, 고립된 부족 배경, 본선 보스 처치와 지구 귀환을 최신 방향에 반영했다. 이 문서에 적은 구현은 직접 작업과 초기 운영 검증에 한정된다. 외계 무인기 연출·본선 전투·원정 호위가 구현됐다는 의미는 아니다.

외형 채팅은 art/work의 tribal 에셋 범위만 작업하며 Unity 사용을 양도했다. 본 작업은 직접 명령·연구 배정·시작 인원 저장을 수정했다. 외형·장비·가구의 다른 변경은 보존했다.

## 수정 내용

- 자원 한 개에 우클릭하면 채집·운반을 직접 지시한다. 진행 중 건설에서도 전환한다. 작업 금지·도구·연구·경로를 먼저 검사해 거절된 명령이 기존 작업·화물을 바꾸지 않도록 했다.
- 건설 예정지 우클릭은 기존 채집을 마냥 기다리지 않고 건설·재료 반입으로 전환한다. 건설 진행과 이미 반입한 재료는 보존한다.
- 연구 화면의 직접 배정은 일반 운반·건설도 중단해 전환할 수 있다. 도달 불가·연구 금지·필수 생활 중인 장수는 기존 작업을 유지한다. 연구 자체를 자동 선택하거나 생활 중 배정을 예약하는 기능은 넣지 않았다.
- 새 저장에 시작 장수 수를 기록한다. 값이 없는 구 저장은 종전 3명 기준을 유지한다. 현재 생존자 수를 시작 인원으로 추정하지 않는다.
- 야행성 포식자도 진행 중 웨이브와 사건 감독의 회복 유예를 따르도록 했다. 방어 후 180게임초의 유예는 저장된 평화 잔여시간으로 판정해 재로드해도 유지한다. 평화 900/600초와 웨이브 적 규모는 바꾸지 않았다.
- 배고픈 장수의 식사 처리가 수면 종료보다 먼저 반환해 아침에도 침대에 붙잡히던 순서를 수정했다. 수면 시간이 끝났다면 식사 이동 전에 기존 수면 종료 처리를 호출한다. 모션·침대 접점 코드는 변경하지 않았다.

## 확인한 결과

- Unity 재컴파일 오류 0.
- 직접 작업 격리 검사 18건 통과: 실제 우클릭 raycast 진입, 채집↔건설 전환, 지정 대상 한정, 금지·도구·경로 거절, 화물 8개 보존과 건설 자재 보존.
- 연구 전환 격리 검사 7건 통과: 도달 불가·금지 시 작업 유지, 운반에서 연구 전환, 화물 정확히 8개 보존.
- 위 격리 검사는 상태를 주입한 회귀 검사다. 자연 플레이 성과로 집계하지 않는다. 연구 검사 첫 실행의 누락 Collider는 검사 스크립트 오류였으며 보완 후 다시 실행했다.

## 1인 자연 플레이에서 드러난 문제

소형 숲, seed 261106, 1명, 정상 비용·이동·생활 규칙으로 진행했다. 공식 CLI 검사 스크립트가 정상 게임 명령을 호출했고 자원·체력 지급이나 적 삭제는 하지 않았다. 사용자 저장 슬롯과 설정을 분리했다.

첫 회차는 창고·잠자리가 60.7초 관찰 시점에 완성돼 있었고, 연구대·화덕은 240.5초 전에 완성됐다. 식사·수면·채집·운반과 요리 생산이 이어졌다. 식량 직접 채집 후 452.1초에 식량 25개, 543.3초에 식량 37개·흙 35개를 관찰했다.

602.8초에 연구비는 결제됐으나 연구자 배정이 거절돼 진행 0이 유지됐다. 이 결과를 근거로 연구 배정 전환을 수정했다. 식사·수면 중의 배정은 여전히 거절되므로 플레이 검증에서 완료 후 재지정한다. 120초 단위 관찰·주문과 실패 진단이 끼어 있어 이 회차를 최단 첫 연구 시간의 전후 비교로 사용하지 않는다.

723초 정상 저장을 불러온 뒤 첫 웨이브 예고/규모가 5에서 15로 바뀌었다. 원인은 OptionsDto에 startingCount가 빠진 것이었다. 이 회차의 전투는 균형 평가에서 제외하고 `work/release-flow-1114/solo-before-save-fix/`에 로그·정상 저장을 보존했다.

## 저장 수정 후 1인 회차

새 게임의 정상 저장·씬 재로드에서 시작 인원 1명과 웨이브 규모 5/37/72가 그대로 유지됐다. 정상 JSON 1~3명, 잘못된 값, 필드 없는 구 저장까지 11개 검사가 통과했다. 별도 회복 유예 검사 7건도 통과했다. 직접 작업·연구·시작 인원·유예의 격리 검사는 총 43건이다.

1명으로 식량 27개·요리 1개를 332.3초에 관찰했고 약초 처방은 822.0초에 완료했다. 874.0초에 첫 웨이브를 앞당겨 897.5초에 방어했다. 5마리, 약 23.5초 전투, 생존 체력77. 1017.7초에 체력100으로 회복했다. 1138.2초 관찰 시 돌 도구 제작도 완료됐다. 이 회차는 요리·취침·연구·회복·제작을 순차 수행했지만 안정적인 식량 비축을 유지하지는 못했다.

방어 후 포식자 추가 출현으로 연구대가 파괴돼, 기존 사건 유예를 우회하는 경로를 고쳤다. 해당 자연 로그·정상 저장은 `work/release-flow-1114/solo-after-save-fix/`에 보존했다.

## 출시 전 남은 핵심 문제

- 3웨이브 전에 생활 불만·식량 부패·방어 준비를 감당하기 어렵다. 낮은 기분이 동료 공격과 탈주로 이어져 재정비 인력을 잃는다. 전투 난도와 생활 압박을 분리해 재검증해야 한다.
- 약제대는 완성되고 주문도 수락됐지만, 이 회차에서는 약초 반입과 약 제조·투약까지 연결됐다는 증거가 없다. 초기 곰팡이 감염은 자연 면역으로 회복했다.
- 화분형 기초 생산, 일반 밭의 종자·파종, 화장실 재료 반입 등은 시설 배치만으로 가동되지 않는다. 이번 회차의 초기 버섯밭은 식량 공급 성과로 집계하지 않는다.
- 1인 첫 연구는 방어 전에 가능했으나 넉넉하지 않다. 수면 교착 수정까지 적용한 완전 새 게임의 1인 시간 비교는 추가로 필요하다.
- 전투 중 가림·경고 과밀, 부족 외형 통일, 원정 출입 전투, 본선 보스·귀환 흐름은 출시 잔여다.

검증 스크립트는 `AgentScripts/Release*1114*.cs`, 자연 로그와 캡처는 `work/release-flow-1114/`에 있다. 도구 검사 실패(시설 이름 오기·Collider 누락·using/접근 제한)는 검사 코드에서 수정했고 게임 결함으로 집계하지 않았다. 그래프 갱신 중 로그 쓰기 지연으로 한 Step이 제한 시간을 넘겼으나, 분리 실행이 끝나고 일시정지·최종 캡처를 확인한 뒤 진행했다.

## 검증 종료와 인계

Unity 컴파일 오류0, 기능 검사43건 통과, 자연 저장의 기상·식사 회귀 검사 통과를 확인했다. 마지막 코드 수정 후 graphify 갱신도 종료0이다. 사용자 설정·격리 저장 경로·GameView 설정을 복원했고 `restore.json`의 active=false를 확인했다. SAVE 요청은 없어 커밋·push·Notion 기록은 진행하지 않았다.

종료 시 `editor_stop`이 시간 초과됐다. 이후 씬 복원 로그와 다른 담당 범위의 OrganicEnemies 에셋 임포트가 관찰됐고, 마지막 상태 조회는 playing이었다. 다른 작업의 Play일 가능성이 있어 추가 강제 중지는 하지 않았으며 외형 담당 채팅에 현재 소유 확인을 인계했다. Edit ready로 반환됐다고 단정하지 않는다.

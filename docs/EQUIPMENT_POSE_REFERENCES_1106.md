# 장비 파지·애니메이션 검수 (2026-11-06)

사용자 요청: 무기마다 자세를 검색해 결정하고, 손 위치와 실제 파지를 최우선으로 검수한다. 캐릭터 비율에 맞춘 게임 애니메이션이며 현실 동작의 정밀 재현은 아니다.

## 참고 자료

- 활: [World Archery 초급 교본](https://extranet.worldarchery.sport/documents/index.php/Federation/Award_Schemes/Beginners_Manual.pdf). 활 손은 과하게 움켜쥐지 않고 지지하며, 시위 손의 당김/앵커/릴리스 역할을 구분한다.
- 총: [NRA 소총 자세](https://www.americanhunter.org/content/how-to-shoot-a-rifle/). 앞손은 총 앞부분을 받치고, 뒤손과 개머리판의 어깨 접촉을 함께 검수한다.
- 카타나의 양손 배치 참고: [Michigan Kendo Club](https://michigankendo.com/resources/parts-of-a-shinai-and-how-to-hold-it). 검도 죽도의 오른손 앞·왼손 뒤 배치를 게임 검의 양손 자세 참고로 사용한다. 실제 카타나 전용 기술 자료로 간주하지 않는다.

## 구현 중

- 총기: 오른손 기준 조준·반동, 보조 손은 실제 해결된 오른손 소켓 좌표를 따라간다. 연발은 짧은 반복 반동.
- 카타나/대형 망치/곡괭이/삽/괭이: 기존 몸 전체 동작을 유지하며 보조 손을 손잡이의 상대 앵커에 맞춘다.
- 손가락: 중립 회전에서 관절별 굽힘을 적용해 매 프레임 누적 회전을 방지. 총의 검지와 활 손의 굽힘은 다르게 설정.
- 미완료: 엄지 접촉, 모든 장비별 실제 손잡이 반경 보정, 활 시위 변형/릴리스 접촉, 어깨 개머리판 접점, 동작별 근접 육안 검수. 코드 추가를 검수 완료로 기록하지 않는다.

## 합격 기준

1. 정면/측면 근접 화면에서 손바닥 접점, 손가락 감쌈, 엄지 반대편 지지가 보인다.
2. 대기·이동·준비·타격/발사·복귀에서 손이 손잡이에서 미끄러지거나 분리되지 않는다.
3. 양손 무기의 보조 손과 팔꿈치가 과도하게 뻗거나 몸통을 관통하지 않는다.
4. 활은 당김 손/화살/시위가 함께 움직이고 발사 때 분리된다.
5. 무기를 내려놓으면 손가락과 보조 손 자세가 원래 애니메이션으로 복귀한다.

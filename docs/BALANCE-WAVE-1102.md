## 5. 웨이브 정량 비교 — 공식 산술·최대 접촉 모형
- N=몸체 수, I=min(N,30), H=ceil((N-I)/50). 표의 DPS는 모든 호스트가 계속 붙어 동시에 공격할 때의 초기 평균값.
- 유닛 전 방어 DPS = I/2 + Σmin(무리몸체,6)/2.
- 건물 전 방어 DPS = I/2 + Σmin(무리몸체,20)/2.
- 방어6 성문 DPS = I/2 + Σmax(1,min(무리몸체,20)-6)/2. 원정 적/불/문 추가 타격 제외.
- 전투 중 마릿수가 줄면 압력도 줄어든다. 첫 공격 타이머가0인 적의 일제 타격은 평균DPS보다 순간적으로 더 위험하다.

  - L도 80무리를 한 성문에 모으면 최대내구1920/575≈3.3초에 돌파된다. 4방향 균등 분산이면 통로당약13초. 전투부대도 모두 노출되면 최소 피해만으로 약55DPS라 병력120의 화력 기반이 빠르게 사라진다.
  - C 범위 무기·지원·진형·수리·교대가 이 차이를 메우면 지휘의 가치다. 반대로 이 모든 것을 강제해도 못 버티는지는 실제 경로·피격·화력 시간축 측정이 필요하다.

## 7. 결정/추가 확인 필요
- 특정 회차 “절대 못 이김”으로 확정할 데이터는 없다. 실제 20/25/30회에서 기술·정책·병력·장비·탑/함정·재료·접촉 호스트 수·공격 가동률·병력 손실 시간을 함께 기록할 것.
- 일괄 동시 접촉과 실제0.5초 생성 스트림을 따로 비교한다. 평균 FPS와 승리 가능성은 별개다.
- 생성 실패30회 후 미생성 적을 포기하고 정상 성공/전체 처치처럼 기록하는 경로(WaveDefense.cs:104~115)는 확정 전멸 기준과 충돌한다. 숫자 튜닝으로 해결하지 말고 실패/재시도 처리 방침을 확인할 것. 별도 CHECKS 인계에 기록했다.
- 추가 몸체의 물리 접촉·개별 피격, AoE를 마릿수만큼 증폭, 원정 중 웨이브 처리 변경은 규칙 변경 질문 대상이며 구현/자동 채택하지 않았다.

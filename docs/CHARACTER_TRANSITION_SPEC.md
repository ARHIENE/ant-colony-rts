# 캐릭터 전환 기획 — 2026-10-17

사용자 요청: 개미 대신 첨부 캐릭터 시트와 같은 캐릭터로 전환할 때 기존 기획의 충돌을 수정한다. 이번 범위는 기획·제작 요청서다. Unity 코드, HUD 화면, 모델·리그·클립은 이번 작업에서 교체하지 않았다.

## 기준

- 두 팔·두 다리로 생활하며 손에 도구를 들고 얼굴로 감정을 표현하는 로우폴리 캐릭터.
- 첨부한 6개 디자인은 외형 참고용이다. 이름, 6종의 전체 채택 여부, 종족 구분과 종족별 능력은 확정하지 않는다.
- 시민은 인구 수로 관리하며 자체 생계·납세·병역을 담당한다. 장수는 개별 캐릭터로서 작업·전투·관계·의료의 대상이 된다. 귀여운 외형을 이유로 전투·사망·포로·질병 규칙을 삭제하지 않는다.
- 기존 작은 세계와 자연 재료 시설·곤충 사육은 유지한다. 정확한 캐릭터 크기와 사람 물건/동물 대비 비율은 미정이다.

## 충돌과 수정

| 기존 전제 | 새 기준 |
|---|---|
| 일반개미 / 장수개미 / 소굴 | 시민 / 장수 / 정착지. 군사 맥락의 인원은 병력·병사 |
| 6개 다리·더듬이·큰턱 의료 | 머리·눈·몸통·팔/손 좌우·다리/발 좌우. 귀·잎·돌기의 기능은 미정 |
| 내부 장기 보류 | 대체 부위에 내부 장기 포함, 뇌 교체 불가. 세부 장기·레시피 미정 |
| 큰턱 날·맨 큰턱 | 손에 드는 근접 무기·맨손. 세부 무기 디자인 미정 |
| 방패 갑각·외골격 코팅 | 방패·보호 갑옷. 갑각 재료를 수집해 쓰는 것은 가능 |

| 더듬이 고리·두더지 큰턱 | 감각 보조 장신구·굴착 재능. 세부 시각 디자인 미정 |
| 실제 개미 종→장수 능력 | 종족 고정 능력 전제 폐기. 기술·장비·개체 특성 유지 |
| 여왕방 생산 특성 잔존 | 여왕방은 이미 삭제된 시설. 교화의 생산 효과 폐기, 대체 효과 미정 |

| 앞다리·턱 운반/가운데 다리 보조 | 손·등·어깨 운반, 필요 시 작업대 고정구. 기본 이동은 두 발 보행 |

## 유지하는 시스템

시민 이주·세금·재개발, 장수 작업표·15종 기술·기분·관계·출산/양육, 징집·부대 체력·외교·포로·원정, 목장 동물·감로·실, 농사·물류·전력·시설·연구·로켓 승리는 유지한다. 새 주민과 사육 동물은 명확히 구분한다. 외형의 귀·잎에서 식성·광합성·추가 감각이나 알/유충 단계를 도출하지 않는다. 종족 간 출산 가능 여부와 자녀 외형 규칙은 미정이다.

## 기존 자산과 후속 구현

- 시설 79개 및 재질·파일 ID는 유지. `CC_NestEntrance`도 ID를 바꾸지 않고 정착지 입구 후보로 취급하며 큰 머리가 통과 가능한지 검사한다.
- 기존 개미 작업 클립 17개와 도감 GIF는 이전 캐릭터 제작 기록이다. 새 캐릭터에 적용 완료한 것으로 표시하지 않는다.
- 시설 경첩/조준 클립 6종은 재사용 후보. 작업 지점, 손잡이·도구 높이, 의자·침대·의료대, 출입구·통로·충돌 크기는 새 체형으로 검증한다.
- 새 메시/리그를 확보한 뒤 보행·운반·작업·전투·쓰러짐·수면·표정을 제작한다. Humanoid/Generic은 실제 본 구조를 보고 결정한다.
- Unity/HUD의 표시 이름·신체 부위·장비 설명·초상화는 구현 후속 작업. 저장 enum·키·파일명을 단순 치환하지 않는다. 기존 부위 손상/장비를 새 체계로 이관하는 명시적 정책과 저장 왕복 검사가 필요하다. 잘못된 부위를 조용히 완치 처리하지 않는다.
- 군사 수량과 장수 개인 신체 건강을 구분한다. 새 캐릭터로 바꿔도 시민 수만큼 GameObject를 만들지 않는다.

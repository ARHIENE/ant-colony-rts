# 숯빛 HTML → Unity 반영 (2026-11-10)

사용자 요청: 승인한 charcoal HTML 색을 Unity에도 반영하고 글씨·배치를 맞춰 실제 게임 화면으로 보여 달라.

## 반영 범위

- 공통 MenuTheme와 HUD 패널을 숯빛·돌빛 회색으로 변경. 배경302e2b, 선택창3d3a35, 테두리797267, 하단2c2b29. 초록은 체력처럼 의미 있는 상태 표시에만 유지한다.
- 자원 패널, 지도 하단, 장수 초상 바탕/이름·상태 글씨, 선택 명령, 배속/설정, 습격 및 알림 색을 charcoal-v8.css에 맞춤.
- 이름표의 기존 녹색 기운 배경도 중립색으로 변경. 게임 행동과 상태 표시 조건은 유지.
- HTML과 Unity의 반투명 혼합 차이를 실제 PNG 픽셀로 확인. 자원 배경 Unity alpha .93으로 보정해 HTML alpha .83의 화면 인상에 맞춤. 기준 샘플 HTML RGB76/77/71 → Unity74/75/67 (서로 다른 월드 바탕). 선택창은61/58/53 →61/59/53, 평화 습격 배경52/49/45 →53/50/46.
- 1440×900 기준으로 선택창344×128, 미니맵190×168, 자원104×142, 습격220×60과 메뉴 간격을 확인. 이름19/본문11/명령12/메뉴13/시계24px 및 Regular/Medium 글꼴 유지·검증. 이전 사용자 요청의 공통 비례 배율을 유지한다. 작은 창에서는 HTML의 옛 고정크기 모바일 배치로 되돌리지 않는다.

## 보존 및 남는 차이

자원 그림은 아직 임시 PrototypeResourceIcon이다. 사용자가 지정한 실제 자원 이미지 사용 기준은 docs/UI_DESIGN_DECISIONS.md에 유지했으며, 임시 그림을 최종 에셋으로 확정하지 않았다. 연구 등 상세 화면은 실제 데이터/조작 구조를 유지하며 공통 색상을 반영했다. 이번에 전체 상세 화면 구조를 HTML로 재작성했다고 주장하지 않는다.

애니메이션/음주 기능 담당 파일은 수정하지 않았다. UI 검증 점유를 잡고 실행했으며 완료 후 Play 중지·본인 잠금 해제. SAVE/커밋/push/Notion/컴퓨터 종료는 수행하지 않았다.

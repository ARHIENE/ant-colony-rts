# 운영 개선 — 검토 100항목의 적용 범위

## 판단 기준
- 사용자 제공100항목은 설계 공백·위험 가설·정합성 의견이다. 100개 버그가 재현됐다는 뜻이 아니다.
- 승인1차는 정착지 자동 운영의 이해 가능성: 막힘 사유/대응, 식량 위치/가용량, 중요 경고 누락 방지, 현재 기획/잠정값/검증 상태 정리다. 필요한 UI/기능 구현은 허용이며 새 화면을 반드시 추가하라는 요청은 아니다. 기존 창을 재사용한다.
- 대상·생산 목표·작업 우선순위를 플레이어가 정하고 장수가 실행한다. 미지정 자연물 자동 채집·새 제조법 임의 선택·수술/전쟁/출정/발사 자동 결정은 추가하지 않는다. 기존 시민·세금·직접 전투 규칙은 유지한다.
- 참고 방향: [RimWorld 공식 소개](https://rimworldgame.com/)의 개별 정착민 요구·건강·생산과 [Oxygen Not Included 공식 소개](https://www.klei.com/games/oxygen-not-included)의 자원 부족·생존·정착지 운영. 두 게임의 수치/부가 시스템을 그대로 복제하거나 모든 의견을 확정 스펙으로 채택하지 않는다.

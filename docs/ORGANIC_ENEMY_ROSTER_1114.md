# 생물형 적 확장 디자인

2026-11-14 사용자 요청: 기계식 외계인보다 저그 같은 생물형 느낌. 해당 외형 시안을 긍정한 뒤 벽 공격형·원거리형을 추가 요청. 이어 운반·은폐·끌어오기·보호·회수·굴착 후보 모두와 주변 회복형 디자인을 요청했다.

이 문서의 행동과 수치는 디자인 단계다. 생물형 17종의 Meshy 모델·텍스처·Smart Rig GLB를 확보했고, Blender 동작 제작과 Unity 에셋 임포트를 진행했다. 후속 작업으로 실제 스폰·웨이브 편성·AI·스킬 효과와 저장 복원을 연결했다([전투 구현과 검증](ORGANIC_COMBAT_1114.md)). 아래 디자인 수치는 확정 밸런스가 아니다. 종별 제작·검증 상태는 [제작 기록](../art/enemy-concepts-1114/PRODUCTION.md)을 기준으로 한다. 이름은 작업명이다.

## 공통 원칙

- 육체·갑각·힘줄·생체 기관으로 구성. 최초 네 발 기계형 무인기 시안은 사용자 요청으로 폐기한다(2026-11-14). 현재 적 디자인 후보는 생물형 17종이며 무인기는 포함하지 않는다.
- 역할마다 체형과 공격 예고를 다르게 한다. 색상만으로 구분하지 않는다.
- 공격 전 준비 → 효과 → 회복/이동 구간을 보여 주어 대응 시간을 준다.
- 작은 RTS 화면에서 읽히도록 최종 모델은 시안의 잔가시와 힘줄을 줄인다.
- 생물 시안이므로 기존 수성 규칙과 장수 직접 지휘를 유지한다. 벽 무시·무한 소환·부활·무적을 기본 능력으로 넣지 않는다.

## 지원·교란 7종

![지원·교란 생물 시안](../art/enemy-concepts-1114/organic-support-concept.png)

| 작업명 | 몸체·실루엣 | 행동과 예고 | 방어측 대응 |
| --- | --- | --- | --- |
| 포낭 운반체 | 여섯 가는 다리 아래 거대한 반투명 배. 안에서 작은 개체가 움직임 | 접근 후 배가 수축·팽창하며 제한된 수의 작은 적 방출. 방출 뒤 배가 줄어듦 | 가까워지기 전 집중 공격. 배는 약하고 운반체 자체는 느림 |
| 안개 분비체 | 낮고 넓은 가오리형 막, 옆면 아가미 | 멈춰 막을 부풀리고 짙은 보라 포자 안개 분비. 뒤따르는 무리의 식별/조준을 방해하는 역할 후보 | 범위 밖으로 위치를 바꾸거나 분비체 우선 제거. 안개가 벽 너머 적까지 자동 노출시키거나 공격을 완전 무효화하지 않음 |
| 갈고리 포식자 | 접힌 큰 턱, 긴 뒷다리, 뼈갈고리 달린 한 가닥 혀 | 고개를 젖혀 턱을 연 뒤 직선으로 혀 발사. 맞힌 노출 장수를 당김 | 벽/엄폐 뒤 이동, 발사 전 옆으로 회피, 당기는 동안 집중 공격. 벽을 관통해 끌지 않음 |
| 갑각 수호체 | 수직으로 솟은 큰 머리판, 짧고 튼튼한 지지 다리 | 몸을 세워 뒤의 작은 적을 정면 공격으로부터 보호. 방향 전환은 느림 | 측면 접근 또는 곡사 공격. 전체 무적이나 모든 방향 보호로 만들지 않음 |
| 회수 생물 | 낮은 여덟 다리와 아래로 굽은 먹이 촉수, 늘어나는 소화 배 | 외계인 사체/잔해 가까이서 멈춰 섭취하고 자신을 회복하는 역할 후보 | 섭취 중 차단·제거. 이미 처치한 적을 그대로 부활시키지 않음 |
| 굴착 잠복체 | 길게 이어진 마디 몸통, 앞쪽 두 굴착 발톱 | 지면 균열이 이동 경로를 예고하고 잠시 멈춘 뒤 출현. 후반 특수 적 후보 | 균열을 보고 장수를 이동·집중 배치. 초반 방벽을 무조건 우회하는 기본 적으로 사용하지 않음 |
| 개화 치유체 | 가는 네 다리, 높이 펼쳐지는 부채/산호 모양 등막, 아래로 늘어진 가는 촉수 | 정지해 등막을 펼치고 가까운 살아 있는 아군에게 옅은 청록·백색 회복 포자를 보냄. 치유 대상에 가는 포자 흐름 표시 | 회복 중 드러나는 연한 몸체를 우선 공격하거나 적 무리를 회복 범위에서 분리. 이동 중 회복 중단, 사망 개체 부활 없음 |

안개 분비체는 낮고 수평적인 실루엣·불투명 보라 안개, 개화 치유체는 높고 수직적인 실루엣·옅은 청록 포자로 구분한다. 치유체끼리 무한 회복이 되는 조합을 피하도록 중첩/대상 규칙은 구현 전에 정한다.

## 이미 만든 특화 4종과의 조합 후보

- 충각수 + 갑각 수호체: 벽 공격과 정면 보호. 측면 이동의 가치가 생김.
- 부식붙이 + 안개 분비체: 지속 벽 손상과 지원형 우선 제거 판단.
- 침사냥꾼 + 갈고리 포식자: 끌려 나온 장수를 노림. 동시 확정 타격이 되지 않도록 충분한 예고/발사 간격 필요.
- 포낭수 + 개화 치유체: 후방 공성·회복 진지. 고정 중인 두 개체에 접근할 기회 제공.
- 포낭 운반체 + 회수 생물: 먼저 잡을 대상 선택. 방출 개체가 무한한 회복 자원이 되지 않도록 횟수/사체 처리 제한 필요.

조합·수치·출현 시기는 모두 제안이며, 현재 게임에 반영된 규칙으로 취급하지 않는다.

# 창고 허용 품목 복사

100항목27의 반복 설정을 기존 창고 화면에서 줄인다. 창고 간 자동 이동 금지는 유지한다.

- 일반 창고/비축더미끼리, 냉장고/냉동고끼리 허용 품목만 복사·붙여넣는다. 복사 뒤 원본 설정이 바뀌어도 복사본은 그대로다.
- 재고·신선도·우선순위·용량은 복사하지 않는다. 붙여넣기로 금지된 물량은 기존 SetAllowed/Eject로 바닥에 보존하며, 식품 신선도를 새것으로 만들지 않는다. 이후 운반은 기존 창고 우선순위·거리·운반 작업 규칙을 따른다.
- 냉장 전용 품목을 일반 창고 필터로 덮지 않도록 서로 다른 분류 간 붙여넣기는 비활성화한다. 퇴비통은 별도 숙성 원료 설정이므로 대상에서 제외한다.
- StorageFilters1029Checks21 통과: 실제 버튼, 초기 비활성,78품목/64이후 필터, 복사 시점 보존, 우선순위 불변, 쌀7/식량5 반출 보존과 식량 잔여70초 유지, 자동 재배치 없음, 냉장/냉동 호환·일반/냉장 차단, 실제 저장/복원.

UI 구조·버튼 동작을 실행 검사했으며 화면 육안 검수는 하지 않았다. 대규모 창고 이전의 장기 조작량과 수동 대량 운반 전체 흐름까지 해결한 것으로 보지 않는다. 개발 일지·캡처는 SAVE 때만 한다.

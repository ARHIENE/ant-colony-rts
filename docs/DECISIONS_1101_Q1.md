새 DTO/저장 필드/enum/자원/도감 키 없음. 신규 요약은 기존 BossProgress.State(killedAt/unclaimed/cargo/home), 수송 Remaining/health/crew/cargo/withdraw에서 계산한다. 이전 저장은 기존 로더의 기본값 경로를 그대로 쓰며 상태를 소급 덮어쓰지 않는다. Notion에는 쓰지 않았으며 통합 담당자가 기존 하위 기획·참조 일지를 확인해 이 잠정안을 반영해야 한다(부모 페이지 전체 교체 금지).

# 사망 동작과 자연물 날씨 표현

사용자 요청: 몹이 단순히 뒤집히는 사망 동작을 다듬고, 바위 적설·계절 잎색·낙엽을 연결한다. 추가 정정은 눈 때문에 바닥 전체가 흰 배경처럼 보이는 문제다. 기존 캠페인 전체 진행 작업과 함께 진행하며, SAVE나 종료 요청은 아니다.

## 반영

- Meshy 원본 체형과 관절을 사용해 현재 자세에서 다리 지지 상실→몸통 기울기→머리/하부 관절 지연→작은 잔떨림→정착으로 이어지는2.6초 동작을 추가했다.17종별 다리·머리·촉수·꼬리 관절 목록을 사용하며 기존 전신 뒤집기 클립은 실제 사체를 구동하지 않는다.
- 사체 방향을 저장하고, 이미 가라앉은 사체는 불러올 때 같은 방향·관절 자세·지면 접촉으로 복원한다. 전투 피해·사체 수량·수명은 변경하지 않았다.
- 무리 추가 개체의 GPU 사망 표본도17종 모두 다시 만들었다. 기존 생존 동작 입력과 무리 간격에 쓰는 width 값을 보존했다. 원본 bank 백업은 work/death-weather-1115/before/banks에 있다.
- 눈/눈보라가 지속되면 자연물 윗면과 지면에 적설이 늘고, 맑은 날·비에서는 녹는다. 비에는 지면·자연물이 어두워진다. 적설/젖음 상태는 저장하며 이동·작업·전투 배율은 기존 규칙을 유지한다.
- Meshy 장식 나무·바위와 실제 채집 노드에 계절 셰이더를 연결했다. 원본 텍스처·재질 에셋은 변경하지 않고 인스턴스 소유 재질을 해제한다. 소나무는 상록수를 유지하며 낙엽은 잎 모양 입자와 회전을 사용한다.
- 바닥 적설은 최대 덮임에서도 원래 지면을 남긴다. 작은 눈 질감, 여러 크기의 노출 지면, 경사면 노출, 절벽 윗면 밝기 제한을 적용했다. 첫 화면에서 여전히 평평해 보여 덮임·질감 크기를 다시 조정했다. 바위 윗면 적설과 지면 덮임은 같은 양에서도 다르게 표현한다.

## 확인한 범위

-17종에서3개 이상 관절이 실제로 달라지고, 최종 자세를 반복 적용해도 회전이 누적되지 않으며 사체 수명·수량이 유지됨 확인.
- 정상 치명 피해 경로로 대표 몹의 새로운 사망 진입, 기존 Animator 뒤집기 비활성, GPU 무리 사체 생성 확인.
-17종 GPU bank의2.6초/63프레임 이상 사망 표본 확인. 생존 무리 간격 보존 기록: horde-bake.txt.
- 강설45/90초 누적, 비의 융설/젖음, 난수 불변, 자연물 재질 연결 확인.
- 정상 저장/전체 재로드에서 적설0.65·젖음0.2와 사체 방향73도·최종 관절·지면 위치·수량·수명 보존 확인.
- 검사 및 화면은 work/death-weather-1115. 최종 콘솔 검사 오류0·경고0. 렌더링 캡처의 날씨·시간은 격리된 검사 상태이며 자연 캠페인 진행 실적으로 합산하지 않는다.
- 초기 화면 검사에서 시간을 과거로 옮겨 RocketEconomy의 시간 역행 검사가 예외를 발생시켰다. 게임 코드를 완화하지 않고 검사 시간을 순방향으로 수정하고 원본 체크포인트를 다시 불러왔다. 런타임에서 자연 발생한 결함으로 기록하지 않는다.
- 셰이더 재임포트 직후의 청록색 임시 화면은 최종 결과가 아니며, 재로드 후 실제 텍스처 화면으로 재확인했다.

## 화면 검수

craft-game-floors의 character-motion·vfx·visual-scorecard 기준을 요청한 동작/날씨 표면에 적용했다. 기존 스타일 유지, 신규 패키지·Meshy 구매·Blender 모델 제작 없음. 전체 게임의 출시 점수는 아니다.

- palette discipline: 3/5 — 흙·주황 낙엽·차가운 눈의 기존 색상 유지.
- style uniformity: 3/5 — 기존 Meshy 모델/텍스처 위에 날씨 표현 연결.
- lighting depth: 3/5 — 눈 아래 지면과 경사/가장자리 구분 개선, 별도 조명 재설계 없음.
- silhouette: 3/5 — 대표 체형3종의 붕괴 전후 윤곽 확인.
- UI intentionality: 3/5 — 기존 HUD 유지·캡처에 포함.
- feedback visibility: 3/5 — 단일 뒤집기에서 여러 관절의 지연 붕괴로 변경, 적설·낙엽 구분.

초기 바닥 가독성과 단일 회전 사망 표현은2/5로 판단해 한 차례 이상 수정했다. 눈 지형과 사망 동작은 기존보다 구분되지만, 별도 날씨 음향·발자국·물리 기반 적설 두께는 이번 범위에 포함하지 않았다. 정상 경제 엔딩 완주는 여전히 미확인이다.

방식: Codex(gpt-6.1-sol, medium)와 Claude가 서로 독립적으로 문항별 결정안을 낸 뒤 비교해 더 나은 쪽을 채택하거나 합쳤다. 레퍼런스는 RimWorld·Oxygen Not Included(산소미포함) 우선. 사용자 미확인 추천안 자동 선택(잠정 수치 포함)이며 구현 완료가 아니다.

## 0. 공통 기준 — G08 달력 (Claude 안 채택)
- '월' 단위 폐지, RimWorld식 계절·일 달력. 1일 = 1배속 150초(낮 100초·밤 50초). 1계절 = 6일(15분 유지), 1년 = 4계절 = 24일 = 60분(유지, 10시간 ≈ 10년 유지).
- 기존 '한 계절 = 하루(15분)·낮 10분/밤 5분'과 '1개월=5분·4주'를 이 기준으로 대체한다.
- 식사 하루 2끼. 시작 보존식 7일 = 17.5분. 납세 매일 아침(기존 주간 75초 → 1일 150초, 월 총세액 기준은 일 기준으로 재산정). 자동 이주 3일마다(ONI 프린팅 포드 3사이클 참고).
- 보스 재등장 30일 → 12일(반년). 최종 방어 15일 유지(=37.5분, RimWorld 우주선 15일 가동). 기존 '30일·1개월' 표기 수치는 아래 각 항목에서 재환산.
- 배속: 일시정지·1·2·3·5배 기존 유지. 모든 타이머는 같은 게임 시계에 연결.

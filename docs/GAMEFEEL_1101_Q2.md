## 수량·검증 해석

- 1단계 상·중16건, 2단계 상·중16건으로 **상·중32건 구현**. 하28건 중Q2-47도 코드 정리, 나머지27건은 위 이유로 후속이다.
- 신규 검사 `Review1101Q2Checks.Main`은 회복 유예 경계·의료 예상·성장 정보·시대별 병행 목표를 검사한다. `RunQ2Scene`은 실제 장면에서 담당 표시·불필요/금지 처치 해제·부모 부위 수술 차단·목표 생성 경로를 검사하도록 준비했다.
- Unity 에디터는 실행하지 않았다. 구조 실제 이동·집도의 교대·새 안내의 두 화면 폭 검증은 Claude에게 인계한다. 상·중의 코드를 연결했다는 것과 게임성 개선이 실플레이로 입증됐다는 것은 다르다.

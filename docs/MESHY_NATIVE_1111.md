# Meshy 원본 리그 전환 — 2026-11-11

## 확인한 원인과 방향

기존 공통 Kemono 리그로 변환한 모션은 팔과 몸의 자세가 원본과 달랐다. 기존 파지 보정도 원본 손 궤적 대신 별도 사인 곡선으로 팔을 움직였다. 사용자에게 원본/변환본을 같은 시점으로 보여 준 뒤, 원본 메시와 원본 리그의 재생을 유지하는 방향으로 진행했다. 앞선 회수 구간·절차적 팔 보정 실험은 원복했다.

보유 Meshy 파일에는 리깅 전후 두 계열이 있다. 오른쪽 팔꿈치–손목 길이는 약 0.1573m/0.1672m이며, 손가락 및 무릎의 bind 회전도 일부 다르다. 같은 이름만 보고 한 리그에 모두 넣지 않는다. `Heavy_Hammer_Swing.fbx`와 `Rerig_All.fbx`를 각각 대응 원본으로 사용한다.

## 이번 변경

- 보유 119종을 `Assets/_Project/Art/MeshyNativeSources`로 임포트했다.
- `MeshyNativeLibraryBuild`는 원본 FBX의 AnimationClip을 직접 참조한다. 스켈레톤 전용 FBX는 Animator를 `SmartRigArmature`에 두고, 전체 모델 FBX는 모델 루트에 두어 서로 다른 뼈 경로를 처리한다. 관절 곡선을 다시 굽거나 기존 Kemono 뼈로 회전 변환하지 않는다.
- 119종 모두 대상 원본 계층에 뼈 경로가 있는지 검사하고 `Resources/MeshyNative/Library`에 등록했다. 이는 시각 품질 전체 통과를 뜻하지 않는다.
- 기존 행동 매핑 27개를 라이브러리에 등록했다. `AntVisual`의 실제 모션·도구·재생 속도·재시작 순번을 읽는 `MeshyNativeMotionPlayer`를 추가했다.
- 대응 원본이 없는 기존 전용 행동은 기존 캐릭터로 표시한다. 미구현 게임 행동용 모션은 라이브러리 보관 상태다.
- `MeshyNativeEquipment`는 원본 손 위치로 장비를 배치한다. 팔 궤적을 덮어쓰지 않는다. 손잡이 축과 접점은 실제 화면 검증이 필요하다.

## 아직 완료되지 않은 범위

- 첫 장수 시험 연결을 전체 모듈형 외형으로 확대하는 작업. 현재 원본 메시만으로는 기존 머리·얼굴·의상 조합을 대체할 수 없다.
- 기존 전용 생활/제작/치료 모션과 모든 장비의 교차 검수.
- 손가락 감김, 활/화살과 머리 간섭, 도구 타격점 및 좌우 손의 최종 화면 검증.
- 실제 게임 행동 전수 재생, 죽음 복제체 및 저장/재시작 회귀 검증.

전수 임포트 CLI는 175초 응답 제한을 넘었으나 Unity 작업은 계속돼 119개 에셋과 Library 생성 완료를 확인했다. 컴파일은 오류 없이 완료했다. 전수 자세 검사 결과와 Play 검증은 확인 후 추가한다. SAVE·커밋·push는 하지 않았다.

## 후속 CLI 검증과 정정

- 119종, 각21시점의 팔·다리 관절 운동 및 길이 불변 검사 통과. 이것만으로 시각 품질 전체 통과를 뜻하지 않는다.
- 원본 FBX 직접 참조 전환 후 서로 다른 리그/루트 형식을 포함한20종·각3시점 비교에서 관절 회전·위치 차이0. 초기 경로 보완용119개 `.anim`과 메타는 참조가 없음을 확인하고 `work/animation-1111/normalized-clip-backup`으로 이동했다. 런타임에는 이 약3.7GB 복제 데이터를 사용하지 않는다.
- 곡괭이는 최초 오른손을 앞손으로 가정한 접점 검사를 통과했지만, 실제 화면에서 머리가 반대쪽에 있는 오류가 남았다. 그 결과는 최종 해결 증거가 아니다. 왼손 앞손 및 날의 타격면 방향으로 정정했다. 코드 재실행/화면 최종 확인은 별도 진행 중이다.
- 도끼7재질의 초기 손잡이 길이 검사 실패를 확인했다. 원본 모션60시점 최대 손 간격을 메타데이터로 계산하도록 수정했으며, Stone 도끼 재검사 통과(뒷손 위치 -0.093~0.084, 허용 -0.20~0.13).
- 몸과 겹친 `Dropped Stone`5개는 자원40 보존 후 옆 바닥으로 이동했다. 코드 수정 재실행 검사에서 돌12 보존·폭0.6m·장수와 수평 거리1.201m·바닥 접지 통과.
- 원본 리그용 갑옷/장신구 뼈 이름, 수납 무기의 FBX 회전 보존, 원본 사망 모션 경로를 추가했다. 해당 착용/사망의 최종 Play 검증은 아직 남아 있다.

- 실제 무기14종의 동작·모델 표시 검사 통과. 창=SpearThrust, 지진망치=HeavyHammer, 분사기/총/지휘봉=기존 전용 파지. 나무칼 누락 경로는 기존 검 메시의 목재 외형 재사용으로 표시 복구.

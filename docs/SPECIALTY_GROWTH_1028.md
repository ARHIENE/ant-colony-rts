# 후천 전문성 획득

100항목51·52·54와 사용자 추가 승인에 따른 현재13계열 연결이다. 전투/큰 사건 전문성·다이아18개 전용 효과 전체 구현 완료를 뜻하지 않는다.

- 실제 유효 작업으로 기본 기술10 최초 도달 시 골드20%,20 최초 도달 시 다이아5%를 각각 평생 한 번 판정한다. 수치는 사용자 승인 잠정값이다. 이미 기준에 도달한 기존/시작 기술은 소급 추첨하지 않는다.
- 현재 계열: 채집·건설·농사·낚시·제작·연구·의료·요리·근력·예술·정치·사육·조사. 주 능력뿐 아니라 실제 보조 성장으로 도달한 기술도 해당한다. 단순 이동·대기/화면 열기에는 판정하지 않는다.
- 특성4칸 만석이면 새 계열 기회를 소모하며 고정 성격을 밀어내지 않는다. 같은 계열 상위는 기존 슬롯에서 교체하고 효과를 중복 보유하지 않는다. 동시 후보는 기본 기술이 높은 순·동률 무작위, 같은 계열은 상위를 먼저 처리한다.
- 획득은 영구 유지하며 기술 하락·재도달·저장/로드로 재추첨하지 않는다. 획득/확률 실패/빈칸·조건 부족/동급 이상 보유/초기·과거 도달 소급 제외를 기록한다. 실제 판정은 알림·이벤트 기록에 남고, 장수 상세 기술 칸을 가리키면 규칙과 현재 결과를 본다.
- 후천 획득은 유전 후보에서 제외한다. 타고난 골드를 후천 다이아로 교체한 경우 원래 타고난 골드만 유전 후보로 보존한다. 자녀의 별도 무작위 생성으로 같은 전문성이 나오는 것과 부모의 후천 특성을 유전하는 것은 구분한다.
- 저장21에 선택 필드를 추가했으며 옛 기록 부재는 최초 유효 작업 전에 기존 기술 기준으로 초기화한다. 타고난 목록/26개 판정 결과/버전을 보존하고, 4칸을 허용하는 실제 규칙과 달리 저장 검사만3칸 제한이던 문제를 수정했다. 옛 필드·enum 번호는 변경하지 않았다.

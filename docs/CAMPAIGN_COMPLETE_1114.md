# 캠페인 완주 연결 — 2026-11-14

사용자가 초반 3일·3웨이브를 반복 검사하는 방식 대신 게임 시작부터 엔딩까지 먼저 연결하도록 요청했다. 초반 경제의 자연 장기 검사는 중단했고, 정상 저장은 보존했다.

## 이번 변경

- 도보 원정대는 장수 현재 위치가 아니라 본거지 지도의 통행 가능한 외곽 길목에 모인다. 장수가 걸어 도착하기 전에는 출발할 수 없다. 귀환은 본거지 전체의 적이 없어질 때까지 기다리지 않고 외곽으로 돌아온다.
- 로켓 발사는 승리가 아니라 본선 전장 진입이다. 본선의 지휘체를 처치해야 최종 결과 화면이 열린다.
- 본선 착륙선은 공격 대상이 아니다. 귀환 명령은 실제 이동을 시작하고, 착륙선에 도착한 장수만 지구로 돌아간다. 발사대에서 다시 출전할 수 있다.
- 본선 보스 체력·공격 예고, 현지 장수와 탑승 상태를 캠페인 저장에 추가했다. 귀환 자체가 치료를 제공하지 않는다.
- 목표와 발사·엔딩 문구를 본선 공략 흐름에 맞췄다. 기존 발사 엔딩 저장은 이전 기록으로 보존한다.

## 검증 방식과 현재 한계

검사 스크립트는 `AgentScripts/CampaignComplete1114Checks.cs`다. 사용자 저장 슬롯과 분리하며, 새 게임 확인 뒤 준비된 로켓 상태를 넣어 후반 전환을 검사한다. 보스 체력 변경은 상태 보존·승리 판정을 위한 시험 조작이다. 이것을 정상 경제로 처음부터 끝까지 플레이한 결과나 전투 재미 검증으로 기록하지 않는다.

후보 코드의 별도 컴파일을 통과했다. Unity에는 19:41 생성된 새 어셈블리가 반영됐고 컴파일 오류가 없었다. 메모리 부족과 재로딩 지연 중 이전 컴파일 상태가 반환된 적이 있어, 어셈블리 생성 시각과 실제 새 API 사용 여부를 별도로 확인한다. 실행 검사 결과는 아래에 이어 기록한다.

본선 외형은 기존 보스와 임시 갑판을 이용한 기능 연결 단계다. 전용 본선 아트·최종 보스 패턴·자연 장기 경제와 난도 검증은 남아 있다. 출정 호위 편성·복귀·원군의 전용 흐름도 완료로 취급하지 않는다. 출시 완료 판정이 아니다.

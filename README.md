# 개미 소굴 RTS

정착지를 운영하며 습격 웨이브를 막는 싱글플레이 전략 게임입니다. 평화 시간에는 생산·건설·연구·치료·수리로 방어를 준비하고, 전투가 시작되면 장수를 직접 지휘합니다. Unity 6로 개발 중이며 PC를 대상으로 합니다.

## 플레이 구조

- **운영과 발전:** 식량과 생활 기반을 마련하고, 남는 인력과 물자로 장비와 방어선을 갖춥니다.
- **웨이브 방어:** 벽·탑·함정으로 무리를 막고, 장수의 배치·집중 공격·스킬·교대·후퇴로 대응합니다.
- **재정비:** 방어가 끝나면 평화 시간에 피해를 복구하고 다음 웨이브를 준비합니다.
- **최종 목표:** 장수 1명 이상이 탑승한 로켓을 발사합니다. 현재 원정 중지로 새 게임의 승리 경로는 완성되지 않았습니다.

직접 조작하는 단위는 장수입니다. 시민은 수량으로, 장수에게 배정한 병력은 부대 체력으로 관리합니다. 시작 장수는 1~3명이며 정해진 건설 순서를 강제하지 않습니다.

## 현재 개발 상태

현재 개발 기준은 `develop`입니다. 아래 내용은 저장소의 최근 작업 기록을 요약한 것이며, 이번 문서 정리에서 게임을 다시 실행해 검증한 결과는 아닙니다.

| 항목 | 상태 |
| --- | --- |
| 웨이브 진행 | 첫 평화 6일, 이후 4일. 시간이 끝나면 자동으로 시작하며, ‘지금 시작’으로 앞당길 수 있습니다. |
| 전투 | 일반 적의 무리 표현과 웨이브 HUD를 구현했습니다. 방어시설의 효과와 초반 난이도를 조정 중입니다. |
| 원정 | 추가 기획 전까지 신규 출발을 중지했습니다. 진행 중인 원정의 귀환과 저장 데이터는 유지합니다. |
| 로켓 | 건조·탑승·발사 기능은 유지합니다. 원정 보상과 최종 방어의 연결은 후속 작업입니다. |
| 남은 문제 | 적이 벽 밖에서 멈춰 웨이브가 끝나지 않는 문제, 초반 연속 플레이와 오래된 검사 정비가 남아 있습니다. |

세부 수치와 검증 범위는 [웨이브 밸런스 기록](docs/BALANCE-WAVE-1103.md), 최신 진행 상황은 [프로젝트 로그](log.md)를 참고하세요.

## 기본 조작

| 입력 | 동작 |
| --- | --- |
| 좌클릭 / 드래그 | 장수 선택 / 여러 장수 선택 |
| Shift + 선택 | 기존 선택에 추가 |
| 우클릭 | 이동 또는 대상에 맞는 작업·공격 |
| A → 좌클릭 | 어택무브 |
| Ctrl + 숫자 | 부대 지정 |
| B | 건설 화면 |
| P | 일시정지 |
| M | 월드맵 |
| Z / C | 카메라 회전 |
| 마우스 휠 | 확대·축소 |
| 마침표 | 대기 중인 장수 찾기 |
| Esc | 메뉴 또는 현재 조작에서 돌아가기 |

선택 대상에 따른 명령과 단축키는 게임 화면의 명령 카드에서 확인할 수 있습니다.

## 개발 환경

- Unity `6000.5.8f1`
- 주요 씬: `Assets/_Project/Scenes/AntColony.unity`
- 게임 코드: `Assets/_Project/Scripts/`
- 검증 스크립트: `AgentScripts/`
- 에디터 제어: Unity Hub 관리 공식 CLI와 `com.unity.pipeline`

Unity Hub에서 프로젝트 폴더를 추가하고 지정된 에디터 버전으로 엽니다. 로컬 도구 경로와 연결 상태는 [작업 규칙](AGENTS.md)을 참고하세요. 이 저장소는 일부 외부 에셋과 프리팹을 커밋하지 않으므로, 새 환경에서 실행하려면 별도로 보관한 해당 파일이 필요할 수 있습니다.

# 개미 소굴 RTS

> **2026-09-11 개발 중 체크포인트:** 장수 중심 구조로 전환하다가 Claude 한도로 중단했습니다. 비행 인터페이스 컴파일 오류와 Safe Mode는 복구했고 보직별 공중 판정 검사는 통과했습니다. 장수 전환 전체는 미완료이며, 아래 구현 설명은 전환 전 검증 상태입니다. 다음 작업과 미완료 파일은 log.md를 확인하세요.

개미 군체를 성장시키며 자원을 모으고, 역할별 개미를 생산해 야생 생물과 적 세력에 맞서는 싱글 플레이 RTS 프로젝트입니다. 지상 위가 아니라 개미 소굴과 그 주변 생태계를 확장하는 흐름을 중심으로 개발하고 있습니다.

## 게임 설명

- 일개미로 Food와 Soil을 채집해 소굴의 자원과 저장 한도를 관리합니다.
- 밭을 건설해 성장한 작물을 반복 수확하고, 성장 시간과 남은 수확량을 확인할 수 있습니다.
- 연구소에서 낚시를 해금하면 해안에서 식량을 채집할 수 있습니다.
- 적 소굴의 모든 건물을 파괴하면 현장에 남은 Food·Soil·Special 전리품을 일개미로 운반할 수 있습니다.
- 여왕방에서 일개미를 생산하고, 일개미로 병영과 연구소를 원하는 위치에 건설합니다.
- 역할별 병영을 성장시켜 더 높은 티어의 전투 개미를 생산합니다.
- 역할별 연구소에서 공격력과 방어력을 연구합니다. 연구 효과는 이후 생산되는 유닛부터 적용됩니다.
- 야생 몬스터와 보스의 공격 패턴을 피하며 전투합니다.
- 플레이어 건물이 모두 파괴되면 패배합니다.

## 현재 구현 상태

| 구분 | 구현 내용 |
| --- | --- |
| 자원 | Food/Soil/Special 채집·반납과 저장 한도, 유닛 유지비·아사·반란, 밭 성장·반복 수확·상태 표시, 낚시 해금·재충전 |
| 조작 | 클릭·드래그·Shift 다중 선택, 대형 이동, 직접 공격, 어택무브 |
| 생산 | 여왕방의 일개미 생산, 역할별 병영의 독립적인 1~3티어 성장과 유닛 생산 |
| 건설 | 일개미의 자유 배치 건설, 건설 시간과 완공 처리 |
| 전투 역할 | Melee, Ranged, Defense, Flying, Support 프로토타입 |
| 연구 | 역할별 공격력·방어력 3단계 연구, 전체 일개미 낚시 해금 |
| 적·보스 | 야생 몬스터 추적·공격, MiniBird 텔레그래프 패턴, 소굴의 주기적 침공·본진 공격·수비 요격 |
| 약탈 | 임시 적 소굴 건물 전멸 후 실제 보유 자원 해금·운반, 적 건물 자동 교전 |
| 건물 전투 | 건물 체력·피해·파괴, 전체 건물 파괴 시 패배 판정 |
| 카메라 | 화면 가장자리 이동, 휠 줌, Q/E 90도 회전, 맵 범위 이동 제한 |

Support는 전용 유닛·병영·연구소와 연구 적용까지 구현했습니다. Flying은 고정 고도 직선 이동, 장애물 무시, 역할별 대공 제한과 지상 범위 공격 면역까지 구현했습니다. 농사와 낚시는 채집·창고 반납까지 연결한 최소 프로토타입입니다. 일개미는 한 짐을 반납하면 대기하므로 다시 채집 명령을 내려야 합니다.

적 소굴은 현재 고정 위치의 약탈 검증용 거점입니다. 주기적 침공·본진 공격·수비 요격은 추가 검증했으며, AI 경제 성장·랜덤 배치·유닛 약탈은 미구현입니다. 또한, Special의 강화·진화 소비처와 보스 전리품도 후속 작업입니다. 수치와 외형은 임시 설정입니다.

## 조작법

| 입력 | 동작 |
| --- | --- |
| 좌클릭 | 유닛 선택 / UI 버튼 사용 / 명령 위치 지정 |
| 좌클릭 드래그 | 범위 안의 유닛 다중 선택 |
| Shift + 좌클릭·드래그 | 기존 선택에 유닛 추가 |
| 우클릭 | 선택 유닛 이동 / 자원 채집 / 적 직접 공격 |
| A → 좌클릭 | 전투 유닛 어택무브 또는 대상 직접 공격 |
| Q / E | 카메라를 90도 회전 |
| 마우스 휠 | 카메라 확대·축소 |
| 화면 가장자리 | 해당 방향으로 카메라 이동 |
| Esc / 우클릭 | 건설 배치 또는 어택무브 모드 취소 |

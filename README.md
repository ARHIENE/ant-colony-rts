# 개미 소굴 RTS

정착지를 운영하며 습격 웨이브를 막는 싱글플레이 전략 게임입니다. 평화 시간에는 생산·건설·연구·치료·수리로 방어를 준비하고, 전투가 시작되면 장수를 직접 지휘합니다. Unity 6로 개발 중이며 PC를 대상으로 합니다.

## 플레이 구조

- **운영과 발전:** 식량과 생활 기반을 마련하고, 남는 인력과 물자로 장비와 방어선을 갖춥니다.
- **웨이브 방어:** 벽·탑·함정으로 무리를 막고, 장수의 배치·집중 공격·스킬·교대·후퇴로 대응합니다.
- **재정비:** 방어가 끝나면 평화 시간에 피해를 복구하고 다음 웨이브를 준비합니다.
- **최종 목표:** 로켓의 목적·최종 공세·승리 조건은 재설계 중입니다. 기존 건조·탑승·발사 구현은 보존하며 현행 확정 승리 조건으로 보지 않습니다.

직접 조작하는 단위는 장수입니다. 2026-11-12 재설계에 따라 병력 배정을 중단하고 장수 개인 체력·장비로 싸우도록 전환했습니다. 진형 효과·선택, 지휘 기술 성장, 시민 세금·이주·징집·수요와 관련 UI/신규 건설을 제거했습니다. 활성 기술은 15개이며 구 저장의 폐기된 값은 호환용으로 보존합니다. 지휘 능력치 제거에 따른 CA 재배분 정책은 아직 미정입니다. 시작 장수는 1~3명이며 정해진 건설 순서를 강제하지 않습니다.

## 현재 개발 상태

현재 개발 기준은 `develop`입니다. 2026-11-12 새 기획으로 장수3명·소형 숲의 첫3웨이브를 같은 새 게임에서 연속 실행했습니다. 공식 CLI의 정상 게임 명령으로 진행했으며 자원·체력 지급이나 적 삭제는 사용하지 않았습니다. 한 회차의 검증으로 출시 준비가 끝났다는 뜻은 아닙니다.

| 항목 | 상태 |
| --- | --- |
| 웨이브 진행 | 첫 평화 6일, 이후 4일. 시간이 끝나면 자동으로 시작하며, ‘지금 시작’으로 앞당길 수 있습니다. 본거지 장수가 0명이어도 진행합니다. |
| 전투 | 일반 적의 무리 표현과 웨이브 HUD를 구현했습니다. 방어시설의 효과와 초반 난이도를 조정 중입니다. |
| 작업·회복 | 건설 배송의 실제 픽업 경로를 작업 선택에 반영합니다. 안정된 장수는 평화 중 개인 체력을 회복하며 수면·휴식·치료가 이를 돕습니다. 전투 명령은 여가를 중단하고, 가까운 적이 있으면 일상 작업·수면보다 방어를 우선합니다. |
| 원정 | 추가 기획 전까지 신규 출발을 중지했습니다. 진행 중인 원정의 귀환과 저장 데이터는 유지합니다. |
| 로켓 | 건조·탑승·발사 기능은 유지합니다. 원정 보상과 최종 방어의 연결은 후속 작업입니다. |
| 남은 검증 | 벽 우회 경계 사례, 다른 시작 인원·지도·장비의 초반 밸런스, 후반 웨이브·장기 저장과 오래된 검사 정비가 남아 있습니다. |

최신 실제 결과와 한계는 [첫 3웨이브 검증 기록](docs/THREE_WAVES_1112.md), 이전 수치는 [웨이브 밸런스 기록](docs/BALANCE-WAVE-1103.md)를 참고하세요. 회복·전투 상태 회귀25개와 배송 경계 검사10개는 별도 폐기용 검사이며 자연 플레이 결과와 구분합니다.

2026-11-13 후속 검수에서는 같은 3웨이브 종료 상태부터 약362게임초를 진행해 세 장수의 질병 해소와 개인HP 회복, 정상 저장·재로드를 확인했습니다. 약초 공급을 연결하고 곰팡이 완치 후 1일 재감염 유예, 질병을 실제 쓰러짐으로 오인하던 기분 반응, 행동 불능 중 붕괴와 공격 붕괴 중 회복을 수정했습니다. 동료·시설 공격 붕괴는 한글 상태와 기존 위협 자동정지 설정에 연결합니다. 감염·저장27개와 붕괴·경고17개 회귀 검사는 별도 fixture입니다.

산성탑에 겹치던 이전 원통과 저장 복원 시 서 있던 시체 표시를 수정했으며, 야간 광량·폭풍 안개를 실제 화면으로 보정했습니다. 기본 자원 표시에는 흙이 포함되고 건설 툴팁은 오른쪽 설명 영역에서 확인합니다. 연구·식량 경제와 다른 시작 조건의 밸런스 검증은 아직 남아 있습니다.

2026-11-13 외형·모션 수정: 머리/얼굴 메시 파손과 흰 앞머리 중복을 수정하고, 눈 감기와 치료 침대 원본 수면 자세를 연결했습니다. 자원 작업 Mine/Chop/Dig의 도구 궤적에 맞춰 접근 거리를 보정했습니다. 곡괭이·도끼 최근접 측정은 각각2.2cm/1.4cm이며 전체 장비·프레임 무관통을 뜻하지 않습니다. 세부 검증 및 미완료 범위는 [모션·시설 통합 기록](docs/FINAL_MOTION_1113.md)에 정리했습니다.

## 개발 환경

환경 아트에는 귀여운 애니메이션풍 캐릭터에 맞춘 Meshy 모델 10종(기본 초가집·창고·망루, 나무·관목·바위·버섯·구리/철 광맥)과 지면 텍스처 8종을 연결했습니다. 숲·초원·해안·건조지대·고산·폐허의 기존 지형 규칙을 유지하며 외형을 교체합니다. 기본 재료가 아닌 개조 건물은 기존 재료별 모델 표현을 사용합니다. 제작 내역과 검증 범위는 [환경 에셋 기록](docs/ENVIRONMENT_ASSETS_1110.md)에 있습니다.

- Unity `6000.5.8f1`
- 주요 씬: `Assets/_Project/Scenes/AntColony.unity`
- 게임 코드: `Assets/_Project/Scripts/`
- 검증 스크립트: `AgentScripts/`
- 에디터 제어: Unity Hub 관리 공식 CLI와 `com.unity.pipeline`

Unity Hub에서 프로젝트 폴더를 추가하고 지정된 에디터 버전으로 엽니다. 로컬 도구 경로와 연결 상태는 [작업 규칙](AGENTS.md)을 참고하세요. 이 저장소는 일부 외부 에셋과 프리팹을 커밋하지 않으므로, 새 환경에서 실행하려면 별도로 보관한 해당 파일이 필요할 수 있습니다.

### 2026-11-12 Claude 중단 작업 인계

Windows 직접 마우스 시험은 클릭 오차로 실패했으며, 전체 재설계 완료를 뜻하지 않습니다. 세부 결과는 [인계 검증](docs/COMMANDER_ONLY_1112.md)에 기록합니다.

# 개미 소굴 RTS

> **장수 중심 1차 프로토타입:** 일반개미 수량을 장수에게 배정해 조작하는 구조입니다. 장수 배정·생산·연구·건설·채집·낚시·약탈·수비와 전투 경험치·레벨 성장 검사를 통과했습니다. 본거지 + 월드맵 원정 구조로 전환해 과학 트리·수송수단·동시 원정·화물 귀환까지 검증했으며 최종 밸런스는 후속 작업입니다.

개미 군체를 성장시키며 자원을 모으고, 일반개미를 배정받은 장수 부대로 야생 생물과 적 세력에 맞서는 싱글 플레이 RTS 프로젝트입니다. 개미 소굴과 그 주변 생태계를 확장하는 흐름을 중심으로 개발하고 있습니다.

## 게임 설명

- 병력을 배정받은 장수로 Food와 Soil을 채집해 소굴의 자원과 저장 한도를 관리합니다.
- 밭을 건설해 성장한 작물을 반복 수확하고, 성장 시간과 남은 수확량을 확인할 수 있습니다.
- 여왕방에서 낚시를 해금하면 모든 장수가 해안에서 식량을 채집할 수 있습니다.
- 본거지 주변은 거의 빈 땅이며, 적 소굴과 보스는 월드맵의 원정 거점에 있습니다. 본거지에는 드물게 소규모 침입(적 장수 포함)만 들어옵니다.
- 과학연구소에서 차량·비행기를 연구·건조하면 월드맵이 열리고, 장수와 병력을 수송수단에 태워 다른 세력 거점으로 원정을 보냅니다.
- 원정지의 모든 건물을 파괴하면 현장에 남은 Food·Soil·Special 전리품을 장수로 운반할 수 있고, 전리품은 수송수단 화물로 실렸다가 귀환할 때 본거지 창고에 들어옵니다.
- 여왕방에서 일반개미 수량을 생산하고 장수에게 배정·회수합니다. 병력 수가 부대 체력이며 손실은 일반개미 총수에서 차감됩니다.
- 장수의 허용 보직과 관직을 변경할 수 있습니다. 관직 변경은 무료이며 지휘한도를 넘는 변경은 거부됩니다.
- 장수로 건물을 배치하면 대기 일반개미가 건설 인력으로 예약되고, 완공·취소 시 한 번만 복귀합니다.
- 역할별 병영은 유닛 생산 없이 티어 강화 연구를 제공합니다.
- 병영의 역할별 공격력·방어력 강화는 현존 부대에도 즉시 적용되며 보직 변경 시 해당 역할의 강화치로 바뀝니다.
- 연구소는 선택한 장수 한 명을 개별 강화합니다. 공격(병력 1마리당 +2)·방어(+1) 각 3단계, 3초, 비용은 다음 단계 × 식량 45·흙 30입니다. 장수의 현재 보직과 같은 역할 연구소에서만 시작하며, 얻은 강화는 보직을 바꿔도 유지됩니다.
- 한 장수는 동시에 한 연구소에서만 강화되고, 연구소는 한 번에 한 장수만 연구합니다. 연구 중 연구소나 장수가 비활성화·파괴되면 완료되지 않으며 비용은 환급되지 않습니다.
- 장수는 레벨 2에 강타, 레벨 3에 방어 태세를 선택 패널 버튼으로 직접 시전합니다(자동 시전 없음). 강타는 장전 후 다음 실제 타격 한 번만 피해 2배, 장전 시점부터 재사용 대기 15초입니다. 방어 태세는 5초간 방어력 +5, 재사용 대기 20초입니다. 병력 0·비활성 장수는 시전할 수 없고, 보직 변경 시 상태가 유지되며, 비활성화되면 장전·태세만 해제되고 대기는 환급되지 않습니다. 강타로 처치해도 경험치가 지급됩니다(수치 임시).
- 장수는 일반 채집·밭·낚시에서 실제로 캐낸 자원 100개마다 채집 숙련도가 1레벨 오르고(최대 5), 레벨당 채집 속도가 10% 빨라집니다. 운반량·병력·전투·건설에는 영향이 없고, 보직·관직·병력 변경과 비활성화에도 유지되며 선택 패널에 레벨·진행도·보너스가 표시됩니다(수치 임시).
- 야생 몬스터와 보스의 공격 패턴을 피하며 전투합니다. MiniBird 보스를 처치하면 즉시 지급 없이 주변 지면에 Food 100·Special 20 전리품 노드가 남고, 장수로 채집해 창고에 반납합니다(수치 임시).
- 플레이어 건물이 모두 파괴되면 패배합니다.

Support는 반경 6m 안의 다른 아군 장수에게 중첩 없이 공격력·방어력 +1을 제공하며 병력이 없으면 버프가 꺼집니다(수치 임시). Flying은 직선 비행, 장애물 무시, 역할별 대공 제한과 지상 범위 공격 면역을 지원하며 지상 보직으로 바꿀 때 유효한 NavMesh에 착륙합니다. 농사와 낚시는 채집·창고 반납까지 연결한 최소 프로토타입입니다. 장수는 한 짐을 반납하면 대기하므로 다시 채집 명령을 내려야 합니다.

장수는 세 경로로 늘릴 수 있습니다. 활성 양육실이 있으면 서로 가까이 있는 장수 쌍은 호감도가 쌓여 식량과 정원 조건이 맞으면 출산하고, 태어난 장수는 부모의 성격·보직을 물려받고 충성심은 부모 평균에 편차를 더해 정해집니다. 스카우트 파견소는 식량과 개미를 소모해 스카우터를 내보내고, 세력이 클수록 높아지는 확률로 장수를 영입합니다. 침공 파동을 이끄는 적 장수는 쓰러지면 수용소에 자리가 있을 때 포로가 되며, 회유는 포로의 충성심·성격에 따른 확률 판정으로 실패해도 반복 시도할 수 있고, 방치하면 탈출하며 언제든 처형할 수 있습니다. 수치는 전부 임시 설정입니다.

병력 0인 장수는 작업·전투를 중단하고 선택·보충 대상으로 남습니다. 플레이어 장수의 사망·포로 규칙은 여전히 미정이며, 포로 경로는 적 장수에만 적용됩니다. 유지비 부족 시 대기 또는 배정 일반개미 1마리를 잃으며, 건설 인력만 남은 경우 예약을 유지하는 임시 정책입니다. 운반·건설 중에는 병력 배정·회수와 보직 변경을 제한합니다.

과학연구소는 인구 60, 낚시 해금, 티어 2 병영을 모두 갖춰야 지을 수 있습니다. 차량을 연구·건조해야 비행기 연구가 열리고, 첫 수송수단이 완성되면 월드맵이 해금됩니다. 차량은 장수 포함 40명·편도 20초, 비행기는 100명·편도 10초를 태웁니다. 탑승한 장수는 병력·성장·숙련도를 그대로 유지하지만 병력 배정·회수와 전투는 할 수 없으며, 한 거점에는 수송수단 한 대만 들어갑니다. 원정 중에도 본거지는 계속 돌아갑니다. 수치는 전부 임시 설정입니다.

원정 거점의 적 소굴은 건물·전리품·생성 지점의 상대 배치를 유지합니다. 살아 있는 건물 수에 따라 Food·Soil을 생산하고 Soil을 소비해 최대 5동까지 확장하며, 침공 개체 생산에도 실제 Food 재고를 사용합니다. 소굴 재고에는 상한이 있어 장기전에서 전리품이 무한히 불어나지 않고, 확장 건물은 본진에서 초기 배치 최소 거리 안쪽에는 세워지지 않습니다. 재고가 모자라 한 마리도 내보내지 못한 침공 파동은 사라지지 않고 짧은 간격으로 다시 시도합니다. 다수 AI 세력·AI 간 전투·유닛 약탈과 Special의 강화·진화 소비처는 후속 작업입니다. 수치와 외형은 임시 설정입니다.

## 조작법

| 입력 | 동작 |
| --- | --- |
| 좌클릭 | 유닛 선택 / UI 버튼 사용 / 명령 위치 지정 |
| 좌클릭 드래그 | 범위 안의 유닛 다중 선택 |
| Shift + 좌클릭·드래그 | 기존 선택에 유닛 추가 |
| 우클릭 | 선택 유닛 이동 / 자원 채집 / 적 직접 공격 |
| A → 좌클릭 | 전투 유닛 어택무브 또는 대상 직접 공격 |
| +1 Ant / Return 1 | 단일 선택 장수에게 일반개미 1마리 배정 / 회수 |
| Next Role / Next Rank | 선택 장수의 허용 보직 / 관직 변경 |
| Strike / Guard | 단일 선택 장수의 강타 장전 / 방어 태세 시전. 버튼에 잠김(`Lv2`/`Lv3`)·준비·발동(`ON`)·재사용 대기(초) 표시, 시전 불가(잠김·병력 0·발동 중·대기) 시 버튼 비활성, 다중 선택 시 시전 안 함 |
| Produce Ant / Unlock Fishing | 여왕방에서 일반개미 생산 / 글로벌 낚시 연구 |
| ATK / Armor 연구 버튼 | 장수 한 명을 선택해 현재 보직의 연구소에서 개별 공격 / 방어 강화 |
| Dispatch / Next Post | 스카우트 파견 / 조작할 파견소 전환 |
| Next Prison / Next POW | 수용소 / 선택 포로 전환 |
| Persuade / Execute | 선택 포로 회유 / 처형 |
| World / Science | 과학·월드맵 패널 열기. 과학연구소 건설, 차량·비행기 연구·건조, 거점 선택, 탑승·출정·전장 전환·귀환 |
| Q / E | 카메라를 90도 회전 |
| 마우스 휠 | 카메라 확대·축소 |
| 화면 가장자리 | 해당 방향으로 카메라 이동 |
| Esc / 우클릭 | 건설 배치 또는 어택무브 모드 취소 |

## 기술 정보

- Unity `6000.5.8f1`
- Universal Render Pipeline `17.5.0`
- Input System `1.20.0`
- AI Navigation `2.0.14`
- 주요 씬: `Assets/Scenes/AntColony.unity`
- 주요 코드: `Assets/Scripts/`
- 에디터 제어·검증: 공식 Unity CLI와 com.unity.pipeline
- Pipeline 패키지: `0.7.0-exp.1`
- 실행 검증 스크립트: `AgentScripts/AcquisitionSetupChecks.cs`(Edit 모드), `AcquisitionBuildingChecks.cs`, `CommanderAcquisitionChecks.cs`, `AgentScripts/CommanderChecks.cs`, `CommanderEdgeChecks.cs`, `CommanderProgressionChecks.cs`, `ActiveSkillChecks.cs`, `LabUpgradeChecks.cs`, `SupportChecks.cs`, `RegressionChecks.cs`, `FishingChecks.cs`, `RaidChecks.cs`, `InvasionChecks.cs`, `SceneInvasionChecks.cs`, `EnemyColonyPlacementChecks.cs`, `EnemyColonyEconomyChecks.cs`
- 각 검사는 새 Play 모드에서 `unity command run_script --file AgentScripts/<검사명>.cs --timeout_ms 60000 --timeout 90`으로 실행합니다. 검사 후 Play를 종료해 변경된 게임 상태를 초기화합니다.

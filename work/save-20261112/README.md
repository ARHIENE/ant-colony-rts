# 2026-11-12 통합 SAVE 복원

11월11~12일 애니메이션/장비/외형 및 다른 채팅의 출시 전 게임성·환경·UI 작업을 통합한다. 변경된 대용량/바이너리 원본은 gzip→350KB조각→base64의 SHA256 검증 묶음으로 보관한다. 동일 데이터는 중복 저장하지 않는다. 기존11월7일과11월10일 복원을 먼저 수행하고 아래를 실행한다.

```text
python work/save-20261112/restore.py --check
python work/save-20261112/restore.py --apply
```

원본은 로컬에 그대로 있다. 따라서 대용량 원본 경로의 Git 수정/미추적 표시는 예상된다. 충돌한 기존 파일은 restore-backup으로 보존하며 prefab/prefab.meta 및 외부 에셋스토어 패키지는 커밋하지 않는다. 실패한 외형 후보는 게임에서 제외한 로컬 보관자료이며 원격 릴리스 원본에 포함하지 않는다.

검증 범위와 남은 legacy 행동·정밀접촉 한계는 docs/ANIMATION_NATIVE_1112.md 및 log.md 참조. 모든 수집 모션119종을 모든 게임 행동119종으로 연결했다는 의미는 아니다. 작업3GIF는 실제0.25배시뮬레이션, 무기10GIF는 원본모션 미리보기다. GIF100ms 간격은 실제 렌더간격과 다를 수 있다.

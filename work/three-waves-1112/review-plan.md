- 자원·장비 지급, 공사/연구 즉시 완료, 체력 복원, 적 제거, 웨이브 상태 덮어쓰기 없음.

## 실행

Unity 소유를 받은 뒤 compile-only로 검사 스크립트 검증 → Prepare → orders.json 작성 후 Step 반복 → Finish. 각 Step은 종료/예외 때 일시정지하고 상태/화면을 남긴다. Prepare/Finish는 사용자 설정, 저장 루트, Game View 크기를 보존·복원한다. 마지막 Play 종료와 Edit/ready, 콘솔을 확인한다.

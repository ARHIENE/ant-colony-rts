# 2026-11-07 통합 SAVE 복원

일반 GitHub 파일에는 코드·문서·작은 에셋이 저장되어 있다. 큰 씬·그래프·폰트·Meshy 애니메이션/텍스처는 API 전송 제한을 피하기 위해 이 폴더의 archive.b64.partNNN에 무손실 tar.xz 압축으로 보존했다. 기존 큰 파일의 일반 경로는 이전 버전일 수 있다. 현재 PC 원본은 최신이다.

새 복제본에서 Python으로 restore.py를 실행하면 manifest.json의 SHA256을 검증한 뒤 큰 파일을 원래 위치에 복원한다. 같은 이름의 로컬 수정이 있다면 먼저 별도 보존한다. .prefab/.prefab.meta는 포함하지 않았다.

제작용 Blender 원본·중복 다운로드·불합격 시험 원본은 기존 로컬 art/work 폴더에 유지하며 완료된 게임 기능으로 취급하지 않는다.

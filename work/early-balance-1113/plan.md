# 초반 운영·전투 재검증 — 2026-11-13

사용자 요청: 외형 세션과 충돌 없이 초반 식량·연구·전투를 개선하고 새 게임에서 첫 3웨이브까지 확인한다.

## 비교 조건

- 3명, 소형 숲, 시드 261106. 같은 후보 생성과 초기 건설·채집 명령을 사용한다.
- 기준 회차와 수정 회차에서 처음 360게임초의 명령 순서를 같게 한다. 이후 수정 회차는 3웨이브 종료와 복구까지 이어간다.
- 정상 생산·운반·연구·전투 명령만 사용한다. 자원·체력 지급, 연구 강제 완료, 적 삭제는 하지 않는다.
- 준비는 3배속, 전투는 1배속. CLI 명령으로 플레이하며 Windows 마우스로 플레이했다고 보고하지 않는다.
- 사용자 저장 슬롯 대신 격리 저장 경로를 쓴다. 설정·저장 경로·Game View는 검증 후 복원한다.
- 실제 HUD 캡처에서 연구 진행, 요리 재고, 전투 대상과 체력을 확인한다.

## 준비한 후보 (아직 Assets에 적용하지 않음)

- 정착 시대 연구 비용: 식량 50→25, 흙 50→30. 이후 시대 비용과 연구량 200은 유지한다. 이전 회차에서 식량 47로 첫 연구를 시작하지 못한 병목을 완화한다.
- 간단한 요리 작업량: 10→7.5. 재료 2와 산출 1은 유지한다. 진행 중인 옛 조리 저장의 누적 작업량이 새 완료량보다 클 때 음수 작업·경험치를 만들지 않도록 남은 작업량을 0 이상으로 제한한다.
- 평화 길이·적 마릿수·적 구성은 변경하지 않는다. 첫 방어는 장수만으로, 2~3웨이브는 연구로 연 방어시설을 활용한다. 전투 수치 변경은 실제 관찰 후 결정한다.

## 확인할 것

- 첫 연구를 시작하고 완료하는 시간, 그때의 식량과 조리 재고.
- 생활·이동·작업·성장 대기·기타 정지 시간을 구분한다. 전투 중 정지를 순수 대기로 세지 않는다.
- 첫 방어에서 적을 읽고 집중 공격·교대·후퇴할 시간이 있는지.
- 2~3웨이브에서 방어시설과 지휘가 피해를 줄이는지, 이후 복구·연구를 이어갈 수 있는지.
- 저장·재로드와 기존 연구/조리 진행 상태의 호환.

## 협업

외형 세션이 Unity를 사용 중이다. 명시적 반환 전 Assets 적용과 에디터 조작을 하지 않는다. 외형·농사·건설 접점 파일은 수정하지 않는다.

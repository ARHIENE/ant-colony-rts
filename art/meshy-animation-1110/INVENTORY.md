# Meshy 프리셋 수집 2026-11-10

신규 **81종**, 기존 보유 38종과 합계 **119종**. 이번 폴더 FBX는 82개이며 Shot_and_Blown_Back은 기존 보유 모션 재다운로드다.

## 검증과 상태

- 공식 Meshy UI에서 프리셋 추가 후 현재 모션 / Mixamo / FBX / 30fps로 다운로드. Axe_Stance 외에는 피부 없이 내보냈다.
- 다운로드 ZIP 전체 CRC 검사 통과. 각 ZIP의 FBX 추출, SHA-256과 AnimationCurve/AnimationStack 데이터 확인. 전체 추출 약 77MB.
- Assets 밖에 보관했다. 이번 모션의 Unity 임포트, 실제 행동 연결, 파지/관통/무릎/루프 품질 검증은 미완료다.
- 모듈형 헤어·얼굴·의상은 교체하지 않았다. 공통 리그 리타게팅 후 여러 외형에서 검사해야 한다.
- 대기 검색 중 Long_Breathe가 중복 다운로드돼 신규 수량에서 제외했다. 대기/대기1 자체는 다운로드 완료로 계산하지 않는다.

## 비용 확인

- 시작 표시 755. 마지막 표시 737. 크레딧 사용 내역에서 2026-11-10 22:55 텍스트를 이미지로 -9 두 건을 확인했다. 이 채팅은 이미지 생성을 실행하지 않았다.
- 확인한 최신 내역에는 프리셋 다운로드 차감 항목이 없다. 단순 잔액 차이는 프리셋 비용으로 계산하지 않는다.
- credit-history.png와 meshy-collected.png에 화면 보관.

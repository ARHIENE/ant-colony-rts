## 파일을 받은 뒤 적용 조건

- 다운로드 파일명·크기·SHA256을 기록하고 이미 받은 동일 파일은 다시 받지 않는다.
- 텍스처 포함 여부, UV와 표면 깨짐을 확인한다. 3K 저장고·화덕은 현재 최종 채택 대상이 아니다.
- 벽은 높이 2.4m, 화덕 작업대는 약 0.85m를 목표로 기존 캐릭터·그리드와 실측 비교한다. 생성 프롬프트 치수는 실제 FBX 치수 검증을 대체하지 않는다.
- 벽 가장자리·지붕 이음새·피벗을 맞춰 연결 시 틈과 겹침을 확인한다.
- 목책문은 문짝과 기둥이 분리됐는지 검사하고, 필요하면 메시를 분리해 경첩을 설정한다. 현재 문 개폐 동작은 구현·검증하지 않았다.
- 저장고 입출고 접근점, 화덕 조리 위치와 손·도구 접점을 기존 행동에 연결한 뒤 Unity에서 확인한다.
- 현재 게임 코드, 리소스 매핑, 저장 데이터는 변경하지 않았다. Unity 적용 완료로 기록하지 않는다.

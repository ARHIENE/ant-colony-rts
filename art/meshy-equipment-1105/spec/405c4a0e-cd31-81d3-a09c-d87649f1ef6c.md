## 1. 플레이 방식과 자동화의 경계

- 플레이어는 나무·광맥·야생 식물에 작업을 지정하고, 청사진·작물·생산 주문·치료 방침·시설 설정을 정한다. 평시 장수를 하나씩 선택해 일터로 보낼 필요가 없다.
- 장수는 작업표에서 허용한 일 중 실행 가능한 요청을 고르고 이동·도구 사용·준비·작업·마무리를 수행한다. 시민은 수량 인구·납세·병역을 담당하며 평시 작업자가 아니다.
- <b>자동 작업은 무료 자원 생성이나 순간 이동이 아니다.</b> 준비 재료·화물·환자·도구는 기존 규칙에 따라 실제 위치에서 이동하고 실제 작업을 거쳐 결과를 만든다.
- 새로운 자연 자원 지정, 제조법 추가, 연구 주제 선택, 전쟁·교역 계약·출정·수술·도축·처형·로켓 가동/발사는 플레이어가 결정한다. 부족하다고 장수가 이를 임의 실행하지 않는다.
- 고정 담당을 이미 확정한 연구·장비 수리·인재 평가/외부 조사는 한 번 담당을 지정한 뒤 자동 수행한다. 고정 담당 부재에 대한 교대 규칙은 각 분야의 기존 예외를 따른다.
- 출전 장수는 전투 직접 조작을 유지한다. 원정의 현지 채집·구조·적재는 지정한 명령과 허용 인원 범위에서 자동 진행하며, 새 출정이나 적대 지역 진입을 임의 결정하지 않는다.

## 2. 작업이 만들어지는 세 가지 방식

| 발생 방식 | 예 | 반복 기준 |
| --- | --- | --- |
| 한 번 지정 | 벌목·채굴·야생 채집·건설·철거·사냥·구조·수술 | 지정한 대상/수량을 마치면 종료 |
| 시설 목표 | 작물, 지정 횟수/재고 유지/계속 생산, 먹이통 목표, 허용 창고, 행정 | 설정을 유지하는 동안 조건에 맞춰 생성·대기·재개 |
| 허용된 유지관리 | 손상 건물 수리, 관리 구역 화재, 치료 방침상 처치, 바닥 물자 운반 | 실제 필요가 있을 때만 생성, 필요 해소 시 종료 |

- 같은 요청을 다시 클릭해도 동일 대상·작업·단계가 중복 생성되지 않는다. 여러 장수 협동을 허용한 건설은 요청 하나에 여러 작업 자리만 배정한다.
- 상태는 <b>대기 → 준비/예약 → 이동·배송 → 작업 → 마무리 → 완료</b>다. 실행 조건 부족은 <b>조건 대기</b>, 플레이어 중지는 <b>일시중지</b>, 철회는 <b>취소</b>로 구분한다.
- 조건 대기는 담당 장수를 현장에 묶어 두지 않는다. 다른 가능한 일을 수행하다 조건 회복 후 다시 경쟁한다. 고정 담당 요청은 다른 장수에게 넘어가지 않는다.

## 3. 누가 무엇을 먼저 하는가

작업표는 기존16칸을 유지한다: 소화·채집·건설·농사·낚시·제작·연구·의료·수리·운반·사냥·요리·예술·치우기·행정·사육. 각 장수의 금지/특성 잠금을 존중하며, 연구·고정 담당 예외도 해당 작업 금지를 우회하지 않는다.

- 먼저 해당 작업의 금지·특성 잠금·출전/탑승/포로/쓰러짐·지역·기술/도구·시설·경로 조건을 검사한다. 기술이 낮다는 이유만으로 가능한 작업을 임의 금지하지 않는다.
- 자기 식사·수면·위생·치료와 생존 행동은 기존 생활 규칙을 따른다. 노란 경보는 이를 강제로 끊지 않는다. 빨간 경보의 생활 중단·의료 간호 중단은 기존 확정 규칙을 유지하며 금지 작업을 해제하지 않는다.
- 평시 다음 작업 선택 순서는 <b>노란 경보 대상 → 장수 작업 종류 우선순위 → 대상 우선순위 → 실제 이동 거리 → 오래 기다린 요청</b>이다. 작업표·대상 우선순위는 모두 1\~9, 기본 5, 높은 값 우선이며 작업표 0은 금지다.
- 소화 작업표의 기존 기본 우선순위 9 예외는 유지한다. 그 밖의 미설정 작업/대상은 기본5다. 대상 우선순위와 작업표 값은 서로 다른 항목이다.
- 동률 끝까지 같으면 저장되는 요청 ID·장수 ID로 순서를 고정한다. 기술 최고 장수가 모든 작업을 독점하는 새 규칙은 만들지 않는다.
- 의료 내부의 생명 위험→중증→경증, 해체 등록 순서, 고정 집도의·원제작자 조건은 공통 정렬보다 앞서 해당 분야 안에서 적용한다.
- 더 높은 우선순위 요청이 생겨도 매 프레임 일을 갈아타지 않는다. 일반 작업은 현재 작업 단위가 끝난 뒤 다시 고른다. 운반은 현재 한 짐의 입고/안전한 내려놓기까지, 진행 중 처치·수술은 기존 중단 규칙을 따른다.
- 플레이어가 장수를 선택해 직접 우선 작업을 지시하면 가능한 대상인지 확인하고 현재 요청을 안전하게 중단한다. 작업 금지·도구·연구·환자/시설 조건을 우회하지 않는다. 지시 거부는 이유를 표시한다.

## 4. 자연 자원 — 벌목·채굴·야생 식물

- 작업 도구는 <b>벌목 / 채굴 / 야생 채집 / 지정 취소</b>다. 장수 선택 없이 클릭 또는 드래그로 현재 존재하는 적격 대상을 지정한다. 종류가 다른 대상은 무시하고 지정 전 대상 수·불가 사유를 표시한다.
- 범위는 현재 대상 집합을 고르는 도구다. 지정 사각형이 영구 자동 수확 구역이 되지 않으며 나중에 자란 다른 식물·자원을 자동 추가하지 않는다.
- 벌목은 도끼, 암석/광맥은 곡괭이, 모래·점토는 삽 등 기존 도구 조건을 사용한다. 야생 열매·버섯은 기존 맨손 조건을 유지한다. 미성숙 야생 식물 수확은 성숙 대기로 두며 임의 파괴하지 않는다.
- 채굴은 채굴 가능한 표시 부분을 지정한다. 아직 없는 지하층·터널 굴착이나 매장량 재생을 자동 추가하지 않는다. 도구/연구가 부족하면 무엇이 부족한지 표시한다.
- 담당 장수가 접근→작업→해당 대상/지정 부분 완료→자원 바닥 배출 순으로 처리한다. <b>자연 채취 작업과 운반은 분리한다.</b> 같은 장수가 두 작업을 허용했으면 작업표 판단에 따라 운반까지 할 수 있다.
- 재성장 식물은 해당 수확 완료 때 지정이 해제된다. 다음 수확은 다시 지정한다. 영구 벌목장·재식림·야생 자동 재수확 구역은 이번 범위에 넣지 않는다.
- 장수 선택 후 자연 자원 우클릭은 그 대상 하나를 같은 작업으로 지정하고 해당 장수에게 우선 작업을 요청하는 빠른 조작이다. 다른 주변 자원을 자동 지정하지 않는다.
- 채집 금지는 지정 여부와 별개다. 금지 대상은 수동·자율·경보 모두 불가하며 금지 해제만으로 지정 작업이 생기지 않는다.
- 지정 취소는 아직 남은 자연 채취 작업만 철회한다. 이미 나온 자원·획득 기록은 삭제하지 않는다. 중간 진행 보존은 해당 자원 규칙을 따르며, 취소 자체가 작업 완료나 자원 지급을 발생시키지 않는다.

## 5. 건설·철거·이동·개보수

- 플레이어가 위치·종류·재료를 정해 청사진을 배치한다. 재료가 부족해도 배치 가능하다. 예약·배송 요청이 만들어지고 운반/건설 가능 장수가 기존 담당 범위에 따라 가져온다.
- 장식 가구는 기존 예술 작업으로 자동 제작/설치하고 담당 예술 기술로 품질을 결정한다. 일반 건설 작업으로 바꾸거나 예술을 새 기술/새 작업으로 중복 추가하지 않는다.
- 필요한 재료·시공 자리·경로가 준비되면 건설 장수가 자동 착수한다. 건설 협동은 기존 허용 인원·작업량 규칙을 사용하고 자원을 중복 소비하지 않는다.
- 재료 부족 요청 때문에 뒤의 가능한 건설이 멈추지 않는다. 재료가 생기면 다시 실행 후보가 된다. 새 공급품은 이미 진행 중인 배송 예약을 포함해 중복 배정하지 않는다.
- 철거·가구 포장 이동·재설치·재료 개보수는 각각 플레이어 지시가 필요하다. 장수가 동선 개선이나 자원 부족을 이유로 임의 철거하지 않는다.
- 건설 취소 100%·완성 시설 철거 70%, 가구 포장 시 내용물 배출·설정 보존, 재개발 보상금 비환급 등 기존 분야별 반환 규칙을 유지한다. 모두 같은 환급률로 통합하지 않는다.
- 생활 공간·출입구가 막혀 준비 불가하면 막힌 위치·원인을 표시한다. 장수가 벽을 임의 파괴하거나 출입 권한을 무시하지 않는다.

## 6. 농사·낚시

- 밭과 작물을 정하면 농사 장수가 자동 파종·비료 사용·성숙 수확한다. 성장은 장수 작업이 아니라 기존 환경/계절 계산이다. 밭마다 고정 장수를 두지 않는다.
- 수확물은 바닥에 배출하고 운반 요청으로 옮긴다. 작물을 유지하면 같은 밭에서 다음 재배 주기를 자동 시작한다. 야생 식물 일회 지정과 구분한다.
- 씨앗·물·비료 등 각 작물의 실제 필수 조건을 검사한다. 비료 선택 기능은 기존대로 비료가 없어도 성장하는 규칙을 유지한다. 없는 관수·제초 비용을 임의 추가하지 않는다.
- 해금된 낚시터는 낚시 작업표에 따라 자동 작업한다. 기존 계절 어획 한도·다음 계절 회복·날씨 보정과 운반 방식을 유지한다. 미지정 자연 자원 금지가 낚시와 밭을 막지 않는다.
- 작물 변경·휴경·시설 중지는 다음 가능한 작업 단계에 반영하고 이미 나온 수확물을 삭제하지 않는다.

## 7. 제작·조리·약품·재활용·장비 수리

- 시설마다 제조법과 <b>지정 수량 / 목표 재고 유지 / 계속 생산</b>을 정한다. 가능한 장수가 준비·작업·완성품 배출을 자동 수행한다.
- 목표 재고는 기존 사용 가능한 완성품 기준으로 진행 중인 확정 산출·배송 중 수량을 포함해 중복 생산을 막는다. 원정/교역 반출 예약품·부패품·사용 불가품의 포함 여부는 기존 품목별 계산을 따른다. 순환 계산이나 음수 예약은 허용하지 않는다.
- 재료·연료 배송은 실제 요청으로 처리한다. 재료가 없으면 플레이어가 이미 설정한 상류 생산 주문/지정 채취가 이를 공급한다. <b>없는 제조법을 자동 추가하거나 미지정 나무를 자동 베어 부족분을 메우지 않는다.</b>
- 실행 불가능한 주문은 원인을 보이며 뒤의 실행 가능한 주문을 처리한다. 재료/전력 회복 시 미완료 주문을 재개한다. 시작 시점 소비·출력 공간·열화/부패는 기존 시설 규칙을 따른다.
- 일반 미완성품은 원제작자만 계속 제작한다. 요리는 다른 요리사가 이어받을 수 있다. 장비 수리는 지정 수리자가 쉬면 대기하고 자동 교대하지 않으며 플레이어가 변경할 수 있다.
- 재활용은 플레이어가 품목을 지정한 경우만 실행한다. 착용/예약 장비 해제 확인·회수 비율·핵심물 보호는 유지한다. 생산 부족을 해결하려고 장비를 임의 분해하지 않는다.
- 의료용 약품·동물약·수술 키트 생산은 기존 의료 작업과 의료 기술 담당을 유지한다. 요리/일반 제작으로 바꾸지 않는다.
- 장비 수리 요청→담당 지정→재료/작업 차례 확보→착용자 반납→수리→원래 착용자 회수/재장착을 자동으로 이어 준다. 소집 중 반납/자동 재장착을 위해 전투를 이탈하지 않는다.

## 8. 운반·창고·전력/유체 설비

- 운반 작업은 허용된 바닥 물품, 건설 재료, 먹이통 보충, 생산 시설 재료, 지정 적재/하역 등 실제 수요에서 발생한다. 같은 물자는 운반 한도까지 묶되 생물·환자는 기존 한 번 1개체 예외를 유지한다.
- 품목 허용·우선순위·빈 공간·실제 입고 지점·도달 경로를 확인하고 물량과 목적지 공간을 함께 예약한다. 목적지가 없으면 물품을 바닥에 유지하며 줍기/내려놓기를 반복하지 않는다.
- 물자가 창고에 들어간 뒤 다른 창고의 우선순위가 올라갔다고 자동 재배치하지 않는다. 실제 사용/생산/지정 반출을 위한 꺼내기는 허용한다.
- 정전이면 작업 요청과 유효한 진행도를 남기고 장수는 다른 일을 한다. 복구 후 재개하며 중복 시작 비용을 내지 않는다. 부족 전력은 건물별 전력 순위1\~9대로 공급하고, 작업/운반 우선순위와 구분한다. 기본 냉장8·생산5·전등3(잠정), 선택→상세에서 변경하고 저장한다. 남은 전력으로 감당할 수 없는 부하는 멈추되 다른 작은 부하를 함께 끄지 않는다.
- 기존 수동 발전·급수 시설은 작업표 담당자가 수요/목표에 따라 운전한다. 자동 설비는 전력·연료·입출력 조건만 맞으면 자체 작동하고 장수는 허용된 보급/정비를 맡는다.
- 배관·탱크는 기존 연결/용량/허용 규칙에 따라 흐른다. 부족하다고 신규 배관·펌프·발전소를 자동 건설하지 않는다. 논리 회로·센서·복잡한 전력 자동화는 별도 기획/연구 범위로 유지한다.

## 9. 연구·행정·인재 평가

- 연구는 주제와 연구소별 담당 장수를 한 번 정하면 이동·연구·생활 후 복귀가 자동이다. 담당 부재 시 진행을 보존하며 임의 대체하지 않는다. 연구소 1곳 1명, 복수 연구소 같은 주제 참여, 주제 완료 뒤 자동 다음 연구 없음을 유지한다.
- 행정은 설치된 시설의 실제 업무 수요를 작업표에 따라 자동 처리한다. 담당이 없다고 세금/이주 기본 동작을 정지시키지 않는다.
- 내부 평가는 지정 평가자가 정해진 갱신 주기에 수행한다. 외부 조사는 대상·방식·담당을 플레이어가 정한 뒤 이동→조사→귀환→보고를 진행한다. 새 조사·외교 약속·자동 전쟁을 선택하지 않는다.
- 연구는 기존 연구 작업표 칸의 허용/금지와 별도로 연구소 담당을 지정한다. 조사는 작업표에 새17번째 칸을 추가하지 않고 전용 평가/파견 담당 지정으로 수행한다.

## 10. 의료·구조·생활

- 허용 의료 장수는 기존 치료 방침에 따라 환자 발견→접근 가능한 약품/침상 확보→구조·급식·처치를 진행한다. 무약 처치·자가 처치 가능 범위는 기존 의료 규칙을 사용한다.
- 같은 의료 담당의 대상 선택은 생명 위험→중증→경증, 같은 단계에서 대상 우선순위·거리·대기 순이다. 실제 진행 중 처치/수술을 단순 새 요청 때문에 끊지 않는다.
- 수술은 플레이어 요청과 필요한 확인 후에만 준비한다. 자동 집도의 선택을 허용한 시술은 기존 의료 능력 기준, 고정 집도 요청은 해당 담당을 따른다.
- 약품/수술 재료·침상 없으면 이유를 표시하고 대기한다. 소비 전 예약·시작 시 소비·집도의 이탈 시 진행/기여 보존·실패 후 자동 재수술 금지는 유지한다.
- 환자가 쓰러짐/사망/포로/이동 등으로 바뀌면 대상과 공간 예약을 재검증한다. 운반자가 쓰러지면 환자는 그 위치에 남고 새 구조 요청이 가능하다.
- 식사·수면·위생·오락·휴식·치료받기는 생활 상태에 따라 스스로 수행한다. 끝난 뒤 가능한 업무를 다시 고른다. 완료된 직접 명령을 영구 반복하지 않는다.

## 11. 사육·사냥·사체

- 허용된 먹이통 목표·반복 돌봄·직접 생산물 채취·자동 치료 설정에서 필요한 작업을 만든다. 목장마다 고정 담당을 두지 않고 기존 사육/운반/의료/요리 작업 분담을 유지한다.
- 새 야생 개체 포획·위험 취급은 플레이어 지정이 필요하다. 실패 후 무한 재시도하지 않고 사유/위험을 알린 뒤 재지정을 기다린다.
- 도축·방생은 대상·마릿수 확인 후에만 한다. 목표 마릿수가 넘었다는 이유로 자동 도축하지 않는다. 새끼 포획/길들이기·고위험 첫 수술·모든 재수술의 수동 확인 예외를 유지한다.
- 사냥은 지정한 동물만 수행한다. 전투 중 임의로 다른 동물을 사냥 대상으로 추가하지 않는다. 사냥 기술·원거리/근접 장착·위험 조건은 기존 규칙을 따른다.
- 시신/사체는 일반 치우기·지정 묘비 안치·식량 해체를 구분한다. 먹을 수 있는 사체는 기존 지정 조건 없이 자동 삭제하지 않는다. 장수 시신은 자동 소멸시키지 않는다.

## 12. 수리·소화·원정·로켓

- 손상된 허용 건물은 수리 요청, 관리 구역 화재는 소화 요청을 자동 생성한다. 장비 수리의 고정 담당·재료/내구도 손실 규칙과 건물 수리를 구분한다.
- 출전·원정·철수 대상과 수송 경로는 플레이어가 정한다. 그 뒤 준비된 인원/화물의 실제 운반·탑승·하역·허용 자동 수송을 기존 설정에 따라 수행한다.
- 원정지에서는 그 지역에 실제 존재하고 작업을 허용한 장수만 작업한다. 본거지 장수가 다른 지역의 요청 때문에 자동 출정하지 않는다. 징집 장수의 현지 작업은 기존 허용 명령 예외를 따른다.
- 수송의 탑승 정원/화물 공간 예약·시신과 부상자 구분·긴급 출발 확인·남은 대상 현지 보존을 유지한다. 적대 지역 진입·새 수송 경로·귀환/철수 개시는 임의 결정하지 않는다.
- 로켓은 이미 지정한 건설/연료 준비/좌석 예약/탑승 요청을 처리한다. 가동·발사·미탑승자 두고 가기는 플레이어 확인이 필요하며 자동 발사하지 않는다.

## 13. 재료 부족·교착·담당자 상실·취소

- 재료 부족과 입력 금지/도달 불가/출력 가득 참/정전/필수 연구·도구 부족/담당자 없음/고정 담당 부재/침상·탑승 자리 부족/위험 확인 필요를 구분한다.
- 조건이 바뀌면 재시도하되 동일 불가 요청을 매 프레임 잡았다 놓지 않는다. 한 요청의 실패 때문에 다른 실행 가능한 요청이 멈추지 않는다.
- 재료를 가진 창고가 있어도 예약·허용·경로 때문에 못 쓰면 정확히 그 이유를 표시한다. 무한 대기 재료를 위해 남은 재고 전체를 독점하지 않는다. 생산은 시작할 수 있는 작업 단위의 기존 예약 정책을, 건설/장비 수리는 기존 개별 정책을 따른다.
- 담당 장수가 식사/수면 등으로 떠나면 안전한 중단점에서 작업자 자리·미사용 개인 예약을 해제한다. 요청·정상 진행도는 남는다. 원제작자/수리자/연구 담당 등 고정 관계는 별도 보존한다.
- 사망·포로·이탈로 고정 담당 복귀가 불가능하면 ‘담당 변경/취소 필요’를 표시한다. 원제작자 전용 미완성품은 자동 폐기나 자동 인계 없이 보관/취소 선택을 제공한다.
- 요청 취소와 실물 삭제를 구분한다. 운반 취소는 현재 위치/원래 공급처 등 기존 규칙대로 물품을 내려놓고, 소비된 재료의 반환은 분야별 규칙만 적용한다.
- 저장/불러오기·지역 전환 후 같은 요청/산출/소비/탑승을 한 번만 인정한다. 유효한 예약·담당·진행·생산 목표·지정과 금지를 보존하고 경로는 다시 계산한다. 오래된 저장의 미지정 자연 자원을 일괄 지정하지 않는다.

## 14. 화면·피드백

- 하단에 ‘작업 지정’을 둔다. 벌목/채굴/야생 채집/지정 취소, 기존 사냥·철거·우선순위 도구와 연결하며 전투·건설 배치 입력과 충돌하지 않는다.
- 드래그 중 대상 수·적격/제외 이유, 지정 후 대상 작업 아이콘·우선순위, 선택한 대상에 남은 작업량·담당·단계를 보여 준다. 지정 표시와 이동/채집 목표 링은 구분한다.
- 장수 상태는 ‘목재 채집하러 이동/벌목 중/돌 채굴 중/재료 운반/정전 대기/식사/수면’처럼 실제 행동을 표시한다. 이동에는 걷기, 작업에는 해당 동작을 사용한다. 경로만 잡고 비비는 상태를 작업 중으로 표시하지 않는다.
- 작업 목록에서 종류·지역·대기 이유 필터, 대상 이동, 일괄 우선순위·중지·재개·취소를 제공한다. 고정 담당/금지로 실행 불가한 요청도 숨기지 않는다.
- 생산 화면은 현재 재고·목표·진행 중/배송 중 수량·필요 재료·막힌 이유를 보여 준다. 목표 달성은 정상 대기이며 위기 알림을 반복하지 않는다.
- 같은 정전·자원 부족·목적지 부재는 시설/지역별로 묶어 알리고 조건 변화 시 갱신한다. 매 장수·매 프레임 새 토스트를 띄우지 않는다.

## 15. 플레이 예시

- 나무 10그루 벌목 지정 → 채집 가능 장수 자동 배정 → 벌목 산출 바닥 배출 → 운반 장수 보관. 미지정 11번째 나무는 유지한다.
- 밭과 작물 설정 → 농사 장수 파종 → 환경 성장 중 다른 일 → 성숙 수확 → 운반 → 다음 파종. 야생 식물 재수확과 다르다.
- 목공 재고 목표와 건물 청사진 설정 → 지정 벌목 산출 운반 → 설정된 목공 주문 생산 → 건설 재료 배송 → 시공. 나무가 없으면 ‘지정 채집/목재 공급 필요’에서 기다리고 숲을 임의 개척하지 않는다.
- 연구 주제·담당 지정 → 연구/식사/수면/복귀 반복 → 완료 알림. 다음 주제를 플레이어가 정하기 전 임의 연구하지 않는다.
- 부상자 발생 → 허용된 구조/의료 담당이 침상 이동·처치·급식. 금지된 수술을 자동 결정하지 않으며 약품이 없으면 가능한 무약 처치/대기 사유를 따른다.

<toggle heading="h2">
재료·목장 UI 최신 기획

구현 여부 별도.

- 건설 시 주재료 하나를 선택하고 수량·내구도·미관·단열·가연성을 비교한다. 부족 시에도 선택·청사진 배치 가능, 부족분 배송 대기, 자동 재료 대체 없음. 귀한 부재료는 기본 제외·직접 지정만 허용한다.
- 재료 변경에서 비용·작업 중 사용 중지·취소 전액 반환·기존 재료 70% 회수를 안내한다.
- 작업표·장수 기술에 사육을 추가한다. 관리 화면은 우리 면적·과밀도·생산/번식 불이익, 종별 성체/새끼 수·목표수·자동 돌봄, 개체별 건강·배고픔·성장·나이/노령·길들임을 표시한다. 우리 전체에 자동 치료·자동 채취 설정을 둔다. 목장별 고정 담당·최대 수용 슬롯은 없다.
- 새 종은 자동 돌봄 켜짐, 치료·채취는 우리 설정을 따른다. 빈 우리도 설정 보존. 먹이통에는 허용 먹이·종류별 목표량·운반 우선순위·반출 명령이 있다.
- 포식 관계·사냥 시작 사전 경고는 없다. 죽은 먹잇감을 처음 먹을 때 ‘잡아먹혔습니다’ 알림 한 번·위치 이동. 관리 동물의 다른 사망은 원인 알림, 지시한 도축·방생은 사망 알림 없음.
- 방생은 대상 수 확인창 후 즉시 소멸. 치료 시설의 복귀 우리 소실은 ‘복귀할 우리 필요’ 표시. 정확한 사망 시점·개체별 약품 정책은 표시하지 않는다.
- 야생 개체의 직접 취급 작업은 안전·주의·위험 표시, 위험하면 대기·알림 후 장수 선택·강행. 길들인 개체는 저항하지 않는다. 우리 안 취급 실패에 따른 탈출은 오른쪽 위치 알림과 재포획·처치 선택.
- 포획과 운반 명령을 분리한다. 결박되거나 쓰러진 개체를 개별 또는 일괄 선택해 목적 우리로 운반 요청하며 개체별 작업으로 대기시킨다. 장수 한 명은 한 마리씩 운반한다. 포획에는 우리가 필요 없고 운반 목적 우리에는 마릿수 슬롯 예약을 하지 않는다.
- 결박 남은 시간·사전 경고·시간 만료 해제 알림은 표시하지 않는다. 시간이 지나 조용히 풀리면 관련 운반 요청을 자동 취소한다.
- 포획 실패는 실패 알림·지정 취소 후 수동 재지정한다. 길들이기는 돌봄 시설의 반복 돌봄으로 통합하며 새끼도 별도 진행한다. 돌봄 실패는 개체의 자동 돌봄만 중지하고 ‘돌봄 재허용’ 명령으로 해제한다. 불가종은 길들이기 진행도 없이 돌봄 효과만 받는다.
- 운반 목적 우리 변경·취소를 지원한다. 경상 투약은 목장, 중상 수술은 치료 시설을 사용하고 수술 시작 후 취소 명령은 제공하지 않는다.
- 자동 도축·도축 금지 UI는 제거한다. 수동 도축은 이름·마릿수 확인창, 새끼 포함 가능. 대기·포획 중 취소 가능, 실제 도축 시작 후 취소 불가.
- 도축대는 허용 종·작업 중지/재개만 설정하고 사체는 등록 순서로 처리한다. 대기열 순서 변경·개별 제외는 없다. 허용 종 해제는 대기에만 적용한다.
- 고위험 첫 수술은 대기·알림 후 집도의 지정, 재수술은 항상 수동이다.
  - 실패 생존 개체는 시설에서 재수술/우리 복귀를 선택하며 예상 성공률·위험을 표시한다.
  - 실패 실제 결과 알림 클릭 시 시설로 이동한다.
  - 성공·회복 완료도 각각 한 번 알린다.
  - 수술 전 성공률·사망 위험은 정확한 퍼센트, 키트는 수량으로 표시하고 의료 능력·부상·후유증 영향과 교대 작업 비중에 맞춰 갱신한다.
- 시설 상태는 수술 대기/수술 중/집도의 대기/회복 중/복귀 대기, 수술 진행률·남은 회복 시간 표시. 복귀 운반은 회복 완료 후 자동 요청한다. 약품·키트가 없으면 작업 시작 불가, 입원 운반은 시설·키트 확보 후 가능하다.
- 동물이 있는 시설은 철거·이동 불가. 시설 내 방생 불가, 우리 복귀 후 가능. 시설 내 도축 지정도 불가하며 우리 복귀 후 가능하다. 실패 후 복귀 개체는 자동 재입원하지 않고 수동 재수술 지시를 기다린다. 누적 후유증과 영향을 개체 정보에 표시하고 우리 변경 시에도 유지한다.
- 개체 이름은 코어키퍼 방식으로 개체 정보창에서 변경한다. 기본 이름은 종 이름이며 변경한 이름은 유지한다. 알림은 이름을 붙인 경우 이름(종), 기본 이름이면 종으로 표시하고 클릭하면 해당 개체 또는 사망 사건 위치로 이동한다.
- 포획·운반·도축·방생은 일괄 요청과 일괄 취소를 지원하며 일괄 요청 후 개체별 취소도 가능하다. 실제 수술·도축 시작 후에는 취소할 수 없다. 실행 불가능한 개체는 제외하고 사유·마릿수를 표시하며 확인창은 실제 적용 대상을 보여준다.
- 여러 종의 일괄 운반은 선택한 모든 종을 받는 유효한 우리만 목적지로 고른다. 공통 목적지가 없으면 선택을 나눠 요청한다. 운반은 결박되거나 쓰러진 개체만 가능하고 자유 이동 개체를 자동 포획하지 않는다. 장수 한 명은 한 마리씩 운반한다.
- 개체 목록은 종·성장 단계·길들임·부상·현재 작업으로 필터링하고 이름·나이·건강·허기로 정렬한다. 정렬은 목록 표시에만 영향을 주며 작업 순서를 바꾸지 않는다. 일괄 요청도 기존 작업 우선순위를 따르고 별도 우선권을 받지 않는다.
- 투약 효과는 투약 당시 경상에만 적용한다. 효과 중 새 경상은 자연 회복만 하며 효과 갱신·중복 투약 없이 기존 효과 종료 후 다음 투약에 포함한다.
- 미관은 기분 사유로 표시하며 스트레스 게이지는 없음. 온도는 추움·쾌적·더움.
- 시작 창고는 권장 목표이며 강제하지 않는다. 건물·장수 외형과 카메라·하단 패널·이름표 개선은 아직 미정.
</toggle>

## 운영 검토의 기존 화면 연결

- 밭의 기존 작물 버튼은 기준 성장/수확·가공 역할·상온 보존을 툴팁으로 비교한다. 작물별 환경 보정·파종/수확/가공 노동은 별도임을 표시한다.
- 과학 상세는 미완 선행 포함 추가 자원 비용/남은 연구량을 표시한다. 이미 지불한 진행/중단 주제는 중복 과금하지 않는 기준이며, 승급·시설·표본/핵심물 확보 비용은 별도다.
- 전력 소비 건물을 선택하고 상세를 펼치면 기존 하단 패널에서 전력 우선순위 1\~9를 조절한다. 작업/운반 순위와 구분하며 높은 순위부터 공급한다. 기본값은 냉장 8·생산 5·전등 3이며 잠정 수치다. 냉장 상태도 하단에 표시한다.
- 게임 설정의 기존 위협 자동 정지 옵션은 ‘새 위협 자동 정지 · 보스 예고1배속’으로 의미를 표시한다. 켜면 보스 범위 예고 시작에1배속, 끄면 사용자 속도 유지다. 정지 상태를 해제하지 않는다. 실제 화면 육안·전 보스 검수 완료는 아니다.

## 후천 전문성·평가·시작 조합 안내

- 실제 유효 작업으로 기술10 최초 골드20%·20 최초 다이아5%를 평생 한 번 판정한다(사용자 승인 잠정값, 현재13계열). 장수 상세의 기술 칸 툴팁에 획득/확률 실패/빈칸 부족으로 소모/동급 이상 보유/과거·시작 도달 소급 제외를 표시한다. 실제 판정은 알림·이벤트 기록에 남기고 저장/로드·재도달로 재추첨하지 않는다. 긴 공통 툴팁은 내용에 맞춰 높이를 늘린다.
- 인재 평가 상세는 상대평가 별점과 개인 기술 성장을 구분하고 직무별 별점 비교를 안내한다(8검사). CA/PA 숫자 숨김과 기존 평가 기준 갱신 규칙은 유지한다.
- 새 게임 상단은 장수 수·실제 침공(웨이브) 인원/간격 배수(웨이브 산식 확정 시 갱신)·사망 설정의 조합을 표시한다.1명 시작의 동료 구조 불가·마지막 장수 포로 패배와 가혹 사망의 쓰러짐 즉사30%(잠정)를 시작 전에 읽을 수 있다. 시작 버튼 설명에도 반복하며 새 확인창이나 자동 옵션 변경은 없다. 실제 화면 검수와 캡처는 SAVE 단계에서 진행한다.
- <b>(이전 설계 구현 기록 — 최종 방어 웨이브 연계 재설계 대상)</b> 로켓 기존 화면은15일 방어의5일 단일→5일 양방향→5일 다방향 계획과 현재 단계를 표시한다. 총병력·상한·간격은 유지하고 검증된 외곽 경로가 없으면 기존 진입점을 사용한다(실제 생성/분산·경로불가 대체·상한22검사). 새 적 구성/목표 변화·15일 실전 검수 완료는 아니다.

## 창고 필터 반복 설정

기존 창고 화면에서 허용 품목 복사·붙여넣기를 제공한다. 일반 창고끼리/냉장·냉동고끼리만 붙여넣으며 복사본은 원본을 나중에 바꿔도 유지한다. 재고·우선순위는 복사하지 않고, 새로 금지된 물량은 원래 신선도대로 바닥에 보존한다. 퇴비통은 전용 설정을 유지한다. 창고 간 자동 재배치 규칙을 추가하지 않았으며 육안·대규모 이전 검수는 남아 있다.

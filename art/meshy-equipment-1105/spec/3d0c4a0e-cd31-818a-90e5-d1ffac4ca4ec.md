## 보스 진행·탐지·재공략

### 첫 발견과 분기·합류

- 첫 필수 보스 위치만 게임 시작부터 공개한다.
- 이후 보스는 해당 보스 전용 탐지 장치를 사용해야 위치가 공개되고 거점에 진입할 수 있다. 탐지 전 우연한 발견·진입은 불가다.
- 연결은 첫 보스 → 여러 경로 분기 → 주요 보스 합류를 섞는다. 분기 안의 공략 순서는 자유다.
- 합류하는 주요 보스의 탐지 장치 제작에는 모든 분기 경로의 보상이 필요하다.
- 초반 전투 역할은 근접 돌파·원거리 대응·범위 공격 회피로 구분하며 역할 수를 보스 수로 고정하지 않는다. 최소 필수 사슬은 A→B/C→D다. A 핵심물 2개, B·C 탐지기는 각각 A 핵심물 1+목재 5+돌 5, B·C 고유 핵심물 각 1로 D 탐지기를 제작하며 D는 로켓 핵심물을 보상한다. 최소 사슬 외 전체 보스 수·종류·배치는 미정이다.

### 탐지 도구 제작·사용

- 앞 보스 핵심 보상을 본거지에 가져오면 연결된 탐지 장치 제작법이 해금된다. 별도 분석 연구는 요구하지 않는다.
- 특정 보스 하나를 찾는 소모형 도구다. 핵심 보상과 일반 재료를 소모해 제작하고 사용 시 도구가 소모된다.
- 한 번 사용하면 대상 위치가 영구 표시되며 거점 진입 가능 상태를 유지한다.
- 위치 공개 후 추가 대기·진입 해금 조건 없이 원정 준비를 마치고 출발할 수 있다.
- 첫 처치 보상만으로 다음 필수 분기 장치를 모두 제작할 수 있는 핵심 보상량을 지급한다. 일반 재료는 따로 준비한다. 분기 장치 마련을 위한 필수 재처치는 요구하지 않는다.

### 재등장·실패·보상 복구

- 처치 후 게임 내 12일이 지나면 같은 거점에 재등장한다. 아군·수송수단이 현지에 있거나 전투 중이면 보류하고 전원 철수 후 생성하며, 기존 전리품·시신·건축물은 보존하고 회차별 보상은 한 번만 생성한다. 반복 공략은 추가 보상 목적이다.
- 보스전 패배·철수 후 다음 도전에서는 보스 체력이 전부 회복된다. 보스 처치 후 재등장 대기와 실패 재도전은 구분한다.
- 최초 획득은 핵심 보상이 장수 소지품/원정 화물에 들어온 순간, 반입은 본거지 하역 순간이다. 복구 제작 자격은 최초 획득에, 다음 탐지 제조법 해금은 반입에 연결한다. 최초 획득 후 언제든 추가 제작 가능하며 분실 때만 허용하는 제한은 없다.
- 복구 제작은 개당 해당 시대 가공재 100+부품 10·60초를 요구한다(잠정). 제작 시설은 미정이다. 핵심물·탐지 도구는 거래/재활용 불가, 탐지 완료 대상 도구는 제작 불가이며 장비·희귀 추가 보상은 재공략에서만 얻는다.

### 선택 보스·로켓

- 선택 보스는 직접 탐험 또는 전용 탐지 장치로 발견한다. 필수 보스의 탐지 전 발견 불가와 구분한다.

### 레기온의 진형 강화

- 진형의 <b>유리한 보정치만 1.5배</b>로 강화하고 불이익은 그대로 적용한다.
- 예: 봉시진 공격력 +20%·이동 속도 +15%·방어력 -10% → 레기온은 +30%·+22.5%·-10%.
- 단순 숫자 부호가 아닌 효과의 유불리로 구분한다. 받는 원거리 피해 15% 감소는 유리한 효과이므로 레기온에서는 22.5% 감소다.
- 진형 강화와 기본 지휘 한도 +50%, 군세 계승은 함께 유지한다.
- <b>현대식 진형 확정(2026-10-25, 수치 잠정):</b> 6종 각각 독립 연구. 횡대·종대·쐐기는 증기 시대(연구량 400·식량 100·기본 재료 100·Special 10), 산개·엄호·화력집중은 석유 시대(800·150·150·20). 실제 병사 대형 없이 부대 능력 보정만 적용한다.
- 방향 판정: 부대의 마지막 유효 이동/공격 방향이 전방. 전방 90° 안 = 방향차 45° 이하, 측후방 = 90° 초과. 철수 = 공격 목표를 해제한 직접 이동 중(어택무브·공격 중 제외). 종대의 이동 보정은 도보 원정에만 적용하고 차량·항공 속도는 올리지 않는다.
- 합산 순서: 기술·장비 기초 능력 → 일반 가산 보정 + 진형 보정 합산 → 건강 등 곱셈 상태 → 방어 처리 → 받는 피해 보정. 받는 피해 감소는 합산 최대 75%. 레기온은 합산 전에 진형의 유리한 폭만 ×1.5. 역린 분노 ×3 / 탈진 ×0.5는 가산 합계 뒤 적용.

## 범위 공격 예고의 배속 대응

기존 위협 자동 정지 설정을 켠 경우, 원형/부채꼴/직선 범위 공격 예고가 시작될 때 현재 게임 속도가1배속보다 빠르면1배속으로 낮춘다. 예고마다 자동 정지를 추가하지 않고, 적·장수·생활 전체에 같은 속도를 적용한다. 수동/메뉴 정지는 해제하지 않는다. 전투 종료 후 자동 고배속 복귀는 없으며 플레이어가 다시 선택한다. 설정을 끄면 선택 속도를 유지한다. 기존 속도 변경 경로를 사용해 정지→재개도1배속이다. 전체 보스 패턴과 실제 화면에서의 반응성은 추가 검증이 필요하다.

## 특성 공통 규칙

### 슬롯·등급

- 빨강·실버·골드·다이아 4등급이며 모든 종류를 합쳐 장수당 최대 4개다.
- 다이아의 별도 개수 제한은 없다. 전체 4칸이 모두 다이아일 수 있다.
- 다이아 2개 제한 및 초과 시 유전 조합 전체 재추첨 규칙은 취소했다.
- 복합 장단점 특성은 전체 효용으로 등급을 판단한다. 부정 효과가 있다는 이유만으로 빨강으로 분류하지 않는다.
- 긍정 등급은 효과의 강도 중심으로 배정한다. 고정/후천 구분과 등급은 독립적이며 후천 전문성도 다이아일 수 있다.
- 등급별 출현 확률(2026-10-25 확정, 수치 잠정): 새 무작위 특성 1칸당 빨강/실버/골드/다이아 = 25/60/14/1%. 시작 후보는 다이아를 먼저 제외하고 재정규화한다. 개수 1/2/3 = 95/4.5/0.5%로 먼저 정한 뒤 칸마다 등급을 뽑는다. 앞서 제안한 153개 등급 초안·8개 보류는 검토 자료이며 전체 확정 배정표가 아니다.

### 고정 특성과 전문성

- 신체·체질·성적 지향은 생성 전용이다. 생활 취향·수면 리듬·기본 성격·작업 태도·기분 성향·담력·대인 성향도 고정한다.
- 예: 집돌이·방랑벽, 수집광·자연주의, 야행성·아침형, 충직·야심가·교활·탐욕·과시욕, 근면·게으름, 낙관·비관, 무던·예민, 겁쟁이·신중·용맹·무모, 사교적·고독·냉혈.
- 동족 포식·폭력 거부·고행·산 중독도 생성 전용 고정 개성이다.
- 성향 자체를 반복 작업·전투·중상·상실로 바꾸지 않는다. 일시적 기분·관계·건강·기술 변화는 별도로 유지한다.
- 천재·둔재·대단한 기억력은 고정 재능이다. 재능은 학습 속도에 영향을 주며 PA·기술 상한을 높이지 않는다.
- 능숙한 손·굴착 재능·빨리 배움·미식가·간병인·장식가·초록 손 등 기존 기술 +3 재능은 해당 기술의 학습 속도 보정으로 변경한다. 정확한 배율·복합 부효과 정리는 미정이다.
- 후천적 전문성은 작업·전투·지휘 등의 실제 성능에 영향을 주며 생성 시 보유하거나 플레이 중 획득할 수 있다.
- 획득한 전문성은 미사용·기술 하락에도 영구 유지한다.
- 효과·발동 상황이 다르면 비슷한 이름이라도 유지한다. 동일한 효과·조건만 통합한다.
- 건설 불가·연구 불가·요리 불가 등 작업 불가 특성은 유지하며 해당 작업표 칸을 잠근다.
- 알코올 의존처럼 별도로 후천 발생을 확정한 특성은 해당 개별 규칙을 따른다. 모든 고정 특성을 이유 없이 후천 획득 대상으로 바꾸지 않는다.

### 생성

- 신규 생성 특성 개수: <b>1개 95% / 2개 4.5% / 3개 0.5%</b>.
- 신규 생성 시 최소 1칸을 비워 후천 획득 여지를 남긴다. 플레이 중 획득하면 총 4개까지 가능하다.
- 부정 특성은 필수가 아니며 장단점 조합은 무작위다. 배타·중복 금지 규칙을 유지한다.
- 시작 장수 선택 후보는 다이아를 제외한다. 이후 외부 인재와 유전 경로에는 다이아를 허용한다.
- 영입·회유가 기존 장수의 특성을 새로 추첨한다는 의미는 아니다.

### 유전

- 팰월드에서 참고한 ‘양쪽 부모의 특성 후보에서 무작위 유전 + 부모에게 없는 특성의 발생’ 구조를 적용한다.
- 부모의 <b>타고난 특성만 유전</b>하고, 경험으로 얻는 전문성은 유전하지 않는다.
- 부모가 보유한 다이아도 유전 가능한 분류라면 이어받을 수 있다.
- 자녀 개수 정원은 1\~3개 생성 확률을 따른다. 긍정·부정·등급을 우선하지 않고 무작위로 조합한다.
- 같은 특성의 중복 보유와 배타 특성의 동시 보유는 금지한다.
- 앞서 부모 특성별 50% 유전은 우리 게임의 잠정값으로 두었다. 팰월드의 실제 내부 확률과 동일하다고 확정하지 않는다.
- 신규 무작위 특성 확률·유전 초과 정원 시 세부 추첨·부모 양쪽 중복의 가중 방식은 미정이다.
- 전문성 비유전과 생성 시 전문성 보유 가능은 구분한다. 자녀의 무작위 생성 후보에 전문성을 포함할지는 후속 확인 대상이다.

### 후천 획득·상위 교체

- 특성별 반복 행동 또는 큰 사건을 계기로 확률 판정한다. 결과는 자동 적용하고 알림·이벤트 로그로 전달한다. 현재 연결한13개 전문성 계열은 실제 유효 작업으로 해당 기본 기술10에 최초 도달하면 골드20%,20에 최초 도달하면 다이아5%를 각각 평생 한 번 판정한다(사용자 승인 잠정 밸런스). 채집·건설·농사·낚시·제작·연구·의료·요리·근력·예술·정치·사육·조사다. 동시 후보는 기본 기술이 높은 순, 동률 무작위이며 같은 계열은 상위를 먼저 처리한다. 기존/시작 기술이 이미 기준에 도달한 경우는 소급 추첨하지 않는다. 다른 전투/큰 사건 계열의 획득 조건까지 연결한 것은 아니다.
- 반복 행동 획득은 장수별·특성별 평생 한 번만 판정한다. 더 높은 누적 횟수에 도달해도 재추첨하지 않는다. 획득/확률 실패/슬롯 부족/동급 이상 보유/초기·과거 도달로 소급 제외를 저장하고 기술 칸 툴팁에 표시한다. 실제 판정은 알림과 이벤트 기록에 남긴다. 기술 하락·재도달·저장/로드로 기회를 되돌리지 않는다. 현재13계열·확률 경계·4칸 만석·상위 교체·실제 저장/복원·유전 후보/툴팁51 검사 통과. 전문성 필드를 실제 JSON에서 제거한 옛 저장도 로드해 소급 추첨이 없음을 확인했다. 공통 툴팁 높이는 내용에 맞춰 긴 상태 설명을 표시한다. 전 특성/전 다이아 전용 효과·육안 검수 완료를 뜻하지 않는다.
- 큰 사건은 장수별·사건 종류별 한 번만 판정한다. 같은 종류의 새 사건이 반복되어도 새 기회를 주지 않는다.
- 한 사건이 여러 특성 조건을 만족하면 특성별로 각각 판정한다.
- 4칸이 차 신규 획득이 막혀도 판정 기회는 소모한다. 무관한 특성을 밀어내지 않는다.
- 명시적으로 같은 전문성 계열인 경우 상위 등급이 하위 등급을 같은 슬롯에서 교체한다. 효과는 중첩하지 않으며 하위 등급을 다시 추가하지 않는다.
- 같은 기술에 관련된다는 이유만으로 모두 같은 교체 계열로 취급하지 않는다. 기존 전문성 중 역할이 명확히 이어지는 일부만 연결한다.
- 기존 고정 특성은 전문성 교체 대상에서 제외한다.
- 빈 슬롯보다 동시 획득 성공 수가 많으면 관련 <b>기본 기술 수치가 높은 후보</b>를 우선한다. 동률 또는 관련 기술이 없는 후보끼리는 무작위로 결정한다. 장비·기분·부상의 일시적 실효 보정은 비교하지 않는다.
- 제거·완화를 허용한 개별 예외가 있다면 먼저 처리하고 같은 사건에서 생긴 빈칸을 사용할 수 있다. 현재 확정한 고정 성향을 이 규칙으로 제거하지 않는다.

## 다이아 공통 성능·툴팁

- 형식: <b>특성명 → 분위기 문장 → 전용 효과명 — 실제 효과</b>.
- 골드까지는 실제 효과 설명만 표시해도 되며, 다이아는 분위기 문장을 함께 표시한다.
- 다이아는 <b>대응 골드 기본 성능 보정치의 1.5배 + 전용 효과</b>를 적용한다.
- 배율은 총성능이 아니라 증가 보정치에 적용한다. 예: 골드 +20% → 다이아 +30%.
- 전용 효과의 확정 수치를 다시 1.5배로 곱하지 않는다. 무간 2타·참경 방어 무시 30%·역린 +200% 등은 각 확정값을 사용한다.
- 앞서 결정한 무중생유·바벨·낙토·태공에도 소급 적용한다. 무중생유 획득량 +30%는 유지한다.
- 비전투 다이아의 기본 보정은 대응 골드 +20% → 다이아 +30%로 확정한다(2026-10-25, 수치 잠정). 바벨 건설·무라마사 장비 제작·천기 연구·파나케이아 의료·식선 조리·화룡 예술 작업 속도, 역발산 근력 적용 후 운반 한도, 여래장 행정 유효 업무량, 하멜른 돌봄 효과 지속시간에 적용하고, 후긴은 일반 평가 오차·발각·포로 확률을 30% 줄인다. 전용 효과의 확정 수치에는 다시 곱하지 않는다.
- 대응 골드의 지표·수치가 미정인 항목은 구현용 숫자를 임의 확정하지 않는다. 툴팁의 최종 기본 보정 수치도 추후 함께 기입한다.

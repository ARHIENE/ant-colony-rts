### 조사 기술과 성장

- 기술은 기존 15종에 <b>조사</b>를 추가한 총 <b>16종</b>이다.
- 조사도 기본값 0\~20이며 공통 PA에 포함한다. 실제 평가·조사 활동으로 성장한다.
- 현재 능력 CA는 <b>16종 기본 기술의 합계</b>다. 개체별 PA는 생성 시 고정되며 최대 200이다.
- 기존 기술의 성장·유지·감소·재분배 규칙은 유지한다. 조사 경험치량과 주·보조 연결은 미정이다.
- 기술 수와 작업표 항목 수는 구분한다. 작업표는 기존 15종에 <b>소화</b>를 더해 16칸이고, 조사는 작업표가 아니라 ‘조사 담당 지정’으로 수행한다.

### 평가 담당과 표시

- 플레이어가 평가 담당 장수를 지정한다. 조사 기술이 높을수록 인재 평가 오차가 줄어든다.
- 우리 세력과 다른 세력의 인재를 모두 평가한다.
- 실제 CA·PA 합계는 숨기고 <b>현재 능력과 예상 잠재력을 별점</b>으로 표시한다.
- 현재 능력은 <b>종합·분야별 평가</b>를 제공한다. 별점은 우리 세력 수준에 대한 상대평가다. 더 강한 장수가 합류해 다음 평가에서 별점이 내려가도 개인 기술이 감소했다는 뜻은 아니다. 평가 상세에서 이를 설명하고 직무는 해당 분야별 별점으로 비교하도록 안내한다. 잠재력도 도달 보장이 아니다. 기존 개인 기술표·CA/PA 합계 숨김은 유지한다.
- 예상 잠재력은 <b>공통 PA 기준으로 앞으로 얼마나 성장할 수 있는지</b> 보여준다. 분야별 미래 능력이나 별도 PA는 만들지 않는다.
- 예상 별점에는 오판 가능성이 있다. 잠재력 도달을 보장하는 수치가 아니다.
- 우리 세력 평가: 최초 평가 10초/명, 내부 평가는 1일(150초)마다 갱신. 별점 0.5 단위 1\~5, 우리 성인 장수 중앙값 = 3점. 오차 = 현재 능력 ±(30−조사)%·PA ±(30−조사), 평가자·대상별 고정 편향을 저장해 재추첨하지 않는다. 일반 잠재력은 추정 범위로 표시하고 후긴 직접 평가만 정확 별점 하나.

전체 구조

- <b>시민 = 시민 인구</b>: 평소 개별 작업을 시키거나 배회·생산을 시뮬레이션하지 않고 수량으로 관리한다.
  - 이주로 늘며 현물 세금이 소굴의 기본 수입이 된다.
  - 병역으로 장수에게 병력을 배정한다.
  - 시민은 자체 생계·현물 납세·병역을 담당하며 모든 평시 작업 지원은 없다.
  - 동원 중 납세 제외·복귀 시 재개하고 전사하면 인구가 감소한다.(<mention url="https://app.notion.com/p/3d0c4a0ecd31812d80fbeceabb70193e" />)
- <b>장수 = 직접 조작 유닛</b>. 평시에는 채집·건설, 전시에는 전투를 수행한다. 플레이어는 다수(10명 이상)의 장수로 작업을 분담한다
- <b>병영 = 생산 시설이 아니라 무기 종류별 강화(연구) 시설</b>. 장수가 든 무기에 맞는 병영의 강화 효과를 즉시 적용받고, 무기를 바꾸면 강화도 즉시 바뀐다
- <b>건설</b>: 시민 차출 없이 장수가 자동 시공한다. 한 예정지에 여러 장수가 참여해 각자의 작업 효율에 따라 함께 진행한다. 철거·가구 이동도 건설 작업에 포함한다.

조작

- 자연 자원은 장수 선택 없이 벌목·채굴·야생 채집을 클릭/드래그로 지정하면 가능한 평시 장수가 자동 수행한다. 선택 장수의 자연 자원 우클릭은 단일 대상 지정+우선 수행 요청이다. 이동/공격은 기존 우클릭 직접 조작, A+클릭 어택무브를 유지한다.
- <b>평시 작업표</b>: <date start="2026-10-08" /> 기획 확정·변경 부분 구현 대기. 장수별 작업 종류를 금지(0) / 우선순위 1\~9(미설정 기본 5, 높은 값 우선)으로 설정한다.
  - 노란 경보 → 장수별 작업 종류 우선순위 → 대상 우선순위 1\~9 → 실제 이동 거리 → 거리까지 같으면 오래 기다린 요청 순으로 선택한다.
  - 금지한 작업은 경보 중에도 수행하지 않는다.
  - 기술 수치를 함께 보여준다.
  - 자원 우클릭은 우선 작업 지시이며 완료 뒤 자율 작업으로 복귀한다.
  - 출전 중에는 자율 작업을 멈추고 직접 조작한다.
- <b>노란 경보</b>: 특정 작업 대상을 최우선으로 지정한다. 식사·수면·치료는 강제로 중단하지 않는다.
- <b>빨간 경보</b>: 정착지 전체에 적용하며 식사·수면·치료받기·간호를 모두 중단하고 작업한다. 작업 금지는 유지하며 해제하면 정상 생활·작업 판단으로 복귀한다.
- 제작은 생산 목록에 따라 허용된 장수가 자동 수행한다. 요리 등 모든 평시 작업은 장수 업무이며 시민 지원은 없다.
- <b>모든 장수가 모든 작업·전투를 할 수 있고</b>, 결과는 기술 수치로 갈린다(림월드식)
- 선택 정보에 이름·특성·무기·병력 체력·지휘 한도·전투 수치를 표시한다. 시민 병력 배정은 징집소 출전 편성에서만 하고 귀환 시 반납한다
- 무기를 교체해도 전사한 시민이 되살아나거나 복제되지 않는다

- <b>장수당 특성 최대 4개</b>. 빨강을 포함한 모든 등급이 합쳐서 4칸을 사용한다. 시작 시 특성 수와 추첨 확률은 미정이며, 단계형 줄의 중복·배타 특성 동시 보유 금지는 유지한다.
- 번식: 부모 특성마다 50% 확률로 물려받고 모자란 수는 랜덤, 충돌하면 재추첨. 스카우트 영입 장수는 랜덤, 포로 회유 장수는 그대로 합류
- 전투 스탯 보정은 병사 1명 기준으로 더하고 병사 1명분 공격 하한 유지(기존 구현 규칙)
- <b>게임 도중 특성 획득 가능</b>. 최대 4개를 지킨다. 아래 사건별 변화는 기존 잠정안이며 새 획득 조건·확률·등급·빈도와 4칸이 찼을 때의 처리는 미정이다. 변화 시 토스트와 이벤트 로그로 알린다.
  - 중상 누적 3회 → 튼튼이면 제거, 아니면 허약 획득
  - 친구·배우자 사망 → 30% 기조 한 칸 하락(예: 낙관 → 없음)
  - 보스 막타 → 20% 담력 한 칸 상승
  - 정신적 붕괴 5회 누적 → 정신력 한 칸 하락
  - 포로 생활 4일 이상 후 구출 → 30% 냉혈 획득(사교적이면 사교적 제거)
  - 원정 참가 10회 → 방랑벽 획득(집돌이면 집돌이 제거)
</toggle>

- <b>시체·치우기</b>: 실제 사망한 시민·장수와 일반 적은 전투 판정에서 즉시 제외되고 시체로 남는다. 회복 가능한 쓰러짐·포로 전환·퇴각에는 시체를 만들지 않는다. 병력 손실은 한 번의 피해로 죽은 수를 한 묶음에 저장하며, 장수 시체·처형된 포로는 각각 1구다.
  - 본거지 평시 장수 누구나 작업표 '치우기'로 처리한다(고정 순서가 아니라 장수 작업표·대상 우선순위·경보 규칙 적용). 시체 2m 안에서 묶음당 기본 작업량 5초, 일반 작업 속도 보정과 결벽 ×1.5를 적용한다.
    - 현장에서 제거하며 별도 처리장·운반·청소 보상 자원은 없다.
    - 장의사는 청소 완료 시 기분 +5(180초).
    - 시민 병력 묶음·일반 적 사체와 남은 사냥 식량만 사망 후 게임 시간 300초가 지나면 소멸한다. 개별 장수(아군·적) 시신은 유해로 남고 자동 소멸하지 않는다. 일시정지 동안 시간도 멈춘다. 동시 작업자는 1명이며 이동·정지·출전·수면·사망으로 중단하면 예약을 해제한다.
    - 동족 포식은 시민·장수 시체에만 가능하다. 1구당 고정 5초 후 해당 1구를 소비해 Food +10(창고 상한 적용), 포만 100, 기분 +15(600초). 포만이 식사 기준 이하이면 가까운 접근 가능한 시체를 스스로 찾는다. 일반 식사·시체 포식은 동시에 진행하지 않는다.
    - 포식 완료를 12m 안에서 목격한 장수는 기분 -8(300초), 포식자를 향한 관계 -10. 동족 포식·냉혈 장수와 탑승·포로 상태는 목격에서 제외한다. 아군 장수 시체를 먹으면 포식자 포함 살아 있는 소속 장수 전원의 기분 -3(한 달).
    - 사냥 지정 야생 개체의 사체는 기존 Food 20 운반 노드를 유지한다. 동족 포식 대상이 아니며, 식량 유실을 피하도록 '치우기 우선'을 지정한 경우에만 자동 청소한다. 시체 수량·소멸 시간·우선 지정·남은 식량·담당 장수·작업 진행도는 저장한다.

#### 특별 장치 (사용자 선택, 수치 잠정)

- <b>숨겨진 특성</b>: 스카우트 영입·포로 회유로 얻은 장수는 특성 1개가 '?'. 그 특성이 처음 효과를 내는 순간 드러남(겁쟁이 = 첫 전투, 야행성 = 첫 밤, 동족 포식 = 첫 시체 등). 1년이 지나면 자동 공개. 공개 시 토스트 "관우의 숨은 특성: 겁쟁이". 번식으로 태어난 장수는 숨김 없음
- <b>별명</b>: 업적을 달성하면 별명이 붙고 이름 앞에 표시(예: 「새 사냥꾼」 관우). 여러 개면 장수 관리에서 하나 고름. 별명이 있으면 기분 +3
  - 예시(클로드 초안): 보스 막타 3회 「새 사냥꾼」 / 한 전투에서 적 장수 3명 격파 「장수 사냥꾼」 / 중상 5회 생존 「불사신」 / 원정 10회 「떠돌이」 / 건설 기술 20 「명장」 / 동족 포식 5회 「식귀」 / 라이벌 결투 3승 「결투왕」 / 몽유병으로 맵 가장자리 3회 「밤나들이」
- <b>기생성 진균 감염</b>(가상의 질병; 실제 개미 전용 감염 생태를 새 캐릭터에 그대로 적용한다는 뜻이 아님): 원정(보스 둥지·중립 자원지) 참가 시 5%, 랜덤 위기 이벤트로도 발생
  - 잠복(2일, 증상 없음, 의무실 옆을 지나면 발견) → 발현(2일, 작업 -30%, 가끔 10초 멍함) → 조종(명령 불가, 맵의 높은 곳으로 올라감) → 사망 + 포자(반경 10m 장수 20% 감염)
  - 치료는 잠복·발현 단계만 의무실에서(5분, Special 15). 조종 단계는 출전시켜 쓰러뜨리거나 격리해야 함. 방역 연구는 포자 감염 확률 절반, 강한 면역은 면역
  - 기존 랜덤 이벤트 '곰팡이 감염'은 <b>따로 유지</b>: 곰팡이 = 가벼운 전염병(빨리 치료), 기생성 진균 = 느리고 치명적인 병

- <b>특성 등급:</b> 빨강 / 실버 / 골드 / 다이아. 복합 특성은 전체 효용으로 판단하며 긍정 등급은 효과 강도로 정한다. 고정/후천 분류와 등급은 독립적이다. 전체 개별 등급 배정표는 재검토 중이며 최신 기준은 <mention url="https://app.notion.com/p/401c4a0ecd3181d88860f1cd12558ae3">특성·다이아 설계</mention>를 따른다.

### 포로 외교·부상·석방 귀환

확정 기획·구현 대기.

- 포로 외교는 몸값을 통한 자국 장수 반환과 상호 포로 교환만 다룬다. 제3자의 포로를 사 와 회유하는 거래는 없다. 돌아온 자국 장수는 아군이며 수용소·재회유가 필요 없다.
- 몸값은 장수의 능력·특성·정치력과 세력 관계에 따라 달라진다. 감액 협상·포로 교환을 제안할 수 있으며 정확한 산식은 미정이다.
- 부상 없는 장수는 포로가 되면 높은 확률로 부상을 입는다. 이미 부상 중이면 기존 부상을 유지하며 포획을 이유로 무조건 추가 부상을 주지 않는다. 확률·중증도는 미정이다.
- 포획 시 상대가 장비를 압수한다. 몸값·교환의 기본은 장수 석방이며 장비 반환은 별도 협상 조건이다. 반환에 추가 대가를 요구할 수 있다.
- 석방 성립 후 귀환 중 상태가 된다. 귀환 기간 = 기본 게임 1계절(6일) + 석방 거점과 본거지의 실제 거리 × 계수. 거리 구간별 고정값은 쓰지 않는다. 기본 1계절은 1배속 실제 15분이며 배속을 적용하고 일시정지 중에는 멈춘다. 거리 계수는 미정, 협상 전에 귀환 예정일을 표시한다.
- 귀환 중 작업·전투·협상 참여는 불가하지만 공격·재포획 없이 안전 귀환한다. 부상은 이동 중 회복하지 않고 석방 당시 상태로 돌아와 본거지에서 치료한 뒤 활동한다.
- 반환에 합의한 압수 장비는 장수와 함께 귀환 시 도착한다. 일반 장비 거래의 즉시 교환과 구분한다.
- 우리가 잡은 적 장수에게도 부상·장비 압수·몸값/교환·장비 반환·거리 비례 안전 귀환을 동일 적용한다.
- 회유에 성공하면 아군이 되어 포로 교환 대상에서 제외한다. 보류 협상의 대상이 회유·사망·이미 석방된 경우 무효 표시 → 진입 시 상황 변화 대사와 확인 버튼만 → 확인 후 협상·알림 종료 흐름을 따른다. 대사는 미정이다.

부상·질병·의료 (림월드 기준)

확정 기획·구현 대기. 기존 2026-09-24 경상/중상 부위 표는 이 규칙으로 교체한다. 장수 의료는 림월드를 기본값으로 하고 아래에 적은 예외만 다르게 둔다. 오염·청결 보정 없음, 약품 재고가 없으면 약이 필요한 투약·수술 불가는 유지한다.

- <b>신체 부위</b>: 두 팔·두 다리인 캐릭터의 머리(뇌)·눈 좌우·몸통(가슴/배)·팔과 손 좌우·다리와 발 좌우를 기준으로 한다.
  - 여러 상처, 통증·출혈·의식·시력·조작·이동·생명 유지 기능을 관리한다.
  - 머리 장식의 귀·잎·돌기 모양을 개미 더듬이로 취급하거나 별도 감각 능력으로 자동 연결하지 않는다.
  - 장식의 생물학적 기능과 세부 내부 장기 목록은 미정. 치명적 손상·사망 판정은 해당 부위의 생명 유지 기능을 따른다.
  - 비행 장비는 신체가 아닌 장비다.
- 경상·중상은 상태 요약 표시이며 실제 행동 가능 여부는 통증·의식·이동 능력으로 정한다.
- <b>치료 구분</b>: 일반 처치(약 없이 가능, 품질 제한) / 약품 처치·투약(약 필수) / 수술(필요 약품·재료 필수). 중상이라고 무조건 수술하지 않는다. 처치는 즉시 완치가 아니며 이후 시간에 따라 회복한다.
- <b>약품·처치 품질</b>: 약품 기초·일반·고급 3등급(재료·연구는 자원 시스템 2026-10-25 확정안, 처치 품질 배율 무약/기초/일반/고급 0.55/1/1.3/1.6). 처치 품질 = 의료 능력·사용 약품·치료 시설·치료자의 신체 상태. 좋은 처치는 회복을 돕고 질병 악화를 더 억제하되 즉시 완치는 아니다.
  - 환자별 약품 허용 수준(치료 안 함 / 약 없이 / 기초까지 / 일반까지 / 고급까지) 안에서 가장 좋은 약을 쓴다.
- <b>초기 부상·질병</b>: 외상(베임·찔림·타박상·화상·산성 손상), 상처 후속(출혈·상처 감염·흉터), 부위 상실(팔·손·다리·발 등), 섭취 문제(식중독), 일반 질병(감염성 질환·기생충, 이름 추후), 환경 피해(저체온·열사병 — 위험 온도에서 벗어나야 회복). 전염 여부는 질병별로 정한다.
  - 식중독은 림월드처럼 직접 치료하지 않고 증상(구토·활동 저하)이 지나가기를 기다린다.
  - 구체 이름·수치는 추후.
- <b>작업 중단·병상 휴식</b>: 가벼운 상처는 활동하며 필요하면 처치 후 복귀. 출혈 중이면 작업을 멈추고 치료받는다.
  - 통증 쇼크·의식 저하·이동 불가면 쓰러지고 다른 장수가 병상으로 운반한다.
  - 회복 중에는 의료 작업과 별도인 '병상 휴식 우선순위'에 따라 쉬거나 일한다.
  - 처치 완료와 완치를 구분한다.
  - 움직일 수 있으면 직접 출전 명령 가능(부상 효과 유지), 쓰러진 장수는 명령으로 일으킬 수 없다.
  - 병상이 없어도 현장 처치 가능. 회복 중에도 배고픔이 진행하며 스스로 못 먹는 환자는 의료 작업으로 급식한다.
- <b>구조·간호</b>: 구조는 운반 가능한 장수(의료 능력 불필요). 목적지는 접근 가능한 빈 의료용 침상 → 없으면 지정된 의료용 바닥 자리, 사용 가능한 곳 중 가까운 곳. 이동 중 사망 위험이 큰 출혈은 의료 장수가 현장에서 먼저 처치한다.
  - 운반 중에도 출혈·질병은 진행한다.
  - 자가 처치는 허용한 장수가 의식·작업 능력이 있을 때만 가능하며 남에게 받는 것보다 불리하다.
  - 우리 장수·포로별로 치료 허용·약품 수준을 설정한다.
- <b>의료 우선순위(장수·동물 공통)</b>: 같은 의료 장수가 장수와 동물을 모두 담당. 생명 위험 → 중증 → 경증, 같으면 우선순위 1\~9 → 거리 → 오래 기다린 요청. 전염성만으로 위독 환자보다 먼저 치료하지 않는다. 진행 중 처치·수술은 마치고 이동한다.
- <b>수술</b>: 건강 화면에서 시술 선택, 절단처럼 되돌릴 수 없는 수술은 결과 확인 후 요청. 집도의는 자동(수술 가능한 의료 장수 중 능력 높은 순) 또는 직접 지정. 환자가 의료용 침상에 있고 약품·재료를 모두 확보해야 시작하며, 준비 중에는 예약만 하고 시작 시 소비한다.
  - 수술 중 마취로 활동 불가·배고픔 진행. 집도의 이탈 시 정지 후 다른 의료 장수가 이어받고 성공 판정은 각 장수의 실제 작업 비중으로 계산한다.
  - 시작 전 취소 자유, 시작 후 취소 불가. 성공해도 회복이 필요하고, 실패하면 시술 미완료·추가 부상·사망이 가능하며 자동 재시도는 없다.
  - 수술은 해당 시술의 목적만 해결한다.
- <b>재수술</b>: 실패 횟수 자체에 벌점을 두지 않고 실제로 남은 손상·환자 상태로 위험이 정해진다.
  - 실패 피해로 수술 부위·주변에 추가 상처가 생길 수 있다.
  - 출혈 처치 후 수술 가능한 상태로 회복해야 하며 이미 소비한 약품·재료는 반환하지 않고 다시 필요하다.
  - 유저가 다시 요청하며 불가능하면 이유를 표시한다.
- <b>흉터·부위 상실·대체 부위</b>: 림월드 기준. 흉터·상실은 일반 치료로 복구되지 않는다.
  - 대체 부품마다 설치 가능한 부위·성능·연구·재료가 다르며 부품을 확보해 수술로 설치·제거·교체한다.
  - 교체 범위의 손상만 해결하고 다른 부상·질병은 유지한다.
  - 대체 범위에는 팔다리뿐 아니라 내부 장기도 포함한다.
  - 뇌 교체는 불가하다.
  - 두 팔·두 다리 신체에 맞는 부품·장기별 성능·레시피는 별도 확정한다.
- <b>건강 화면</b>: 의식·이동·작업 능력·통증·출혈 요약, 부위별 상처·흉터·상실, 처치 상태(미처치 / 처치 완료 / 다음 처치까지 남은 시간), 질병 심각도·증상·면역 진행도, 출혈 지속 시 예상 사망 시간, 치료 설정(약품 허용·자가 처치·병상 휴식), 수술 목록(시술·필요 물자·담당 의료 장수·대기 사유·취소).
- <b>알림(오른쪽)</b>: 즉시 = 쓰러짐·생명이 위험한 출혈·질병 위독·사망 / 문제 발생 = 구조할 자리 없음·치료할 장수 없음·약품 부족 / 일반 처치·가벼운 회복은 알림 없이 건강 화면. 같은 환자의 같은 문제는 기존 알림을 갱신하고, 누르면 해당 장수로 이동해 건강 화면을 연다.
- 장수와 동물 사이에는 질병이 전염되지 않는다(치료·운반·배설물 수거 포함). 장수는 의료용 침상·의료용 바닥 자리, 동물은 동물 치료 기구를 쓰며 혼용하지 않는다.

<toggle heading="h2">
사망·시신·묘비·추모

확정 기획·구현 대기.

- <b>사망은 일반 치료로 되살릴 수 없다.</b>
  - 장수 시신은 별도 대상으로 남아 운반할 수 있고 기존 사체 '치우기'와 구분한다.
  - 오른쪽 사망 알림과 기록에 이름·사망 원인을 남긴다.
  - 동료 사망 기분은 관계가 가까울수록 크다.
- <b>묘비</b>
  - 유저가 묘비 건물을 짓고 시신 안치를 지시하면 운반 장수가 옮긴다.
  - 묘비 하나에 한 구. 선택하면 이름·사망 날짜·원인 표시. 안치된 시신은 부패하지 않는다.
  - 철거 전에 시신을 꺼내거나 다른 묘비로 이장해야 한다.
  - 땅을 파는 무덤 안은 묘비 건물로 교체했다.
- <b>추모</b>
  - 장례식·추모 지시·참석자 관리는 없다.
  - 지나가던 장수가 고인과의 관계에 따라 짧게 추모하고 일시적인 위로를 받는다(반복 중첩 없음). 친한 장수는 여가 시간에 일부러 찾아가 추모할 수 있다.
  - 전투·구조·응급 치료보다 우선하지 않는다.
  - 관계 기준·방문 빈도는 추후.

### 내구도·수리

- 옷은 착용 중 서서히 닳고 갑옷은 피격으로도 손상된다. 도구는 사용으로 닳는다. 무기를 포함한 장비 내구도 소모 계수는 추후 조정한다. 내구도 0이면 파괴·소실하며 착용자·장비명을 오른쪽에 알린다.
- 파괴 전 주요 제작 재료와 작업 시간으로 수리한다. 수리량에 비례해 최대 내구도가 감소하고 현재 내구도는 감소한 최대치까지 회복한다. 품질은 유지한다. 같은 손상량을 나눠 수리해도 총손실이 같아야 한다.
- 제작 능력이 높을수록 수리 속도가 빠르고 재료 소모·최대 내구도 손실이 적다. 수리마다 담당자를 지정하며 식사·휴식·부상·포로 등으로 이탈하면 일시정지한다. 자동 교대는 없다.
- 유저는 담당자를 언제든 변경 가능. 변경 전 남은 작업의 재료량·예상 최대 내구도 손실을 새 담당자 기준으로 표시하고 적용한다. 각자가 실제 수행한 수리량·소모 재료·발생한 손실은 유지하며 마지막 담당자로 전체 결과를 다시 계산하지 않는다.
- 수리는 일괄 지정·일괄 취소·개별 취소를 지원한다. 담당자도 일괄 지정 후 개별 변경할 수 있고 총 필요 재료를 표시한다.
- 무기·금속 갑옷은 대장간, 천옷·가죽옷은 재봉 작업대 등 해당 제작 시설의 제작 대기열을 함께 사용하고 순서를 조절한다. 재료 부족/착용자 소집 중이면 대기하고 뒤의 가능한 작업을 진행한다.
- 모든 필요 재료와 실제 작업 차례가 확보될 때까지 장비를 계속 사용한다. 시작 시점 손상량으로 소모량을 재계산·표시하고 확보 후 시작한다. 착용자가 작업대에 장비를 벗어 놓고 제작 담당자가 수리한다. 장비·재료는 예약해 중복 사용을 막는다.
- 수리 중 장비는 사용 불가. 임시 장비는 유저가 직접 지정한다. 완료 후 무기·옷·갑옷 모두 원래 착용자가 자동으로 다시 장착하며 소집 중이면 해제 후 수행한다. 임시 장비는 바닥에 내려놓는다. 이는 쓰러져 떨어뜨린 무기의 수동 회수와 구분한다.
- 완료품은 작업대 옆 바닥에 두고 다음 제작을 진행한다. 원래 착용자 예약은 유지하며 다른 장수가 가져가지 못한다. 착용자 없는 바닥·창고 장비는 운반 담당자가 맡기고 완료 후 일반 보관 대상으로 처리한다.
- 취소해도 완료된 수리·최대 내구도 감소·재료 소모는 유지하고 미사용 재료 예약을 해제한다. 맡긴 장비는 현재 상태로 원래 착용자가 회수·재장착하며 소집 중이면 해제 후 수행한다.
- 수리 완료 알림은 착용자·장비명을 표시하고 클릭 시 장비 위치로 이동한다. 화면에 담당자·진행도·필요 재료·현재/수리 가능한 최대/원래 최대 내구도·예상 결과·대기 사유를 표시한다.
- 다른 장수에게 장착 지시하면 기존 수리·착용자 예약을 취소하고 새 지시를 따른다. 이미 진행한 수리와 소모는 유지한다. 원래 착용자 사망·이탈 시 수리는 계속하되 예약 해제 후 일반 보관한다.
- 장비 소실 시 요청 취소·미사용 재료 예약 해제·알림. 작업대 철거·파괴 시 장비와 남은 재료는 바닥에 남고 진행도 보존·중단. 유저가 새 작업대를 지정하면 기존 담당자·진행도로 재개한다.
- 최대 내구도가 낮다는 이유만으로 수리를 금지하지 않는다. 예상 결과를 보여주되 수리 후 현재 내구도가 증가하지 않는 경우만 시작 불가다.

- <b>구현 잠정값</b>
  - PA = 생성 시 max(80, CA+20)\~200 균등, 번식은 부모 평균 ±20. 최근 활용 이력은 작업량 기준 시간 상수 600, 표본 300 이상부터 활용 비중 5% 미만 기술에 작업량×0.05 경험치를 나눠 감소. 보조 능력은 현재 구현된 활동만 연결(채집·건설·농사·낚시·근접→근력, 의료→연구, 요리·예술→제작, 운반→채집). 연구 주제·제작 분류별 보조는 분류가 없어 미적용. 장수 상세에 CA/PA·기술별 활용 비중 표시.
- <b>사용자 확정</b>
  - 포텐은 기술별 한도가 아닌 장수 전체 능력의 공통 성장 한도이며 최대 200이다.
  - 실제로 같은 작업을 계속 시키면 해당 분야와 관련 능력이 성장하고, 계속 활용하지 않는 능력은 내려가 분포가 바뀐다.
  - 연구와 근력만의 일대일 교환이 아니라 16종 기술 전체가 작업별로 상호작용한다.
  - 구현: 기술·작업 각각 15종.
- <b>현재 능력과 포텐</b>
  - 16종 기본 기술은 각각 0\~20이다.
  - 현재 능력 CA = 16종 기본 기술 합계(소수 성장분 포함), 잠재 능력 PA = 개체별 총 성장 예산이며 0 ≤ CA ≤ PA ≤ 200을 지킨다.
  - 모든 기술을 동시에 20으로 올릴 수 없다.
  - 구현: 기술·작업 각각 15종.
- <b>PA는 생성 시 정해진 뒤 고정된다.</b>
  - 시작 기술·부모 유전·숙련 특성의 기본 기술 보정까지 포함해 초기 CA가 PA 이하여야 한다.
  - 영입·회유·저장·불러오기로 PA를 다시 추첨하지 않는다.
  - 분포·유전 확률은 미정이다.
- <b>특성·장비·기분·부상·나이의 효과 보정은 기본 기술 합계 CA와 구분한다.</b> 기술 +3 재능은 최신 규칙상 학습 속도 보정으로 변경한다. 아래 과거 ‘기본 20+특성 3=23’ 예시는 해당 재능의 현행 규칙이 아니다.
  - 직무·무기를 바꿔도 기본 기술 비용은 동일하며 CA를 다시 평가하지 않는다.

### 주 능력·보조 능력 상호작용

- <b>성장 배분 초기안(잠정)</b>: 한 활동의 성장 예산을 주 능력 80% / 보조 능력 합계 20%로 나눈다. 보조가 여러 개면 20% 안에서 나누며 보조가 없는 활동은 주 능력 100%다. 기존 경험치를 각 관련 능력에 100%씩 중복 지급하지 않는다.
- 본업의 결과·속도·품질은 기존 주 기술 효과를 유지한다. 보조 성장은 그 기술의 기존 효과로 이어진다(근력 → 운반량, 제작 → 제작 품질, 의료 → 의료 성능 등). 모든 능력을 작업 효율에 무조건 합산하지 않는다. 별도로 확정한 정치 기술은 행정·외교에 사용한다.

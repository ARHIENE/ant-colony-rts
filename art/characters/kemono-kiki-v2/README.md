# 토끼 주민 얼굴 V2 — 외형 검토용

사용자 요청: 크리스마스 소녀 원본과 너무 비슷한 얼굴 인상을 변경.

- `rabbit-newface.blend`: 독립 저장한 정적 모델.
- `front.png`, `three-quarter.png`: 현재 모델의 정면·사선 렌더.
- `build.py`: Blender의 기존 `Kiki_Rabbit_Settler` 장면을 복사해 V2를 제작하는 스크립트.
- `iris.png`: 새로 제작한 청록색 홍채 텍스처. blend에도 포함.

눈 간격과 세로 비율, 볼과 턱 형태, 입 주변 정점, 앞머리 배치를 조정했다. 원본 Kiki 메시·텍스처를 기반으로 수정한 파생 시안이며 완전히 새로 제작한 얼굴은 아니다. 원본 특유의 인상이 일부 남아 있다.

정면·사선 렌더에서 외형을 확인했다. 원본과 V1은 보존했다. 리그·표정 키·애니메이션 및 Unity 연결은 적용하지 않았다.

# 수동 조합용 외형 부품

`appearance-parts.blend`의 씬 선택으로 각 보드를 연다. 자동 생성 기능은 작업 범위에서 제외했다.

- `Appearance_Parts_Board`: 얼굴형 3, 귀 6, 머리 장식 4, 기본 표정과 울먹임·울음·긴장·사망, 얼굴 무늬, 수동 조합 예시.
- `Expressions_Extended`: 놀람·화남·아픔·졸림·잠듦·풀이 죽음·뿌듯함·호기심·당황·맛있음·공허함. 땀·눈물·홍조는 별도 OVERLAY 루트. 아픔+땀, 웃음+홍조, 놀람+눈물 예시 포함.
- `Hair_Scars_Injuries`: 가르마·둥근 앞머리·곱슬·쌍솜털·잎싹·짧은 솜털 6개. 흉터(SCAR)·긁힘(SCRATCH)·멍(BRUISE)·반창고(BANDAGE)를 이마·볼·몸통·왼팔·오른팔·다리 6부위에 각각 배치한 24개 독립 부품.

EXPR, OVERLAY, HAIR, SCAR, SCRATCH, BRUISE, BANDAGE 루트를 선택해서 해당 자식 메시만 복사한다. PreviewBody/DisplayBody는 확인용 몸체다. 보드의 위치는 전시용이며 캐릭터에 배치할 때 루트 위치를 맞춘다. 초기 보드 부품의 `display_z_offset`은 되돌려야 한다. 카탈로그 JSON에 기록했다.

표정·무늬·상처는 현재 기본 몸체 표면에 맞춘 메시다. 다른 얼굴형이나 체형으로 옮길 때 표면 밀착을 조정해야 한다. 리깅·표정 전환·게임 연결·회복 단계 기능은 구현하지 않았다. 반창고는 작은 부착형 패드이며 팔다리를 감는 붕대 모델은 아니다.

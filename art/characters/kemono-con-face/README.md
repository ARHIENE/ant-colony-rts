# 이모티콘 얼굴 인상 시안

사용자가 제공한 SD 이모티콘의 큰 눈·짧은 얼굴·작은 미소·홍조 표현을 참고했다. V2를 복사해 얼굴만 수정했으며 머리·몸·옷은 유지했다. Kiki 기반 얼굴의 인상이 남는 파생 시안이다.

- `rabbit-con-face.blend`: 별도로 저장한 정적 모델.
- `face-close.png`, `front.png`, `three-quarter.png`: 확대·정면·사선 렌더.
- `build.py`: Blender의 `Rabbit_NewFace_V2` 장면을 원본으로 제작.

확대 렌더로 눈과 입 위치를 확인하고 과한 눈 변형을 줄였다. 애니메이션과 Unity 적용은 하지 않았다.

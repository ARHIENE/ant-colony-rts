# 단순한 주민 캐릭터 — 새 시안 20종

- `variants-20.png`: 번호 01~20의 정면 비교 이미지.
- `variants-20.blend`: 20개의 독립 캐릭터 루트와 전시 장면. 기존 주민 키트를 수정하지 않고 새로 모델링했다.
- `variants-20.json`: 번호별 형태·귀·몸 비율 목록.
- `variants.py`: 비교용 모델 생성 스크립트. Blender에서 새 장면을 만들며 기존 장면을 삭제하지 않는다.
- `simple-resident.blend`, `preview.png`: 첫 기본형 및 5개 뼈를 사용한 24프레임 걷기 시안.
- `frames/`: 기본형 걷기 동작의 12개 렌더 프레임. 20종 전체에 애니메이션을 적용한 것은 아니다.

몸과 머리를 이어 목을 없애고, 손발·귀·눈·입·볼 위주로 단순화했다. 몸 폭과 높이, 위아래 폭 변화, 귀 형태와 색을 달리했다. 장비·랜덤 생성·Unity 연결은 포함하지 않는다. 최종 캐릭터나 게임 규격으로 확정된 자산이 아니다.

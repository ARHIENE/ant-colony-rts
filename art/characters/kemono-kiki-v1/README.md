# Kiki 에셋 기반 토끼 주민 — 정적 외형 시안

사용자가 프로젝트에 넣은 `Assets/Kiki/Xmas Girl/Model/Kiki-v2.fbx`의 얼굴·머리카락·의상 메시와 텍스처를 복사해 재사용한 파생 시안이다. 독자적으로 새로 만든 얼굴 모델이 아니다. 원본 Unity 에셋과 씬은 수정하지 않았다.

- `rabbit-settler.blend`: 외형 검토용 단독 Blender 파일, 사용한 텍스처 포함.
- `front.png`, `three-quarter.png`: 최신 정면·사선 렌더.
- `game-angle.png`: 높은 카메라 각도 시험. 마지막 소매 색상 통일 전 이미지이며 Unity 게임 화면이 아니다.
- `build.py`: 열린 `Kiki_Reference_Study` 장면의 재질 연결·휴식 자세를 기준으로 복사본 생성.
- `polish.py`: 복사본에 한 번 실행하는 의상 정리·렌더 단계. 이미 정리한 모델에 반복 실행하지 않는다.

몸 높이를 줄이고 머리 비율을 키웠다. 토끼귀·꼬리·앞치마 장식을 추가하고 산타 모자·목의 털 장식·방울을 제외했다. 눈·눈썹·속눈썹과 머리카락의 원래 구조를 유지한다.

현재 결과는 자세를 고정한 정적 메시다. 원본에는 리그와 표정 키가 있으나 이 시안의 변경된 비율로 리깅·표정·애니메이션을 이관하거나 검증하지 않았다. Unity 적용·게임 카메라 검증·독립 배포는 하지 않았다. 사용자 제공 에셋에서 파생된 파일이므로 원본과 같은 자산 취급 범위로 관리한다.

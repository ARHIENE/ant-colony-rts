# 흰 토끼 수인 03 — 외형 검토용

- `rabbit03.blend`: 기존 캐릭터와 분리한 새 모델. 얼굴 텍스처는 파일 안에 포함했다.
- `front.png`, `three-quarter.png`: 정면·사선 렌더.
- `face.png`: 눈·눈썹·입·홍조를 그린 얼굴 텍스처.
- `build.py`, `face.py`: 모델·얼굴 생성 코드.

수인 콘셉트 시트의 03번을 참고해 짧은 은빛 머리, 흰 토끼귀, 파란 작업복을 제작했다. 첫 렌더 후 턱 아래 길이와 앞머리 깊이를 줄였다. 원화의 머리카락 흐름과 눈매를 완전히 재현한 상태는 아니며, 사용자의 외형 검토를 위한 1차 모델이다.

리깅·애니메이션·Unity 적용·게임 카메라 검증은 하지 않았다. 최종 게임용 폴리곤 최적화 전이며 옷과 머리 일부에 부드러운 표면 수정자를 사용한다.

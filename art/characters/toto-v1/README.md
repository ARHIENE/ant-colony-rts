# 토토 로우폴리 모델 v1

통통한 캐릭터 시안 중 크림색 토토를 먼저 제작한 정적 3D 시안입니다.

- `toto-v1.blend`: 편집 가능한 모델과 촬영용 장면.
- `toto-v1.fbx`: 모델만 내보낸 파일. 21개 메시, 2,914 정점, 5,700 삼각형.
- `preview.png`: 실제 Blender 렌더.
- `validation.json`: FBX 왕복 후 메시·삼각형 수, 경계 크기, 재질 존재 확인.
- `forms.py` / `build.py`: 형태 생성 소스. Blender에서 build.py 실행 시 별도 시안을 생성합니다. 최종 내보내기는 선택한 모델에 대해 수행합니다.

Z 위, 정면 -Y, 발바닥 높이 0. 크기는 시안 단위이며 세계 내 실제 크기는 미정입니다. 낮은 폴리곤과 smooth shading을 사용했습니다. 볼터치는 몸 표면을 따라가는 별도 메시입니다. 기존 시설·개미 자산은 수정하지 않았습니다.

리깅·웨이트·애니메이션·Unity 임포트는 아직 하지 않았습니다. 몸과 팔다리는 분리된 정적 메시이며, 실제 작업용 관절 변형과 가구 높이·운반물 부착 검증이 필요합니다. 나머지 다섯 캐릭터는 이번 모델에 포함되지 않습니다.

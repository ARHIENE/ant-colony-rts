# HUD V6

`hud-v6.html`을 브라우저로 연다. V5 원본은 유지하며 기존 관리 화면과 동작을 재사용한다. Unity와 연결되지 않는 HTML 시안이다.

## 2026-10-22 시안 정리

- 사용자 제공 `ai-slop-taxonomy.md`의 Safe Green Regression, Excessive Card Nesting, Colored Left Border Cards, Everywhere Glow, Extreme Hierarchy 항목을 현재 HUD에 맞춰 적용했다.
- 표면은 중성색, 색은 경고·상태·선택에 사용한다. 게임 지도와 의미 있는 상태 색은 유지한다.
- 등급 외형 전시·보석 아이콘·발광·그라데이션·색 띠를 제거하고 특성 이름과 등급 문자로 표시한다.
- 자원·생산·특성·진형은 행 구분을 사용하고, 제목 20/15px·본문 13px·보조 12px로 정리한다. 탭은 밑줄로 선택을 표시하고 버튼은 눌림·포커스를 유지한다.
- 이 변경은 HTML/CSS 시안만 대상으로 한다. Unity 글자 크기 문제의 해결로 취급하지 않는다.

## 화면 구성

- 항상 보이는 하단 메뉴는 52px. 선택이 없으면 선택 패널을 숨긴다.
- 장수·복수 선택·출전 장수·시설·동물 선택 시 작은 명령 카드만 표시한다.
- 상세 버튼으로 기존 상세 정보를 별도 창에서 확인한다.
- 왼쪽 미니맵은 접을 수 있다. 상태 미리보기로 선택 예시를 전환한다.
- 오른쪽 알림과 달력, 상단 장수·자원·인구 표시를 유지한다.

## 시안의 경계

- 수량·내구도·수리 계수·음주 간격은 화면 검토용 예시다. 확정 밸런스가 아니다.
- 생산·수리 진행 버튼과 음주 상태 전환은 수동 미리보기다. 실제 재고 예약, 자동 반복 생산, 병목 판정, 이동/재장착 AI, 배관 시뮬레이션은 구현하지 않는다.
- 도구는 종류별 재질을 선택하는 화면 예시이며 개별 실물 도구 재고와 연결하지 않는다.
- 원료 필터 선택은 유지되지만 실제 재료 소비 계산에는 연결하지 않는다. 제조법 전체와 금속 재활용 작업 화면은 후속 범위다.
- 맵은 기존 V5의 SVG 예시를 사용한다. Unity의 랜덤 계단 지형이나 새 3D 캐릭터를 표시하는 화면은 아니다.
- V5 기능의 전체 재검증을 뜻하지 않는다. V6 검사에서는 레이아웃·선택·상세·미니맵·새 관리 창의 대표 조작을 확인한다.

검사: `node design/hud/hud-v6.check.cjs`. 1440×900, 1280×720, 960×720에서 선택 카드 높이·넘침과 대표 화면 전환을 확인한다. 결과 이미지는 저장하지 않는다.

# V6 디자인 검수

2026-10-22. 사용자 요청: 최신 기획 추가 전에 디자인 스킬 적용 여부와 어색한 부분을 검토.

## 판정

디자인 스킬 적용 흔적은 있으나 충분하지 않았다. 얇은 하단 메뉴, 필요할 때만 여는 상세, 키보드 포커스, 동작 줄이기는 반영되어 있었다. 반면 이전 V5의 갈색 버튼이 녹색 패널에 남았고, 수리 설명과 카드가 길며 상세 진입이 중복되었다. 스킬을 읽었는지에 대한 과거 실행 이력 전체를 증명하는 것은 아니며, 이 판정은 현재 코드와 화면 기준이다.

이번 검수에는 `design_skill/emil-design-eng/SKILL.md`를 적용했다. 기존 `DESIGN.md`와 `.impeccable/surfaces/design-hud-hud-html.md`의 큰 하단 콘솔 규칙은 하단을 줄여 달라는 최신 사용자 요청과 충돌하므로 V6에 강제하지 않았다.

| 수정 전 | 수정 후 | 이유 |
| --- | --- | --- |
| 녹색 패널·갈색 버튼 혼재 | 녹색 중립 버튼, 금색 활성/주요 버튼 | 상태와 위계를 일관되게 표시 |
| 수리 공통 설명 상시 노출·큰 카드 | 설명 접기, 카드 여백과 문단 간격 축소 | 대상·재료·진행·지시를 먼저 확인 |
| 선택 카드와 명령 목록의 상세 중복 | 선택 카드 상세만 유지 | 같은 기능의 중복 제거 |
| 조작 후 내부 목록 재생성 | 스크롤과 키보드 포커스 유지 | 반복 설정 시 위치를 잃지 않음 |
| 최신 인재 관리 진입 없음 | 하단 인재·편성 및 기존 상세의 연결 버튼 | 새로운 기능을 기존 흐름에 연결 |
| 설명과 미정 수치 혼동 가능 | 예시·미정·시안 조작 명시, 조건 접기 | 확정 규칙과 화면 예시 구분 |

## V6 화면 기준

- 항상 보이는 하단 메뉴 52px, 미선택 시 선택 카드 숨김.
- 선택 카드는 최대 162px, 낮은 화면에서는 132px. 긴 정보는 상세 창으로 분리.
- 관리 창은 화면 높이 88% 이하, 내부 내용만 스크롤하고 닫기·탭을 유지.
- 버튼·입력·접이식 제목에 키보드 포커스 표시. 대화상자에는 제목 연결.
- 960/1280/1440 폭을 검사. 1280×720에서 수리와 진형 실제 화면을 육안 확인.
- 새 표정/3D 아트, Unity UI, 모바일 전용 레이아웃은 이 작업 범위가 아니다.

## 검증과 한계

`hud-v6.check.cjs`, `hud-v6-people.check.cjs` 통과. HTML의 대표 상태 전환과 레이아웃 검증이며 기존 V5 전체 기능이나 Unity 구현 완료를 의미하지 않는다. 특성 효과와 평가 정확도 등은 설명 및 예시 상태이고 게임 시뮬레이션은 별도 구현 대상이다.

## 보석 등급 외형 수정

| Before | After | Why |
| --- | --- | --- |
| 보라색 글씨만 강조한 둥근 다이아 카드 | 청록·파랑의 각진 카드, 면 패턴·광택·발광 테두리 | 사용자 제공 참고 이미지의 보석 등급 인상 반영 |
| 나머지 등급은 문자만 표시 | 동일한 보석 구조의 레드·실버·골드 외형 비교 | 레드도 같은 광택을 유지하고 색과 등급명으로 구분 |

도감·장수 보유 다이아·효과 미정 다이아에 공통 적용. 일반 특성의 등급은 미정이므로 임의로 배정하지 않는다. CSS의 data-grade로 네 등급을 지원한다. 정적 광택이며 반복 반짝임 애니메이션은 없다. 인재 관리 검사 통과, 1280×720 화면 확인.

# HUD V5 최신 관리 화면 검토

## 2026-10-15 누락 항목 보완

직전 코드·Notion 대조에서 확인한 9항목을 HTML 시안에 보완했다. 기존 225개 검사 통과는 전체 기획 구현 완료를 의미하지 않는다.

- 연구: 상단 과학 화면, 6시대·선행 조건·연구소 등급·장수 배정, 한 연구 공동 진행, 전환 시 진행 보존, 완료 후 수동 선택. 연구 목록·비용은 명시된 예시이며 전체 콘텐츠 목록 확정이 아니다.
- 농사: 3×3 밭 선택, 작물·환경·우선순위·물주기·비료·수확·뿌리뽑기. 수확물 바닥 생성·재성장, 상하좌우 병충해 전파. 의료·관리 상단에서 진입.
- 설비: 전력 공급/수요/용량·기계 연결/사용, 부족·단절·과부하 시 정지. 배관·밸브·탱크와 별도 신호선·AND/OR/NOT. 냉장고의 물류 전력 상태에 연결. 단일 연결망 예시로 지도 배선 편집·유체 물리는 포함하지 않는다.
- 장비: 보관함 장착·교체·해제와 장수 상세/무기 표기 연결, 원정 중 보관함 접근 차단.
- 의료: 확정 15부위 표시·상처/흉터/상실·기능, 별도 병상 휴식 우선순위. 시술 선택·약품/재료/부품 예약·취소 반환, 바닥 자리 수술 금지, 출혈/재료 부족 사유, 해당 시술의 범위만 회복. 부품 이름·성능·연구는 여전히 미정이며 시안용 대체 부품을 사용한다.
- 귀환: 협상 전 거리 비례 예정일, 귀환 진행/완료, 일반 장비 거래 즉시 도착과 석방 동반 장비 도착을 분리. 상호 포로 교환, 무효 협상의 확인 전용 화면. 1배속 300초=게임 1개월, 일시정지/협상 중 정지. 거리 계수는 명시된 예시.
- 추모: 관계·여가 여부 확인, 기분 요인과 일시적 위로 연결, 중복/비상 방문 금지 및 만료. 사용자 추모 명령이 아니라 접힌 시안 진행 도구로 상황을 재현한다.

새 애니메이션은 추가하지 않았다. 기존 포커스 복원·키보드 탭·reduced-motion을 유지한다. 기본 73·물류 58·동물 건강 8·관리 87·누락 보완 86 = 총 312개 브라우저 검사가 통과했다. 새 화면은 1440/1280/1000/720px DOM 넘침 검사를 통과했으며, 캡처·육안 이미지 검토는 하지 않았다.

적용 기준: 사용자가 제공한 `design skill.zip`의 `emil-design-eng`, `review-animations`(프로젝트 `design_skill/` 내용과 동일), 프로젝트 `DESIGN.md`. 설치·전역 설정 변경 없이 해당 지침을 읽고 적용했다.

## 디자인 결정

- 짙은 갑각색 `#1b1712`, 우물색 `#120f0b`, 본문 `#efe7da`, 선택색 `#f2a93b`, 위험색 `#e8574a` 등 기존 토큰을 재사용한다.
- 한글은 기존 sans 글꼴, 변화하는 숫자는 기존 condensed 숫자 스타일을 따른다.
- 상단에는 `의료·관리` 진입점 하나를 추가한다. 의료·동물 위생·묘비·포로는 관리 창 탭, 원정·압수 장비·지역은 원정 창 탭으로 묶는다.
- 현재 상태 → 가능한 지시 → 대기 이유 순서로 읽는다. 시안 강제 진행 버튼은 접힌 상세 영역에 둔다. 출발·도착 진입 등 실제 명령은 상세 영역 밖에 둔다.
- 기존 베벨·촘촘한 목록·상태색을 유지한다. 장식용 애니메이션·새 라이브러리는 추가하지 않는다.

## 기능 검증 범위

- 기존 HUD 72, 물류 58, 동물 질병 8, 신규 관리 87: 브라우저 검사 합계 225 통과.
- 신규 검사는 약 없는 처치·수술 예약 반환·중단·실패·부위별 치료·회복, 배설물/퇴비 원료 보존, 매장/유해, 포로 탈출/재포획/석방, 승객/화물 분리·적재·출발·하역·장비 반환·정착지별 적재를 다룬다.
- 1440/1280/1000/720px에서 새 7개 화면 본문 넘침 없음. 넓은 데이터 표는 자체 스크롤을 사용한다.
- 기존 투약 검사는 앞 시나리오의 예약과 섞이지 않도록 새 페이지에서 실행한다. 중복 소비·정지 중 완료 방지 기대값은 유지한다.

## 시안의 한계

HTML은 예시 데이터와 수동 진행 버튼으로 흐름을 검토하는 도구다. 장수 의료·수송·포로의 시간, 능력 보정, 질병 경과·전투 결과는 실제 게임 시뮬레이션이 아니다. 종별 질병, 약품 레시피, 수송 거리·수용량 등의 미정 수치는 확정하지 않았다. 새로고침하면 예시 상태로 돌아온다. Unity 구현·저장 데이터와 연결하지 않는다.

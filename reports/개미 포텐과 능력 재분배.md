# 개미는 맡은 일에 맞춰 능력을 재분배한다

개미 장수마다 **전체 능력의 성장 한도인 포텐(PA)을 두고 최대값은 200**으로 정한다. 능력 변화는 경과 시간이 아니라 **계속 수행한 실제 작업의 비중**에 따라 결정한다. 자주 활용한 능력은 성장·유지되고, 충분한 작업 이력에서 계속 적게 활용한 능력은 점진적으로 감소한다. 포텐에 도달하면 총량 증가는 멈추지만 능력 구성은 바뀔 수 있다. 아래 내용은 기획 적용안이며 게임 코드 구현이 아니다.

## 확정 요구사항과 적용 설계를 구분한다

**사용자 확정 사항**은 개미별 전체 능력 포텐 최대 200, 반복 작업에 따른 분야별 성장, 덜 쓰는 능력의 감소와 재분배, 모든 능력 사이의 작업별 상호작용이다. 특성은 **빨강(부정)·실버·골드·다이아 네 분류**, 개미당 **합계 최대 4개**, 게임 도중에도 획득한다. 빨강은 부정 특성 분류다.

**기획 적용안**은 기존 기술 13개를 각각 0~20으로 두고 **CA = 기본 기술값 합계 ≤ PA ≤ 200**을 유지하는 것이다. PA는 생성 시 정한 값으로 고정한다. 시작 기술 보정은 기본값에 반영하므로 CA에 포함하고, 특성의 실효 보정과 일시 효과는 제외한다. 직무를 바꾸거나 특성을 얻는 것만으로 PA가 늘어나지 않는다.

## FM의 성장 예산을 참고하되 작업 이력은 자체 설계한다

FM 공식 매뉴얼은 현재 능력과 능력치 분포의 관계, 포지션별 능력 비중, 훈련과 의미 있는 출전 시간의 성장 영향을 설명한다. 우리 게임은 **성장 총량과 성장 방향을 분리하는 원리**를 참고하되, 복잡한 포지션 가중치 대신 기본 기술 1점 = CA 1점으로 단순화한다. ([SI 능력 설명](https://community.sports-interactive.com/sigames-manual/football-manager-2024-fr/joueurs-r5004/), [SI 성장·훈련 설명](https://community.sports-interactive.com/sigames-manual/football-manager-2024/players-r4958/))

FM의 모든 미사용 능력이 정해진 비율로 감소한다는 공식 산식은 이번 조사에서 확인하지 못했다. 아래 작업 비중·감소·재분배 규칙은 사용자 요구에 맞춘 자체 설계다. **게임 며칠 후 감소, 하루 고정 감소량, 하루 재분배 상한을 두었던 초안은 폐기한다.**

## 13개 기술은 실제 작업의 주능력과 보조능력으로 연결한다

기존 작업의 주기술 효과는 유지한다. 보조기술이 성장하면 그 기술의 원래 효과를 통해 다른 작업에도 영향을 준다. 하나의 유효 작업에서 발생한 성장 예산을 나누며, 초안 배분은 **주능력 80% / 보조능력 합계 20%**다. 보조가 여럿이면 20%를 나누고, 해당 보조가 없으면 주능력에 100%를 준다. 이 비율은 사용자 확정값이 아닌 **잠정 밸런스안**이다.

| 실제 작업 | 주능력 | 보조능력과 적용 조건 |
|---|---|---|
| 채집 | 채집 | 실제 부하가 있는 활동의 근력 |
| 건설·수리 | 건설 | 근력 |
| 파종·수확 | 농사 | 근력. 작물의 자동 성장은 작업 아님 |
| 낚시 | 낚시 | 부하를 동반한 그물 회수의 근력. 대기 제외 |
| 제작 | 제작 | 단조는 근력, 정밀기계는 연구, 장식은 예술 등 실제 작업 종류에 해당하는 능력 |
| 연구 | 연구 | 실제 주제에 해당하는 의료·농사·요리·제작·지휘·해당 무기 기술. 없으면 연구 단독 |
| 근접 전투 | 근접 | 근력 |
| 원거리 전투 | 원거리 | 없음 |
| 실제 부대 지휘·전술 수행 | 지휘 | 상황에 맞는 근접·원거리. 같은 전투의 예산 중복 지급 금지 |
| 간호·수술 | 의료 | 연구 |
| 요리 | 요리 | 제작 |
| 예술 작업 | 예술 | 제작 |
| 운반 | 근력 | 채집 |
| 운동 | 근력 | 씨름 등 실제 해당 활동에만 근접 |
| 사냥 | 실제 사용 무기 기술 | 근접 무기를 쓰면 근력 |
| 치우기 | 무거운 물체 운반에 근력 | 새 기술 추가 없음 |
| 학습용 휴게 가구 이용 | 실제 학습한 해당 기술 | 소량 활용. 단순 휴게 제외 |

이 표의 13개 기술은 채집·건설·농사·낚시·제작·연구·근접·원거리·지휘·의료·요리·예술·근력이다. 연구를 계속 시키면 연구와 해당 주제의 보조능력이 성장하고, 작업 이력에서 쓰이지 않는 근력은 감소할 수 있다. 운반이나 운동을 병행하면 근력을 유지할 수 있다. 연구에서 정밀기계 제작으로 옮기면 연구 활용을 이어가면서 제작을 키우며, 채집·건설·운반을 오가면 공통으로 쓰는 근력을 유지한다.

## 계속 수행한 작업의 비중으로 성장과 감소를 판정한다

최근 유효 작업 이력이 충분히 쌓였을 때 각 기술의 활용 비중을 판단한다. 주·보조능력은 해당 작업에서 함께 활용한 것으로 기록한다. 반복적으로 많이 쓰는 능력은 성장하거나 유지하고, 계속 적게 쓰는 능력을 감소 후보로 삼는다. 단순 명령 변경이나 짧은 직무 순회만으로 유지 판정을 충족하지 않는다. **휴식·수면·대기·단순 이동·치료받기는 작업 이력 표본에서 제외한다. 유효 작업이 없으면 이 규칙에 의한 능력 변화도 없다.**

CA가 PA보다 낮으면 실제 작업 경험을 바탕으로 남은 예산 안에서 성장한다. 한도에 도달한 뒤에는 감소 후보 기술에서 실제 줄어든 만큼만 관련 기술로 재분배한다. 내릴 후보가 없으면 정체한다. 예컨대 CA 150 / PA 150에서 비활용 기술이 0.10 감소하고 연구 작업의 성장 조건이 충족되면 연구 관련 기술 합계가 최대 0.10 성장할 수 있다. 감소만으로 다른 능력이 자동 상승하지 않는다.

감소는 한 번만 차감하고 재분배 단계에서 다시 빼지 않는다. 같은 작업을 여러 능력에 기록해도 성장 경험을 복제하지 않으며, 하나의 작업 예산을 배분한다. 기술은 0 아래 또는 20 위로 가지 않는다. **최근 이력의 길이, 유지에 필요한 활용 비중, 작업량당 성장·감소율은 미정**이다. 휴식 때문에 손해를 보지 않고, 직무의 지속적인 편중과 병행이 능력 분포에 드러나는지 검증한 뒤 수치를 확정한다.

## 특성 획득 규칙은 성장 예산과 별도로 확정한다

긍정·부정 특성은 합계 4칸을 공유하며 플레이 중에도 획득한다. 획득 조건·확률, 이미 4개일 때 교체·거절·상실 처리, 상충 특성의 공존 여부는 아직 확정하지 않는다. 이 미정 사항을 임의의 자동 교체나 다섯 번째 슬롯으로 보완하지 않는다. 다음 기획 검토에서는 직무 병행이 실제로 능력 유지를 돕는지, 관련 직무 전환이 기존 숙련을 활용하는지에 맞춰 이력과 변동률을 정한다.
